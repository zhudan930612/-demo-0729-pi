## 1. 目标与非目标

### 1.1 目标

1. 在现有地图右下角增加“灾害风险”入口，并以“查看台风”为本期完整功能。
2. 通过独立 Node 代理安全接入 APIHz，不向浏览器或仓库暴露凭据。
3. 支持多实时台风、当前自然年度历史台风、右侧路径面板、底部压缩时间轴、逐点动画、预测路径、四象限风圈、警戒线和地图双向联动。
4. 保持行政下钻、影像、地块工具、地块详情、种植档案与保单功能稳定。
5. 保持天地图文字注记位于所有专题图层之上。

### 1.2 非目标

- 本期不实现查看天气、地震、暴雨、洪水、干旱、卫星云图、雷达图或台风专题图。
- 不实现截图查看、截图管理或截图导入。
- 不实现会话内自动刷新或手动刷新。
- 不用浏览器直连 APIHz，不使用 `VITE_*` 注入 APIHz 凭据。
- 不插值、不抽稀、不平移、不合并台风节点，不用平均半径画普通圆，不推算缺失业务数据。
- 不把 Leaflet 图层、定时器或请求取消句柄放入 Pinia。

## 2. 现有架构与 owner seam

| Owner | 保留职责 | 本次新增职责 | 明确禁止 |
|---|---|---|---|
| `server/` | 新建独立运行单元 | 凭据读取、固定上游访问、输入与响应校验、统一错误、脱敏探针 | 浏览器凭据、开放代理、记录完整 URL/query/raw response |
| `web/src/features/typhoon/` | 新建纯业务模块 | wire 适配、北京时间、排序、样式、时间轴、预测快照、风圈几何、播放纯状态 | Vue、Pinia、Leaflet、DOM、网络请求 |
| `web/src/api/typhoon.ts` | 新建本站 API client | 仅调用 `/api/typhoons`，转换 HTTP/统一错误 | APIHz URL、ID、KEY、永久跨会话缓存 |
| `web/src/stores/typhoon.ts` | 新建纯会话 store | 实时/历史实体、焦点、每台风节点、打开顺序、抽屉与加载状态、session generation | Leaflet Layer、Timer、AbortController |
| `web/src/map/typhoonLayerController.ts` | 新建 Leaflet owner | 实际/预测路径与点、风圈、中心标记、警戒线、hover/click 事件和清理 | Pinia、localStorage、HTTP、产品状态决策 |
| `web/src/components/typhoon/` | 新建展示组件 | 路径面板、节点表、图例、时间轴、弹窗 | 直接操作 Leaflet、直接请求 API、跨组件业务状态 |
| `MapControlStack.vue` | 右下角控制菜单 | 灾害一级菜单与禁用反馈，只 emit 进入事件 | 重置行政、请求台风、操作图层 |
| `MapView.vue` | 地图装配与跨模块协调 | 灾害模式进入/退出、行政/相机顺序、控制器装配、timer/request owner 协调 | 堆放排序、时间轴算法、API 适配或大段专题渲染 |
| `drilldown.ts` | 行政 path 与导航守卫 | 受守卫管理的回省动作 | 组件直接改 `path` 绕过守卫 |

### 2.1 资源唯一 owner

- 台风 Leaflet layer 与 Leaflet event：`typhoonLayerController`。
- 逐点动画 timer：独立 playback controller/composable；退出、切换台风、点击节点和关闭历史时统一取消。
- 台风请求 AbortController/session generation：repository 或 `MapView` 会话 owner；退出后迟到响应不得写回。
- 全局焦点台风与每台风当前节点：typhoon store。
- 地图相机与行政切换顺序：`MapView`，并通过 drilldown action 保持 Breadcrumb 同步。

## 5. 真实 API 探针门禁

1. 凭据仅来自 process environment 或已忽略的本地 `.env.local`，禁止放入 CLI 参数、日志、文档、测试 fixture 或提交文件。
2. 探针使用北京时间当前自然年度，记录 UTC 抓取时刻和北京时间日期。
3. 年度列表只记录总数、`start/stop` 聚合计数和字段名。
4. 详情只记录样本类别、节点数量、风圈/预测数量、字段名和异常；不记录 `no1`、名称、经纬度、原始节点或完整 URL。
5. 当前快照有实时台风时，不得把“无活动台风真实样例”标记为覆盖；该分支只能由 mock 自动测试覆盖，等待真实无活动时刻补探针证据。
6. 单次探针只能证明该抓取时刻与样本，不承诺年度长期完整性、更新频率或所有历史数据形态。
7. 真实响应与文档冲突时，停止收紧 schema，先更新脱敏证据和需求事实，不通过猜测兼容。

## 6. 停止条件与回滚

任一条件出现时停止进入下一里程碑：

- 对应测试、构建、`git diff --check` 或 secret scan 失败。
- Leaflet layer/event/timer/request owner 不唯一或退出后仍能复活状态。
- 出现图层重复、点击执行两次、地图自动下钻、相机时序错乱、地块数据丢失。
- 真实 API 字段不足以支持需求且需要新的产品或数据源决定。
- 为实现专题功能需要把算法、列表或渲染大段重新堆入 `MapView.vue`。

回滚只回滚当前里程碑的独立提交，不用整文件 restore 覆盖其他已验收工作。
