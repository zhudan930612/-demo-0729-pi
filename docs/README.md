## 实施计划

- [参保村灾害风险联动 V1.1 实施计划](./plans/参保村灾害风险联动-v1.md)：13 参保村三源风险标注 + 风险卡片 + 双季连作措施；状态：已实施（2026-08-10，见计划第 0 节实施摘要）。
- [实时天气多级政府驻地标牌 V1 实施计划](./plans/实时天气多级政府驻地标牌-v1.md)：省→市、市→县、县→乡镇的渐进实时天气标牌、可信政府驻地坐标、按点查询边界与验收计划；状态：已实施（2026-08-05，见计划第 7 节实施摘要）。
- [多村保单业务数据扩展 V1 实施计划](./plans/多村保单业务数据扩展-v1.md)：把 AI 地块识别、参保确认、4+1 保单造数与前端按村加载从龙江村推广到章镇镇/三界镇 13 个影像覆盖村；状态：已实施（2026-08-08，13 村全链路完成，见计划第 0 节实施摘要）。
