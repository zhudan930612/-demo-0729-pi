# 农险双精准地图 Demo —— 灾害风险与台风查看需求

> 版本：v3.2（2026-08-01 验收覆盖复核修正）
> 状态：核心产品需求已确认，可进入开发；真实 API 字段与代理联调作为开发第一阶段技术验证
> 适用范围：右下角“灾害风险”工具及其“查看台风”子功能

---

## 1. 文档目的

本文档独立记录本次新增的灾害风险需求，不修改或替代原有地图、下钻、影像和地块需求文档。

本期优先规划“查看台风”。后续用户提出的每个台风子功能，都必须先对照 APIHz 台风接口文档和真实返回结果判断支持程度，再决定是否纳入实现：

- API 直接支持；
- API 数据可由应用层组合实现；
- API 文档未确认；
- API 不支持，需要其他数据源或调整需求。

## 2. 功能范围

### 2.1 一级入口

在地图右下角现有工具栏增加一级入口：

> **灾害风险**

点击后只展开灾害相关子查看项，不立即进入灾害风险模式：

- 查看台风：本期优先功能；点击该项后才正式进入灾害风险模式、切回浙江省省级状态并加载台风数据；
- 查看天气：预留入口，本期暂不实现；
- 后续可扩展：查看地震、暴雨、洪水、干旱等气象灾害或自然灾害相关内容。

### 2.2 本期不做

- 不新增“查看截图”功能；用户提供的截图仅作为交互、信息布局和地图呈现参考；
- 不在本期实现“查看天气”；
- 不在本期扩展地震、暴雨、洪水、干旱等其他灾害功能；
- 不把台风专题图、卫星云图或雷达图作为当前已确认的必做内容。

## 3. 查看台风总体流程

```text
灾害风险
└── 查看台风
    ├── 查询当前活动台风
    │   ├── 一个或多个活动台风：同时展示全部台风
    │   └── 没有活动台风：显示“当前无活动台风”
    └── 用户主动进入历史台风
        └── 默认查看当前自然年度
        ├── 底部历史时间轴
        ├── 历史台风逐点动画
        └── 右上角实时/历史台风列表
```

### 3.1 实时台风

- 用户点击“查看台风”后，系统首先查询当前时刻的全部活动台风；
- 当前存在一个或多个活动台风时，地图同时展示全部活动台风；
- 选择某个台风只改变右侧详情面板和地图高亮，不隐藏其他活动台风；
- 当前没有任何活动台风时，默认只显示：

> **当前无活动台风**

- 无活动台风时默认隐藏右侧台风列表和底部历史时间轴；
- 在页面底部显示“查看历史台风”按钮；
- 点击“查看历史台风”后，历史时间轴以底部抽屉形式自下而上展开；
- 抽屉展开后按钮保留在底部，再次点击按钮时，历史时间轴自上而下收回；
- 点击“查看历史台风”只展开或收回历史查看入口，不自动打开任何历史台风、不自动播放动画；
- 无活动台风时不得自动切换或自动绘制历史台风。

### 3.2 多台风独立性

每个活动台风必须独立保存和渲染：

```text
台风 A
├── 实际历史路径
├── 当前点
├── 未来预测路径
├── 风圈
├── 时间节点
└── 台风详情

台风 B
├── 实际历史路径
├── 当前点
├── 未来预测路径
├── 风圈
├── 时间节点
└── 台风详情
```

不得：

- 把多个台风的路径点合并成一条路径；
- 让多个台风共用当前台风详情；
- 因选中一个台风而隐藏其他活动台风；
- 用一个台风的风速、风圈或预测节点渲染另一个台风。

### 3.3 右侧台风路径面板

右侧显示“台风路径”信息面板和活动台风列表：

- 列表展示全部活动台风；
- 每个台风可独立展开或选择；
- 选中台风后展开该台风的时间节点和详情；
- 其他台风可以保持折叠，但地图图层继续保留；
- 选择时间节点后，只高亮对应台风的对应位置和信息，不影响其他台风显示；
- 当前选中台风使用更明显的路径、标签、风圈或中心点高亮。

每个台风详情至少包含：

- 台风编号；
- 中文名称和英文名称；
- 当前时间；
- 中心位置；
- 中心气压；
- 最大风速/风力；
- 移动方向；
- 移动速度。

### 3.4 实时台风图层

当前存在活动台风时，每个台风均展示：

- 实际历史路径和当前台风位置；
- 未来预测路径；
- 台风风圈。

24 小时和 48 小时定位警戒线是灾害风险模式的全局固定图层，地图只绘制一组，不按台风重复创建。

图层必须通过图例、线型、颜色或填充明确区分，不得只依赖颜色传达含义。

## 4. 历史台风

- 历史台风查看由用户主动进入，不与实时台风状态混淆；
- 查看范围限定为当前自然年度，即当年 1 月 1 日 00:00 至当前时间；
- 数据查询直接使用当前年份参数 `year=当前年份`，不再合并前一年数据，也不使用滚动 365 天；
- 历史台风通过底部时间轴上的台风标签主动打开；
- 只有通过时间轴打开的历史台风才进入右侧台风列表并在地图展示；
- 打开后地图展示该台风的完整历史实际轨迹；
- 关闭历史台风后，从右侧列表和地图移除，但保留时间轴标签和原始数据；只能通过再次点击时间轴标签重新打开；
- 选择历史时间节点后，可查看该节点的位置、时间、中心气压、最大风速/风力、移动方向和移动速度；
- 用户此前提供的所有台风相关截图均可作为前端排版、信息层级、列表结构、时间轴组织、节点表格、地图标注和交互呈现的参考；
- 截图只用于参考布局和呈现方式，不新增“查看截图”或截图浏览功能；
- 截图中的具体颜色、字体、尺寸、圆角、阴影、间距和控件样式不直接照搬；前端视觉风格、设计令牌、组件边界和响应式规则以仓库当前 `DESIGN.md` 为准；
- 灾害风险面板、台风列表、节点表格、时间轴和详情弹窗应在遵循 `DESIGN.md` 的前提下，吸收截图中适合本产品的排版与信息组织方式；
- 历史台风的实际路径和历史节点按 `datas[]` 展示；选中历史节点时，仅在该节点实际返回 `wind_radius[]` 时展示对应历史风圈，缺失时不推算；
- 历史预测路径仅在数据源明确提供与该历史时段绑定的预测版本时展示，不得把当前预测或估算结果冒充历史预测；
- 24/48 小时定位警戒线不是历史数据版本，而是灾害风险模式的全局固定静态图层；进入模式后始终只绘制一组，不按实时/历史台风重复创建。

多台风历史查看时，所有已加载台风的全部历史点和路径均显示：

- 不抽稀；
- 不隐藏；
- 不合并；
- 不因为路径接近或重叠而删除任何点。

## 5. 历史台风时间轴、动画与列表

### 5.0 截图参考与当前产品设计约束

本节把此前用户提供的截图转成可供新会话直接使用的文字参考。后续开发不应依赖当前会话中的临时图片记录。

#### 5.0.1 截图保留的排版和信息结构

- 所有此前发送的台风相关截图，包括台风列表、节点表格、地图路径、风圈、中心点标注、详情弹窗和底部时间轴截图，均可作为前端排版与呈现参考；
- 截图只用于确定信息层级、区域布局、列表展开方式、节点表格结构、地图标注位置和交互反馈，不要求逐像素复刻；
- 截图不新增为产品功能，不实现截图查看、截图管理或截图导入。

#### 5.0.2 台风地图工作台的空间布局参考

截图呈现的是“地图为主、信息浮层贴边”的全屏地图工作台：

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部：轻量产品/状态信息条                                     │
├───────────────────────────────────────────────┬──────────────┤
│                                               │ 右上：台风路径 │
│                                               │ 列表面板       │
│                 大面积地图                    │                │
│     路径、节点、中心标记、风圈、警戒线           │ 节点表格       │
│                                               │ 可展开/滚动    │
│                                               ├──────────────┤
│                                               │ 灾害风险工具入口│
├───────────────────────────────────────────────┴──────────────┤
│ 底部：紧凑历史时间轴、月份刻度和台风标签                      │
└──────────────────────────────────────────────────────────────┘
```

- 地图始终是最大面积的视觉主体；
- 台风路径面板固定在地图右上或右侧边缘，不遮挡地图中心；
- 面板内先展示台风名称列表，展开后在对应台风卡片内显示节点表格；
- 节点表格使用紧凑的多列信息布局，截图中体现的字段顺序为“时间、气压、风力、移速”；
- 列表和节点区域在内容过多时独立滚动，不能把整张地图页面撑高；
- 地图顶部可保留当前台风的摘要状态，但不使用大面积标题横幅压过地图；
- 底部时间轴横跨地图下沿，显示有台风数据的月份刻度和台风名称标签；
- 右侧工具入口与台风路径面板保持边缘停靠，避免与底部时间轴互相遮挡。

#### 5.0.3 台风列表卡片参考

- 列表以“台风名称/编号 + 中文名 + 英文名”作为每条台风卡片的主信息；
- 每条台风卡片是独立、紧凑、可点击展开的行；
- 实时台风与历史台风通过状态图标、文本或其他非颜色线索区分；
- 展开态在台风卡片下方显示节点表格，收起态只保留台风身份信息；
- 实时台风展开态参考截图：卡片下方显示按时间倒序排列的历史节点，最新节点在顶部；
- 历史台风展开态显示全部历史节点，节点很多时在卡片内部滚动；
- 当前展开的台风、当前选中的节点和可见性状态必须有明确的非颜色反馈，例如边框、背景、图标、字重或高亮描边；
- 实时台风不显示删除/移除控件；历史台风的隐藏/恢复控件只作用于当前地图展示，不删除数据。

#### 5.0.4 节点表格参考

节点表格采用截图所示的紧凑行式结构：

```text
┌──────────────┬────────┬────────┬────────┐
│ 时间         │ 气压   │ 风力   │ 移速   │
├──────────────┼────────┼────────┼────────┤
│ 08月01日23时 │ 925    │ 17级   │ 25     │
│ 08月01日20时 │ 925    │ 17级   │ 24     │
│ 08月01日17时 │ 925    │ 17级   │ 26     │
└──────────────┴────────┴────────┴────────┘
```

- 表头与数据列对齐，时间列占主要宽度，数值列保持稳定宽度；
- 每一行对应一个真实 `datas[]` 历史节点，不把多个节点合并成摘要；
- 当前选中节点使用整行高亮或等价的清晰状态，不只改变文字颜色；
- 节点左侧可使用与历史路径点风速等级一致的状态点，但必须同时保留文字/线型等辅助识别；
- 节点表格需要支持滚动，滚动时表头应保持可理解；
- 缺失字段显示 `--` 或明确的暂无数据文案，不使用猜测值填充。

#### 5.0.5 地图路径、中心标记和风圈参考

- 每个台风使用独立的实际路径和节点图层；多台风路径重叠时保持真实坐标，不人为平移；
- 路径节点沿路线连续排列，点的颜色和大小表达该节点自身风速，不能用一个统一颜色覆盖整条路径；
- 当前/选中节点在基础风速样式之上增加外圈、光晕、标签或置顶层级；
- 截图中的中心点使用醒目的中心标记，并在附近显示“台风名（时间）”短标签；标签不得遮挡节点表格或关键地图操作；
- 选中节点显示该节点对应风圈，风圈应以四象限半径绘制不规则区域；不使用普通圆替代；
- 风圈区域与路径节点保持层级区分，风圈不能遮盖选中中心点和关键文字；
- 地图上的路径、预测路线、风圈、警戒线和选中态必须通过线型、填充、边框、图标或文字形成多重区分。

#### 5.0.6 底部时间轴参考

- 时间轴固定在地图底部边缘，以浅色轨道、月份刻度和台风名称标签组成；
- 历史时间轴作为底部抽屉实现：打开时自下而上展开，关闭时自上而下收回；
- “查看历史台风”按钮固定在页面底部，负责切换抽屉展开/收回状态；
- 台风名称标签使用紧凑的胶囊/圆角标签形式，标签长度表达台风生命周期，不按名称统一固定长度；
- 标签在时间轴上按实际时间范围排列；没有台风的月份不显示，不保留整年空月份；
- 多条台风标签可以分行排列，避免同一时间段的标签相互覆盖；
- 点击台风标签后，标签进入打开/选中态，右侧列表新增并展开对应台风，地图执行逐点动画；
- 再次点击已打开的历史台风标签，关闭该历史台风；标签保留但恢复未打开态，右侧列表和地图移除对应台风；
- 当达到实时台风优先规则或六条展示上限时，历史台风标签保留但显示不可打开状态，并明确说明“实时台风数量已达展示上限”；
- 时间轴内容超出可用宽度时使用横向滚动或左右切换，不通过极度缩小字体解决；
- 时间轴视口切换不能清除地图已加载的实时台风、历史台风或当前选中节点。

#### 5.0.7 本产品设计文档优先级

- 前端视觉风格和样式以仓库当前 `DESIGN.md` 为准，优先遵循其中的设计令牌、颜色语义、字体、圆角、间距、面板、按钮、悬停、窄视口和地图工作台规则；
- 灾害风险面板、台风列表、节点列表、时间轴、风圈弹窗和详情面板可以借鉴截图的信息编排，但不得直接复制截图中的品牌样式、颜色、字体、尺寸或控件外观；
- 截图参考与 `DESIGN.md` 冲突时，以 `DESIGN.md` 为准；本需求的业务规则与截图行为冲突时，以本需求已确认的业务规则为准。

### 5.0.8 灾害风险模式下的地块工具状态

- 当前存在地块筛选、批量新增、手动画图、人工地块修形或种植档案未保存内容时，“灾害风险”入口为不可点击/禁用状态，必须先保存或取消当前操作；
- 点击一级“灾害风险”入口只展开子菜单，不切换行政状态、不加载数据；点击“查看台风”后才正式进入灾害风险模式；
- 进入“灾害风险”模式后，行政下钻状态和面包屑切回浙江省省级，只切换省级行政图层，不把地图相机移动到浙江省省级全景；实时数据返回前保持用户进入模式时的中心点和缩放级别；
- 进入“查看台风”流程后，地图默认缩放级别设为 z=4.5；数据返回后如果存在实时台风，地图直接把默认选中的最新实时台风之最新观测节点放到地图画布几何中心，并保持 z=4.5；其他实时台风继续显示，但不参与首次居中计算；没有实时台风时保持 z=4.5 和进入流程时的地图中心；
- 同时隐藏当前地块图层，并关闭地块详情、种植档案和保单抽屉；退出灾害风险模式后保持关闭，不自动恢复；
- 首次视角完成后允许用户继续缩放和平移地图；地图全局最小缩放级别为 z=3.5，与行政下钻和地块查看保持一致，用户可放大，也可缩小到 z=3.5；
- 退出灾害风险模式时不恢复进入前的行政下钻状态，也不恢复进入前的相机位置；行政状态保持浙江省省级，地图保留退出瞬间的中心点和缩放级别；
- 进入“灾害风险”模式后，地图右下角的“地块工具”入口继续显示，但设置为不可点击/禁用状态；
- 灾害风险模式下不得通过“地块工具”入口打开、切换或叠加地块查看、筛选、批量编辑或手动画图模式；
- “地块工具”不可点击状态需要通过禁用样式、禁用光标或等价的视觉反馈明确表达，不能仅依赖颜色变化；
- 右侧“台风路径”面板提供明确关闭按钮；点击后清除全部实时/历史台风图层、风圈、警戒线、预测路线、列表选中状态和历史时间轴抽屉状态，并退出灾害风险模式；
- 退出“灾害风险”模式后，“地块工具”入口恢复可点击状态；
- 该规则适用于进入灾害风险模式后的实时台风、历史台风及其节点查看状态。


### 5.1 时间范围和数据查询

- 历史台风只查看当前自然年度，范围为当年 1 月 1 日 00:00 至当前时间；
- 首次进入灾害风险模式时加载当前年度台风摘要和实时台风详情；当前没有活动台风时，仍按本规则准备当前年度历史数据，但默认不展示历史入口内容；
- 当前年度历史台风详情按 `list.type=stop` 逐条加载 `datas[]`；成功返回的历史详情用于用户点击“查看历史台风”后生成时间轴；
- 实时台风详情成功后即可先展示实时台风及其地图图层，不等待全部历史详情请求完成；历史详情在后台继续加载；
- 历史时间轴默认不展示；只有点击底部“查看历史台风”按钮后，才以抽屉形式自下而上展开已加载成功的历史时间轴；
- 当前年度没有历史台风时，“查看历史台风”按钮仍保留且可点击；抽屉展开后显示“当前年度暂无历史台风”；
- 历史详情尚未全部完成时允许展开抽屉：已加载台风先显示标签，抽屉内显示“历史数据加载中”，后续成功数据动态补充标签；
- 抽屉展开后再次点击底部按钮，时间轴自上而下收回；
- 只有点击时间轴标签后，历史台风才进入右侧列表并在地图展示；
- 数据查询直接使用 APIHz 的 `year=当前年份`，不合并前一年数据，不使用滚动 365 天；
- 按 `list.type` 分类：`type=start` 为实时台风，`type=stop` 为历史台风；
- 每条列表记录通过 `list.no1` 查询详情，使用 `datas[]` 获取历史节点；
- 历史时间轴只纳入当前自然年度内有历史节点的月份；
- 所有 `time_ymdh`、当前自然年度边界、月份判断、节点排序和时间轴定位统一按北京时间 UTC+8 解释；
- 当前月份只展示到北京时间当前时刻，不展示未来日期。

### 5.2 时间轴月份压缩和台风标签

底部使用日期时间轴展示当前自然年度的历史台风。时间轴不是固定显示完整 1—12 月，而是只显示实际存在历史台风节点的月份：

- 某月份没有任何历史台风节点时，不显示该月份；
- 空月份不占用时间轴展示空间；
- 月份刻度按有数据月份排列，每个有数据月份占相同宽度；
- 单个月份内部按该月实际日期比例定位节点和标签起止位置；跨月台风标签在压缩后的等宽月份段上连续展示；
- 隐藏空月份后，月份之间的视觉距离不再严格等于真实日历距离，以紧凑和可读为优先。

每个历史台风标签的时间范围由其详情 `datas[]` 计算：

```text
开始时间 = datas[] 最早的 time_ymdh
结束时间 = datas[] 最晚的 time_ymdh
周期长度 = 结束时间 - 开始时间
```

- 标签起止位置由压缩后的时间轴坐标映射确定；
- 同一月份内按实际日期比例定位，周期较长的标签通常更长；
- 有数据月份等宽后，不承诺跨月份标签的像素长度与真实持续小时数保持全局严格比例；
- 只有一个有效节点时使用最小可读宽度；
- 标签不得因为台风名称不同而使用相同固定宽度；
- 台风跨越自然年度时，时间轴只显示当前年度范围内的部分；通过时间轴打开后，节点列表和地图展示 API 返回的完整 `datas[]` 历史节点及完整路径。

### 5.3 时间轴展开和左右切换

时间轴展开后不得通过无限缩小字体或压缩标签解决拥挤问题。

V1 时间轴在内容超出可用宽度时必须支持横向查看：

- 宽屏下尽可能展示当前自然年度内的全部有数据月份；
- 标签发生重叠或总宽度超出容器时，支持左右箭头或横向拖动切换时间轴视口；
- 左右切换只改变时间轴视口，不改变地图当前图层和选中台风；
- 月份刻度和台风标签随时间轴视口同步移动；
- 时间轴的当前选中台风始终保持可定位和可回看。

### 5.4 历史台风逐点动画

点击底部时间轴上的历史台风标签，地图对该台风执行从首节点到末节点的逐点路径动画。API 只提供完整 `datas[]`，动画由前端实现。

动画过程：

```text
显示第 1 个历史节点
→ 显示第 1 段路径和第 2 个节点
→ 显示第 2 段路径和第 3 个节点
→ ……
→ 显示最后一个节点和完整路径
```

规则：

- 节点按 `datas.time_ymdh` 升序播放；
- 每一步新增一个实际历史节点和与前一节点的路径线段；
- 节点颜色、直径和路径样式遵循历史路径点规则；
- 播放速度固定为每 300ms 新增一个历史节点，不按真实日期间隔等比例播放；
- 点击具体节点、关闭该历史台风或退出灾害风险模式时，立即停止该台风动画；
- 用户系统启用“减少动态效果”时，不播放逐点动画，直接显示完整历史路径和最后一个节点的风圈及详情；
- 点击时间轴标签后自动播放，不提供暂停、继续或重播按钮；
- 播放结束后保留完整历史路径；
- 点击另一台风时停止当前动画，切换目标台风并从其首节点开始播放；
- 动画不改变 API 原始节点、不插值、不生成额外业务节点。

### 5.5 右上角实时/历史台风列表

右上角“台风路径”列表只展示：

```text
实时台风（type=start）
├── 全部实时台风
历史台风（type=stop）
├── 已通过时间轴打开的历史台风
└── 未打开或已关闭的历史台风不进入列表
```

排序规则：

1. 所有 `list.type=start` 的实时台风优先显示；
2. 实时台风按各自最新 `datas[].time_ymdh` 倒序排列，最新台风在前；首次加载后默认选中并展开第一条实时台风；
3. 历史台风排在实时台风之后；
4. 历史台风按时间轴首次打开顺序排列，先打开的在前、后打开的在后；
5. 历史台风不按台风编号、中文名称、英文名称或最近节点时间重新排序；
6. 关闭后再次打开的历史台风，按本次重新打开时间排到已打开历史台风的末尾。

展示上限：

- 地图最多展示 6 条台风，数量按“实时台风数量 + 已打开历史台风数量”计算；
- 实时台风数量未超过 6 条时，全部实时台风始终保留，不显示删除/关闭操作；
- 实时台风数量达到 6 条时，不允许再打开历史台风；
- 实时台风数量超过 6 条时，按实时台风优先规则全部保留；此时不允许打开任何历史台风，地图台风数量可超过 6 条，这是实时台风优先于六条上限的例外；
- 首次进入灾害风险模式时自动加载实时和当前年度历史数据；
- 数据加载成功后不设置自动刷新机制，不提供手动刷新按钮；当前模式会话使用单次数据快照；
- 只有重新进入灾害风险页面/模式，或按 `F5` 刷新浏览器页面，才会再次加载数据并重新计算实时台风、六条展示上限和预测/实际状态；
- 因此本期不实现会话内“实时台风新增后自动关闭历史台风”或“实时台风减少后自动恢复历史台风”；
- 历史台风只能通过时间轴标签打开，打开后进入列表和地图；
- 历史台风标题行提供关闭图标；关闭后从右侧列表和地图移除，但保留时间轴标签和原始数据；只能通过再次点击时间轴标签重新打开；
- 节点很多时，列表内部滚动，不抽稀、不删除、不合并节点；
- 列表、时间轴和地图图层必须同步。

### 5.6 列表展开和节点展示

#### 实时台风

首次加载存在一个或多个实时台风时，全部实时台风的实际路径、最新中心点和最新节点风圈同时显示；按最新节点时间倒序排列，并默认选中、展开最新的一条实时台风。未选中实时台风仍保留路径、最新中心点和最新风圈，选中台风置顶高亮。

实时台风展开后显示该台风已经发生的历史观测节点，即详情中的 `datas[]`，不把未来预测节点放入节点列表：

- 节点按时间倒序排列，最新历史节点在最前；
- 每个节点至少显示时间、中心气压、风力/强度和移动速度；
- 节点数据来自该节点自身，不使用当前最新值覆盖历史值；
- `forecast_babj[]` 只作为地图预测路线数据，不作为实时台风历史节点展示。

#### 历史台风

历史台风展开后展示该台风 `datas[]` 的全部历史观测节点：

- 不只展示首尾节点；
- 不抽稀、不隐藏、不合并节点；
- 节点按时间倒序排列，最新节点在最前；
- 每个节点至少显示时间、中心气压、风力/强度和移动速度；
- 节点过多时在列表区域内部滚动，不能用删除节点解决展示长度问题。

### 5.7 节点点击后的地图联动

台风查看区分两层选中状态：

- 全局只有一个“当前焦点台风”，用于右侧详情、路径置顶和强调高亮；
- 每条已展示台风各自记录一个“当前节点”，用于该台风节点高亮和风圈展示；切换焦点台风不清除其他台风已记录的当前节点。

点击实时或历史台风列表中的任意历史节点后：

1. 完整历史路径继续显示，不因选中节点而只保留局部路径；
2. 被选节点增加高亮；
3. 地图将风圈切换为该节点实际返回的 `wind_radius[]`；
4. 风圈中心定位到该节点的 `lat/lon`；
5. 详情弹窗切换为该节点对应的时间、位置、气压、风速/风力、移向和移速；
6. 其他时间节点的风圈隐藏，避免同一台风整个生命周期的风圈叠加遮挡；
7. 其他台风的路径和当前选中状态不受影响。

节点未返回风圈数据时：

- 不使用其他时间节点的风圈替代；
- 不根据风速、强度或平均半径自行推算；
- 显示“暂无该节点风圈数据”或对应字段 `--`。

历史台风节点点击与逐点动画的关系：

- 只有点击底部时间轴上的历史台风标签才打开台风并开始该台风逐点动画；
- 点击右侧列表中的台风标题行不播放动画，只展开或收起节点；
- 点击具体节点不播放动画，直接切换到该节点；
- 动画播放时，列表中的当前播放节点同步高亮，地图显示当前播放节点风圈；
- 动画结束后保留完整历史路径，默认显示最后一个节点的风圈和详情；
- 再次点击时间轴上的同一历史台风标签，关闭该台风并从列表、地图移除，时间轴标签保留。

三者同步规则：

- 有实时台风时，时间轴抽屉展开或收回都不隐藏实时台风列表和地图图层；
- 收回时间轴抽屉只隐藏时间轴，已打开历史台风继续保留在右侧列表和地图；
- 抽屉关闭时没有可操作的历史标签，必须先打开抽屉；
- 点击右上角实时台风名称：展开对应实时台风节点，地图选中该台风；不播放历史动画；
- 点击右上角已打开历史台风名称：展开或收起对应历史台风节点，不重新播放动画；
- 点击右上角节点：地图高亮对应节点，切换对应风圈和详情，时间轴指示器移动到对应时间，不播放动画；地图只平移到足以让该节点可见，不改变用户当前缩放级别；
- 点击底部时间轴历史台风标签：打开对应历史台风，右上角列表新增并展开，地图开始该台风动画，并自动适配该台风实际路径与预测路径的完整范围；
- 再次点击已打开的时间轴标签：关闭对应历史台风，清除该台风的节点高亮、风圈和详情，右上角列表和地图移除，时间轴标签保留；其他实时台风和历史台风不受影响；
- 点击地图上的历史路径或节点：右上角列表同步高亮对应台风和节点，时间轴定位到对应台风；
- 选择一个台风只改变对应详情和高亮，不隐藏其他实时台风；
- 动画结束后保留完整历史路径，默认显示最后一个节点的风圈和详情。

## 6. 历史路径点视觉规则

### 6.1 点的基本含义

历史实际路径由按时间排列的固定观测点组成，每个点代表一个时间节点。点的颜色和基础直径由该节点的最大风速决定。

API 字段对应：

```text
datas.time_ymdh       时间点
datas.lat              纬度
datas.lon              经度
datas.wind_speed_ms    中心风速，单位米/秒
datas.intensity_code   强度代码
datas.intensity_text   强度中文名称
datas.intensity_desc   强度完整描述
```

### 6.2 固定颜色和尺寸

| 风速范围 | 强度 | 颜色 | HEX | 点直径 |
|---:|---|---|---|---:|
| `< 17.2 m/s` | 热带低压 | 蓝绿色 | `#14B8A6` | **5px** |
| `17.2–24.4 m/s` | 热带风暴 | 蓝色 | `#3B82F6` | **6px** |
| `24.5–32.6 m/s` | 强热带风暴 | 黄色 | `#FACC15` | **7px** |
| `32.7–41.4 m/s` | 台风 | 橙色 | `#F97316` | **8px** |
| `41.5–50.9 m/s` | 强台风 | 粉色 | `#E879F9` | **9px** |
| `≥ 51.0 m/s` | 超强台风 | 红色 | `#EF4444` | **10px** |

所有路径点统一使用：

```text
边框颜色：#334155
边框宽度：1px
```

上表中的点直径不包含选中态外圈、当前点光晕或其他交互叠加。

### 6.3 时间快照规则

每个路径点是一个固定时间快照：

```text
时间 T1 → 风速 V1 → 颜色 C1 + 大小 S1
时间 T2 → 风速 V2 → 颜色 C2 + 大小 S2
时间 T3 → 风速 V3 → 颜色 C3 + 大小 S3
```

- 点生成后颜色和直径固定；
- 不因后续节点或当前风速变化而重算历史点；
- 只有到达下一个时间节点时，才使用该节点风速新增并计算新点；
- 不使用当前风速统一刷新全部历史点；
- 不对历史点平滑、插值、抽稀或重新分级；
- V1 假设每个路径点都有有效风速；
- 若接口返回缺失或无效风速，属于数据异常，不使用其他字段猜测，也不套用默认颜色或大小。

### 6.4 当前点和选中点

颜色和基础直径表达风速强度，交互状态使用额外视觉叠加表达：

- 当前最新点：增加白色外圈或光晕；
- 用户选中点：增加高亮外圈；
- 普通历史点：仅显示对应颜色、尺寸和边框；
- 交互叠加不得改变风速对应的基础颜色和直径。

## 7. 多台风路径重叠

当多个台风路径接近或完全重叠时：

- 仍按各自真实经纬度和自身节点风速独立绘制；
- 不人为平移；
- 不人为错开；
- 不合并；
- 不删除重叠点；
- 不改变真实坐标。

通过以下方式解决辨识问题：

- 右侧台风列表独立选择；
- 选中台风的路径、路径点、中心点和标签置于更高层级并高亮；
- 未选中台风保留显示，但可降低显示优先级；
- 点击某台风或其时间节点时，只高亮和展示对应台风的对应节点；
- 完全重叠的点不做视觉偏移，使用台风列表和选中置顶作为独立选择入口。

## 8. 固定定位警戒线

### 8.1 业务定义

24 小时和 48 小时线采用中央气象台台风网使用的固定地理业务边界，正式名称为：

- **24 小时定位警戒线**：台风中心进入后，表示预计 24 小时内可能对我国有显著影响，并可能于 24 小时内登陆我国；
- **48 小时定位警戒线**：台风中心进入后，进入 48 小时定位警戒业务范围。

两条线：

- 不是台风风圈；
- 不是预测路径；
- 不是预测概率范围；
- 不是动态缓冲区；
- 不随台风中心移动；
- 不由台风 API 返回。

系统使用静态经纬度折线绘制，并可据此判断台风中心是否进入对应警戒区。

### 8.2 固定坐标

坐标顺序为 `[纬度, 经度]`，取中央气象台台风网当前前端 `guardLine()` 实现：

```ts
const guardLine24 = [
  [34.005024, 126.993568],
```

## 9. APIHz 台风接口能力边界

文档地址：<https://www.apihz.cn/api/tianqitaifeng.html>

### 9.1 已确认支持

- 使用 `year` 获取一个年份的多个台风摘要列表；
- `list.type=start/stop` 作为实时台风/历史台风的分类依据；
- 列表排序、节点倒序展示、节点点击后的路径高亮、风圈切换和列表/地图联动由应用层实现；
- 每条列表记录包含唯一编号 `list.no1`、中英文名称和状态 `list.type`；
- 使用每条记录的 `no1` 分别查询单个台风详情；
- `datas`：单个台风的历史观测节点，包括时间、经纬度、气压、风速/强度、移动方向和移动速度；
- `forecast_babj`：单个台风的未来预报节点，包括预测时间、经纬度、气压、风速/强度和预报描述；
- `wind_radius`：单个台风的风圈数据，包括风圈等级及东北、东南、西南、西北四个象限半径。

因此，APIHz 支持：

```text
多个台风摘要列表
  → 按 no1 分别查询多个台风详情
  → 应用层同时展示多个台风
```

一次 `no` 详情请求只对应一个台风，不能一次获取所有台风的完整路径、预测路径和风圈。

### 9.2 尚未确认

APIHz 文档尚未确认：

- `year=当前年份` 是否能稳定返回当前年度完整台风列表；
- API 数据更新时间；
- 历史节点与 `wind_radius[]`、`forecast_babj[]` 的长期稳定绑定和全部缺失结构。

2026-08-02（北京时间）已使用真实 API 完成脱敏技术验证：首次技术探针 UTC 时刻为 `2026-08-01T17:55:36Z`，随后使用仓库正式脚本复跑，最终提交报告的 UTC 抓取时刻为 `2026-08-01T18:09:15Z`；两次聚合结果一致：

- `year=2026` 返回 15 条摘要，其中 `type=start` 2 条、`type=stop` 13 条；列表同时出现 `start/stop`，每条包含 `no1`、中英文名称与状态等文档字段；
- 一个 `start` 详情样本返回 44 个 `datas[]` 节点，44 个节点均含非空 `wind_radius[]`，预测数组挂在 1 个观测节点上并包含 8 个 `forecast_babj[]` 节点；
- 一个 `stop` 详情样本返回 21 个 `datas[]` 节点，没有非空 `wind_radius[]`，但 1 个观测节点上出现 1 个 `forecast_babj[]` 节点；这证明历史样本也可能带预测字段，前端不得仅凭 `type=stop` 推断其一定缺失，是否属于与历史时段绑定的预测版本仍需保守判断；
- 本次当前年度快照存在 2 个活动台风，因此没有覆盖真实“当前无活动台风时刻”；该 UI 分支由自动测试覆盖，等待未来当前时刻无活动时再复核；
- 补充的过去完整自然年度列表脱敏结构探针中，2025 年返回 32 条（`start=0`、`stop=32`），2024 年返回 28 条（`start=0`、`stop=28`），2023 年返回 20 条（`start=0`、`stop=20`），三年字段集合一致。这证明 API 能返回 `start=0` 的列表结构，但不能冒充当前无活动台风时刻。

上述结果只证明对应抓取时刻、两个详情样本和三个过去自然年度的列表结构，不保证当前年度列表长期完整、数据更新频率或所有历史节点的字段形态。可提交的完整聚合字段名与计数见 `server/reports/apihz-probe-summary.json`；报告不含凭据、完整 URL、台风编号、名称、坐标或原始节点。当前年度活动与字段已获真实覆盖；当前无活动 UI 获自动测试覆盖；API 的 0-start 返回形态获过去自然年度真实探针覆盖。

本需求已确认使用 `list.type=start/stop` 作为产品中的实时台风/历史台风分类依据，不得在应用层另设时间窗口重新分类。后续适配仍需允许字段缺失，并在真实响应发生结构漂移时停止收紧 schema、更新脱敏证据。

### 9.3 接入安全和查询规则

- API `id`、`key` 等凭据不得放入浏览器端代码或提交到仓库；
- 正式接入通过本仓新增的独立 Node 服务端代理完成；服务端从未提交的环境变量或服务端 `.env.local` 读取凭据，前端只调用本站代理接口；
- 仓库需要提供服务端独立启动命令、开发环境前后端联调方式和生产部署说明；
- 代理隐藏 APIHz 凭据、校验上游 HTTP 状态和响应基本结构，并统一错误响应；成功数据基本保持 APIHz 原字段结构，由前端适配；
- 不得使用 Vite `VITE_*` 环境变量向前端注入 APIHz 凭据，因为该类变量会进入浏览器构建产物；
- 文档和仓库不得记录真实开发者 ID、KEY 或完整带凭据请求；
- 首次进入灾害风险模式自动加载实时台风和当前年度历史数据；
- 实时台风详情成功后即可先展示实时台风，不等待历史详情全部完成；历史详情请求继续加载；
- 历史时间轴默认隐藏，无论当前是否存在实时台风；
- 页面底部显示“查看历史台风”按钮；点击后以底部抽屉形式自下而上展开已加载成功的历史时间轴，再次点击后自上而下收回；
- 有实时台风时，打开或收回时间轴抽屉都不影响右侧列表中的全部实时台风；只有点击时间轴标签打开的历史台风才追加到右侧列表；
- 收回时间轴抽屉只隐藏时间轴，不关闭已经打开的历史台风；已打开历史台风继续保留在右侧列表和地图；
- 抽屉关闭时不显示历史台风标签，必须先打开抽屉后才能点击标签；
- 当前没有活动台风时，默认只显示“当前无活动台风”，右侧列表保持隐藏；
- 当前阶段暂不展开通用 API 请求失败、部分历史详情失败和重试交互，待真实 API 接入后专项确认；预测快照失败边界按 11.5 节执行；
- 数据加载成功后保持当前数据快照，不自动刷新；
- 不提供台风面板内的手动刷新按钮；只有从灾害风险模式退出后再次进入，或按 `F5` 刷新浏览器页面时，才重新执行数据加载；单纯展开或收起面板不重新加载；
- 正式接入应通过受保护的服务端代理或同等安全中间层；
- 历史台风直接查询当前自然年度 `year=当前年份`，不合并前一年数据，不按滚动 365 天过滤；
- 24/48 小时定位警戒线使用系统内置固定坐标，不从 API 获取，不用风圈或预测路径缓冲代替。

## 10. 最新节点风圈与悬停弹窗

### 10.1 最新节点风圈

对每个实时台风，取其 `datas` 中时间最新的观测节点作为该台风的最近一次发布节点。最新节点以 API 返回的 `time_ymdh` 排序确定，不使用浏览器当前时间推算。

每个实时台风的最新节点独立展示：

- 当前中心标记；
- 当前节点对应的路径点颜色和基础直径；
- API 实际返回的各级风圈；
- 中心点悬停详情弹窗。

风圈数据来自该最新节点的 `datas.wind_radius`。优先使用四象限半径生成不规则风圈：

```text
ne_radius_km：东北
se_radius_km：东南
sw_radius_km：西南
nw_radius_km：西北
```

不得用 `avg_radius_km` 画成普通圆替代四象限风圈。`avg_radius_km` 只作为辅助统计值。API 未返回某个风圈等级时，只显示实际返回等级，不自行推算，不用其他等级或平均半径填充缺失数据。

### 10.2 中心点悬停弹窗

鼠标移动到实时台风最新中心图标时，展示该台风最新节点的完整弹窗；移出中心图标并进入风圈区域时，切换为对应风圈弹窗。多个台风各自拥有独立中心点和弹窗，不能混用字段。

中心点弹窗至少展示：

- 台风中文名称、英文名称和最新节点时间；
- 中心位置；
- 风速风力；
- 中心气压；
- 移速移向；
- 七级、十级、十二级半径；API 缺失的等级显示 `--`；
- 参考位置；
- 未来趋势。

参考展示结构：

```text
白海豚（DOLPHIN） 8月1日20时
中心位置       156.20° / 21.60°
风速风力       58米/秒，17级（超强台风）
中心气压       925百帕
移速移向       24公里/小时，西北西
七级半径       200-400公里
十级半径       120-160公里
十二级半径     70-90公里
参考位置       距离某地某方向约2940公里
未来趋势       将以每小时20-25公里的速度向西北方向移动，强度变化不大
```

### 10.3 风圈区域悬停弹窗

鼠标移动到某个风圈区域时，展示当前风圈等级和四象限半径信息，参考用户提供的风圈悬停截图：

```text
十级风圈
西北       东北
160km      160km
西南       东南
120km      160km
```

规则：

- 移入七级、十级或十二级风圈区域时，展示对应等级弹窗；
- 弹窗默认展示四个象限的全部半径，鼠标所在象限可额外高亮但不隐藏其他象限；
- 风圈重叠时，优先识别最内层、等级更高的风圈：十二级 > 十级 > 七级；
- 移出风圈区域时关闭风圈弹窗；
- 移入中心图标时切换为完整中心点弹窗；
- 实时台风默认展示各自最新节点风圈；历史台风展示各自当前选中节点风圈；
- 移入任一已显示风圈时，弹窗只使用该风圈所属台风、所属节点的数据，不得混用最新实时节点或其他台风字段。

### 10.4 参考位置

参考位置不得固定使用那霸市或任何单一地点。它应随台风的当前中心位置和数据源内容动态确定，不同台风或同一台风的不同时间节点可以使用不同参考地点。

优先级：

1. 如果数据源返回官方位置描述、公报原文或包含参考地点的自然语言，直接展示原始文案；
2. V1 不建设参考地点库，也不根据经纬度自行选择地点或计算距离、方向；
3. 如果 API 没有返回官方参考位置原文，统一显示“暂无参考位置”，不得编造。

应用层计算文案格式：

```text
距离{参考地点}{方向}约{距离}公里
```

V1 规则：

- 只展示 API 返回的官方参考位置原文；
- API 未返回时显示“暂无参考位置”；
- 不新增地点库、海域划分、距离计算或方向计算；
- 不使用固定城市替代动态参考位置；
- APIHz 当前已确认经纬度字段，但未确认直接提供官方参考位置文案。

### 10.5 未来趋势

未来趋势优先使用 API 原始预报描述，不得凭空编造：

1. 优先展示 `forecast_babj.forecast_desc`；
2. 没有完整预报描述时，使用 `move_desc`、`move_dir_text`、`move_speed_kmh` 及预测节点生成应用层文案；
3. 只有预测点时，根据预测节点的方向、速度和强度变化生成结构化文案；
4. 数据不足时显示“暂无预报信息”。

API 原文与应用层生成文案必须在数据来源上可区分。未来趋势可参考：

```text
将以每小时20-25公里的速度向西北方向移动，强度变化不大
```

### 10.6 API 能力边界

| 弹窗/风圈需求 | APIHz 状态 |
|---|---|
| 最新节点时间、中心位置 | 直接支持：`datas.time_ymdh`、`lat`、`lon` |
| 风速风力、中心气压、移速移向 | 直接支持：`wind_speed_ms`、`intensity_text`、`pressure_hpa`、`move_speed_kmh`、`move_dir_text` |
| 各级风圈和四象限半径 | 直接支持：`wind_radius` 及 `ne/se/sw/nw_radius_km` |
| 中心点悬停完整弹窗 | 应用层实现 |
| 风圈区域悬停弹窗 | 应用层实现 |
| 参考位置官方原文 | APIHz 文档未确认 |
| 参考位置距离和方向 | V1 不计算；API 无官方原文时显示“暂无参考位置” |
| 未来趋势原文 | 优先使用 `forecast_babj.forecast_desc`，真实字段内容需接入时确认 |
| 未来趋势结构化文案 | 应用层根据预测字段生成 |
| 缺失风圈等级显示 `--` | 应用层实现，不自行推算 |

## 11. 未来预测路线

### 11.1 数据来源和预测范围

V1 只展示 APIHz 台风接口提供的中国预测路线 `datas.forecast_babj[]`，不展示日本、中国台湾或美国预测路线。APIHz 文档和示例显示，预测节点可覆盖发布时刻之后最多 120 小时，即 5 天；例如发布为 8 月 1 日 23 时，最远预测节点可到 8 月 6 日 23 时。

120 小时是当前文档示例能确认的预测范围，不在需求中承诺每次响应永远返回 120 小时。实际展示范围以本次接口响应中 `forecast_hour` 的最大值为准：

- 最大值为 120：展示到 120 小时；
- 最大值小于 120：只展示 API 实际返回的范围；
- 不自行补足到 120 小时；
- 不根据历史路径或首尾点自行推算更远预测。

### 11.2 API 直接提供预测节点

未来预测点由 API 直接提供，应用层不负责生成未来位置、风速、气压或强度。`forecast_babj[]` 每个元素对应一个预测节点，包含：

```text
forecast_hour        未来第几小时
lat                  预测纬度
lon                  预测经度
position_text        预测位置
target_time_ymdh     API 时间字段
pressure_hpa         预测气压
wind_speed_ms        预测风速
intensity_code       预测强度代码
intensity_text       预测强度名称
forecast_desc        预测描述
```

前端按 `forecast_hour` 升序排序（若时效相同则保留 API 顺序），保留本次响应返回的全部预测节点，并依次连接形成一条预测路线：

```text
最新实际点
   │
   └── 虚线 → 12小时预测点
                 │
                 └── 虚线 → 24小时预测点
                               │
                               └── 虚线 → 后续 API 预测点
```

### 11.3 中间节点不自行插值

API 返回多少预测节点就展示多少预测节点。若响应包含 12、24、36、48、60、72、84、96、108、120 小时节点，全部保留；若只包含 12、24、48、72 小时，也只展示这些节点。

允许连接相邻 API 节点形成路线，但不允许：

- 只保留首尾点；
- 删除 API 已返回的中间节点；
- 自行补充 API 未返回的 18、36、60 等业务预测点；
- 对中间位置、风速、气压或强度做业务插值；
- 将插值结果冒充 API 预测节点。

V1 不做预测路径平滑或业务插值。地图线段直接连接相邻 API 原始节点。

### 11.4 预测点颜色和大小

预测点使用自身 `forecast_babj.wind_speed_ms`，沿用历史路径点同一套固定风速映射：

| 风速范围 | 颜色 | 点直径 |
|---:|---|---:|
| `< 17.2 m/s` | `#14B8A6` | 5px |
| `17.2–24.4 m/s` | `#3B82F6` | 6px |
| `24.5–32.6 m/s` | `#FACC15` | 7px |
| `32.7–41.4 m/s` | `#F97316` | 8px |
| `41.5–50.9 m/s` | `#E879F9` | 9px |
| `≥ 51.0 m/s` | `#EF4444` | 10px |

- 预测点统一使用 `#334155`、1px 边框；
- 预测路径使用虚线，历史实际路径使用实线；
- 颜色和点大小表达该节点的预测风速/强度，虚线和实线表达预测/实际状态；
- 预测点不使用当前实际风速统一渲染，也不使用历史点风速代替。

### 11.5 预测路线单次快照与重新加载

每次进入灾害风险模式或按 `F5` 重新加载并成功获取 `forecast_babj[]` 时，将其视为一整套最新预测快照。当前模式会话内不自动刷新；重新加载时，使用新快照整体替换上一版预测路线：

```text
获取新 forecast_babj[]
    ↓
校验完整数据
    ↓
按本次响应整体生成新预测点和路线
    ↓
一次性替换旧预测图层和详情数据
```

新旧发布之间以下字段均可能变化：

- 预测点数量；
- 预测时效和最远时间；
- 预测位置；
- 预测风速；
- 预测气压；
- 预测风力和强度；
- 预测描述；
- 预测路线形状；
- 预测点颜色和直径。

因此不得把两次发布的节点合并，也不得只更新部分字段。重新加载失败时不得渲染部分新预测数据；仅当当前页面内存仍持有上一版完整预测快照时，继续显示并标识为旧数据。按 `F5` 后不承诺保留刷新前的内存快照。

### 11.6 重新加载后预测节点转为实际节点

当前模式会话内不自动刷新。重新进入灾害风险模式或按 `F5` 加载后，当新的 `datas[]` 已返回对应实际观测节点时，使用实际数据替换上一版预测数据：

- 位置使用 `datas.lat/lon`；
- 风速使用 `datas.wind_speed_ms`；
- 气压使用 `datas.pressure_hpa`；
- 强度使用 `datas.intensity_code`、`datas.intensity_text`；
- 颜色和点直径按实际风速重新计算；
- 路径由虚线切换为实线；
- 旧预测值不保留在当前实时路径中。

### 11.7 时间字段边界

API 文档把 `target_time_ymdh` 定义为“时间段时间”，公开示例中多个预测节点可能出现相同值，因此 V1 以 `forecast_hour` 作为主要预测时效展示字段，例如“12 小时后”“24 小时后”。`target_time_ymdh` 作为原始字段保存，接入真实接口后再确认其究竟是预报发布时间、起报时间还是预测有效时间；确认前不得单独把它当作预测有效时间。

API 未提供预测算法、轨迹推算公式或预测误差计算方法；应用层只读取 API 节点、排序、连接和渲染，不自行生成业务预测结果。

## 12. 台风功能状态

进入灾害风险模式后，“地块工具”入口为禁用状态；退出灾害风险模式后恢复可用。

台风查看至少区分：

1. 未打开灾害风险工具；
2. 加载实时台风；
3. 存在一个活动台风；
4. 存在多个活动台风；
5. 当前无活动台风；
6. 查看历史台风；
7. 已选中台风；
8. 数据加载异常（V1 仅保留状态占位，真实 API 接入后专项定义失败与重试细节）。

实时台风与历史台风的路径、状态文案和数据来源必须明确区分。

## 13. V1 验收标准

1. 右下角存在“灾害风险”入口；点击只展开子菜单，不切换模式；点击“查看台风”后才进入灾害风险模式、切换到浙江省省级状态并加载台风数据；“查看天气”保留规划位置但不实现具体功能。
2. 存在未保存地块或种植档案操作时，灾害风险入口不可点击；进入灾害模式后隐藏地块图层并关闭地块详情、种植档案和保单抽屉，退出后不自动恢复。
3. 台风路径面板关闭按钮执行统一退出：清除全部台风专题图层、列表选中状态和时间轴抽屉状态；行政状态保持省级，地图保留退出瞬间的中心点和缩放级别。
4. 点击“查看台风”后，行政状态和面包屑切换到浙江省省级，只更新省级行政图层，不移动地图中心，并把默认缩放级别设为 z=4.5。存在活动台风时直接把默认选中的最新实时台风之最新观测节点放到地图画布几何中心，缩放保持 z=4.5；其他实时台风继续显示但不参与首次居中计算。不存在活动台风时保持进入流程时的地图中心和 z=4.5。首次视角完成后可继续缩放和平移；地图全局最小缩放为 z=3.5，可放大，也可缩小到 z=3.5。全部活动台风按北京时间最新节点倒序排列，默认选中并展开最新的一条，其他实时台风路径、中心点和最新风圈继续显示。
5. 每个已展示台风独立展示实际历史路径和当前/选中实际点；实时台风展示 API 返回的预测路径和最新节点风圈；历史台风只在选中节点实际返回 `wind_radius[]` 时展示该节点风圈，只在数据源明确提供对应历史版本时展示历史预测路径。选择某台风或时间节点只改变对应详情和高亮，不隐藏其他台风。
6. 当前没有活动台风时默认显示“当前无活动台风”，右侧列表和历史时间轴隐藏；点击页面底部“查看历史台风”按钮后只展开时间轴，不自动打开历史台风。
7. 历史台风只查看当前自然年度，查询 `year=当前年份`；时间轴从当年 1 月 1 日延伸至当前时间，不合并前一年数据，也不使用滚动 365 天。
8. 所有时间按北京时间 UTC+8 解释；历史时间轴只展示当前自然年度内存在台风节点的月份，空月份不显示；有数据月份等宽，月内按日期比例定位。标签起止位置按压缩时间轴坐标映射，不要求跨月份后的像素长度与真实持续小时数保持全局严格比例。跨年标签裁剪到当前年度，打开后列表和地图展示完整 `datas[]`。
9. 历史时间轴默认隐藏；页面底部按钮控制抽屉自下而上展开和自上而下收回；抽屉关闭时不能操作历史标签，收回抽屉不关闭已打开历史台风；当前年度无历史台风时按钮仍可用，抽屉显示“当前年度暂无历史台风”。
10. 点击历史台风时间轴标签后，以每 300ms 一个节点自动播放完整 `datas[]`；不提供暂停、继续或重播按钮。点击节点、关闭台风或退出模式立即停止；系统减少动态效果时直接显示完整路径。
11. 动画结束后保留完整历史路径，并默认显示最后一个节点的风圈和详情；列表节点点击只切换节点高亮、该节点风圈和详情，不播放动画，并只平移保证节点可见，不改变当前缩放级别。
12. 右上角列表展示全部 `type=start` 实时台风和已通过时间轴打开的 `type=stop` 历史台风；实时台风在前且不显示删除/关闭控件，历史台风按本次打开顺序排列；关闭后重新打开的历史台风排到末尾。
13. 再次点击已打开历史台风的时间轴标签，或点击该台风标题行的关闭图标，关闭该台风并清除其路径、节点高亮、风圈和详情；其他台风不受影响，时间轴标签保留且只能通过时间轴重新打开。
14. 地图最多展示 6 条台风；实时台风优先。实时台风达到或超过 6 条时历史标签保留但不可打开并显示“实时台风数量已达展示上限”；实时台风超过 6 条时全部保留。
15. 实时台风展开后只显示 `datas[]` 历史节点；历史台风展开后显示全部 `datas[]` 节点；节点按时间倒序、最新在前，节点很多时列表内部滚动，不抽稀、不合并。
16. 所有历史路径点按自身 `wind_speed_ms` 使用文档固定颜色、直径和统一边框；缺失风速不猜测、不降级；多台风路径重叠时不平移、不删除、不合并。
17. 点击任意实际节点后，完整实际路径保持显示，选中节点高亮，只显示该节点实际返回的 `wind_radius[]`；其他时间节点风圈隐藏，缺失风圈时显示暂无数据，不借用、不推算。
18. 24/48 小时定位警戒线作为灾害风险模式全局静态图层始终只绘制一组，不按台风重复创建；使用文档固定坐标，24 小时为黄色实线，48 小时为蓝色虚线，均有纵向文字标注且不填充。
19. V1 只展示 APIHz `forecast_babj[]` 中国预测路线；展示 API 返回的全部节点，最远范围以本次 `forecast_hour` 最大值为准，不补足、不插值；预测点按自身预测风速着色，预测路径虚线、实际路径实线。
20. 当前模式会话使用单次数据快照，不自动刷新、不提供手动刷新按钮；重新进入模式或按 `F5` 后只在新预测数据完整校验通过时整体替换预测路线，已有实际 `datas[]` 时用实际节点替换预测节点；不得渲染部分新预测数据或混合新旧节点。
21. APIHz 凭据只由本仓独立 Node 服务从未提交的服务端环境变量读取；前端只调用本站代理。代理校验上游 HTTP 状态和基本结构、统一错误响应，成功数据基本保持 APIHz 原字段结构；仓库不记录真实凭据。
