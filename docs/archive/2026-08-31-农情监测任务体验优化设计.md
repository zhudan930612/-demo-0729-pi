# 农情监测任务体验优化设计

## 目标

在不改变农情监测任务数据、任务状态流转、派发、定位和影像链路的前提下，统一右侧任务列表、全量任务抽屉与任务详情的信息层级和视觉反馈，使其成为受灾预警任务体验的稳定参考。

## 范围与边界

### 本次范围

- 优化右侧「任务列表」的标题、状态筛选、任务行层级、空态与「查看全部任务」入口。
- 优化「查看全部任务」抽屉的表格默认态、统计筛选、搜索、分页、选中反馈及表头滚动行为。
- 统一主面板任务详情与抽屉右侧详情的字段顺序、状态样式、定位行、处置说明和影像资料样式。

### 不在范围

- 不新增任务状态、审批流、批量操作或后端接口。
- 不改任务生成、状态流转、地图定位和影像数据逻辑。
- 不将全量任务默认态改为卡片流；默认态保持任务表格，选中任务后再进入左卡片/右详情双栏。

## 交互与布局

### 右侧任务列表

- 标题显示「任务列表 · 共 N 项」，右侧提供「查看全部任务」。
- 状态筛选保持待下发、待领取、进行中、已完成四态，并显示各状态数量；状态筛选变更时只过滤当前列表。
- 任务行固定三层：任务编号与状态、任务名称、任务类型/村/创建时间。
- 默认展示最近 10 条任务；空态显示「暂无任务」。

### 全量任务抽屉

默认态为「统计筛选 → 搜索 → 任务表格 → 分页」：

| 列 | 规则 |
|---|---|
| 序号 | 固定窄列，按当前页计算。 |
| 任务编号 | 固定宽度，等宽数字。 |
| 任务名称 | 自适应主列。 |
| 类型 | 固定宽度。 |
| 状态 | 固定宽度，语义徽标。 |
| 村 | 固定宽度。 |
| 创建时间 | 固定宽度，等宽数字。 |

- 统计项为总任务、待下发、待领取、进行中、已完成；点击后筛选并回到第一页。
- 搜索覆盖任务名称、任务编号和村名；无结果时在表格区域展示空态。
- 表头在表格滚动时固定，任务行悬停使用浅青色；点击行后保留抽屉，进入双栏详情态。
- 双栏态左侧为任务卡片并高亮当前任务，右侧为详情；返回后恢复原先的筛选、搜索和页码。

### 任务详情

主面板详情和抽屉详情使用一致的字段顺序：

1. 基础信息：状态、任务类型、任务描述、关联保单、任务定位、创建时间、执行人。
2. 处置说明：SOP 动作、执行要求。
3. 影像资料：提交时间、缩略图或明确空态。

- 详情标题固定在滚动区域顶部，主体内容单独滚动。
- 状态徽标、字段标签宽度、影像缩略图比例和空态文案在两个入口一致。
- 任务定位按钮及其地图联动保持现有行为。

## 验收标准

1. 右侧任务列表可在不展开详情的情况下辨识任务编号、名称、状态、村和创建时间。
2. 全量任务默认态为表格，表头固定；一页目标展示约 12 条任务。
3. 筛选、搜索、分页后选择任务，返回列表时上述上下文不丢失。
4. 主面板详情和抽屉详情字段顺序、状态样式、影像空态一致。
5. 既有派发、状态流转、地图定位、影像查看的自动化回归通过。
