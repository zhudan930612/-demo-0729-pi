# 受灾预警任务列表与全量任务对齐 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将受灾预警任务列表和全量任务抽屉的默认阅读结构对齐农情监测，同时保留现有双栏详情与受灾预警专属字段。

**Architecture:** 改动集中在 `DisasterWarningPanel.vue`：右侧任务列表增加顶栏和数量，抽屉根据 `drawerTaskId` 在默认表格与既有双栏详情之间切换。任务数据、状态和抽屉状态仍由现有 store 持有，组件只增加展示计算与局部渲染状态；Playwright 从用户实际派发流程验证新结构。

**Tech Stack:** Vue 3 `<script setup>`、TypeScript、CSS、Playwright、Vitest、Vite。

```vue
<template v-if="!drawerTask">
  <div class="dw-task-drawer-tools"><input v-model.trim="taskQuery" type="search" placeholder="搜索任务名称或村" /></div>

          <td>{{ task.taskNo }}</td><td>{{ task.name }}</td><td>{{ task.typeName }}</td>
```
