# 农情监测任务体验优化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 统一农情监测右侧任务列表、全量任务抽屉与任务详情的信息层级和视觉反馈，同时保持既有数据与交互链路不变。

**Architecture:** 修改限定在 `AgriTasks.vue`：以现有 `allTasks`、`filteredTasks`、`visibleTask` 与 `drawerTask` 为唯一数据来源，新增只读统计展示与可测试的语义标识，不新建接口或存储状态。默认全量任务仍为表格，选中任务后保留左卡片/右详情的双栏结构。

**Tech Stack:** Vue 3 Composition API、TypeScript、Pinia、Playwright、Vitest。

### Task 2: 优化右侧任务列表与全量任务默认表格

**Files:**

- Modify: `web/src/components/agri-monitoring/AgriTasks.vue`

- [x] **Step 1: 补齐右侧列表统计与任务行层级**

  使用现有 `filteredTasks` 按状态计算数量，在标题显示总数；状态筛选按钮显示 `状态 · 数量`。任务行保持既有数据但明确三层：编号/状态、名称、类型/村/创建时间。

  ```vue
  <div class="tasks-head">
    <span class="list-caption">任务列表 <b>{{ filteredTasks.length }}</b></span>
    <button type="button" class="view-top" @click="showAll = true">查看全部任务</button>
  </div>
  <button v-for="s in statusFilters" :key="s" type="button" class="sf-item">
    {{ s }}<strong>{{ listStatusCount(s) }}</strong>
  </button>
  ```

- [x] **Step 2: 优化默认表格可扫读性**

  保留七列和现有字段。表头设置粘性定位，固定序号、编号、类型、状态、村、时间列，任务名称占余下宽度；行悬停使用 `#ecfeff`，每页以 `ResizeObserver` 计算的可见行数为准，且至少为 2 行。

  ```css
  .task-drawer-list thead { position: sticky; top: 0; z-index: 1; background: #f8fafc; }
  .task-drawer-list th { color: #334155; font-weight: 700; }
  .task-drawer-list .t-no { width: 42px; }
  .task-drawer-list .t-time { width: 150px; }
  ```

- [x] **Step 3: 保持筛选、搜索和分页上下文**

  不在 `selectFromDrawer`、`closeDrawerDetail` 或关闭详情后重置 `query`、`drawerStatus` 和 `page`。仅在搜索或统计筛选变化时将页码重置为 1；保留既有 `ResizeObserver` 以适应表格和双栏态高度。
