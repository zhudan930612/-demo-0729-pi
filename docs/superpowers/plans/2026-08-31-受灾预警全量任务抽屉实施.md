# 受灾预警全量任务抽屉 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让受灾预警「查看全部任务」抽屉与农情监测任务抽屉使用一致的双栏视觉和交互结构。

**Architecture:** 仅在 `DisasterWarningPanel.vue` 扩展抽屉局部状态和模板，不改变 Pinia 任务数据与派发接口。抽屉复用农情监测的统计筛选、搜索、分页、左侧卡片与右侧详情结构；详情沿用受灾预警专有字段与证据展示。

**Tech Stack:** Vue 3 Composition API、TypeScript、Pinia、Vitest、Playwright。
