# 受灾预警村定位与演示任务状态 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复预警村卡片定位，并让一键派发在风险节点展示稳定的进行中、已完成演示任务及资料。

**Architecture:** 村级定位在灾害模式 composable 中加载既有乡镇村界文件，把真实几何写入完整下钻路径。任务对象仍由 Pinia store 创建；一键派发再调用 store 级状态设定方法，令主面板与抽屉复用同一份完成记录和影像数据。

**Tech Stack:** Vue 3、TypeScript、Pinia、Leaflet、Vitest、Playwright。

async function loadVillageGeometry(townshipCode: string, villageCode: string): Promise<Geometry | null> {
  try {
    const fc = await fetchJSON<FeatureCollection>(`/data/villages/${townshipCode}.geojson`)
    return fc.features.find((feature) => String(feature.properties?.code) === villageCode)?.geometry ?? null

}

```ts
applyDemoTaskState(taskId: string, status: Exclude<DisasterTaskStatus, '待领取'>, time: string) {
  const task = this.tasks.find((item) => item.id === taskId)
  if (!task || task.status === '已完成') return
  task.status = status
  if (status === '进行中') {
    task.history = [...task.history, { time, text: '任务进行中（演示）' }]
    return
  }
  task.history = [...task.history, { time, text: '任务完成（演示证据已挂载）' }]
  task.evidence = [
    { url: '/data/agri/evidence/img_001.jpg', time: `${time} 现场取证` },
    { url: '/data/agri/evidence/img_002.jpg', time: `${time} 现场取证` },
  ]
}
```

自然播放继续使用现有 `advanceTaskStatuses`；其“已完成即跳过”保护不得删除。

function demoStateOf(index: number, total: number): '待领取' | '进行中' | '已完成' {
