# 受灾预警任务列表与全量任务对齐设计

## 目标

在不改变受灾预警任务的生成、状态流转、地图定位、预警等级和影像资料逻辑的前提下，使其右侧「任务列表」与「查看全部任务」抽屉的默认阅读结构对齐农情监测模块，补齐标题、统计、入口和表格表头。

## 范围与边界

### 本次范围

- 优化受灾预警右侧「任务列表」顶栏：显示「任务列表 · 共 N 项」、各状态数量和顶栏「查看全部任务」入口。
- 优化受灾预警「查看全部任务」抽屉默认态：统计筛选、搜索、任务表格和分页。
- 保留抽屉任务详情：点击默认表格行后进入左侧任务卡片、右侧详情的双栏态；返回后回到原表格上下文。
- 补充自动化测试，覆盖顶栏入口、默认表格列、详情切换和返回。

### 不在范围

- 不改变任务数据、任务编号规则、任务状态、派发方式、状态流转或后端接口。
- 不为受灾预警新增农情监测特有的「待下发」状态。
- 不改变详情中预警等级、关联预警解除提示、处置说明、变化记录和影像资料。

## 交互与布局

### 右侧任务列表

- 顶栏左侧显示「任务列表 · 共 N 项」，其中 N 为当前状态筛选下的任务数；右侧为「查看全部任务」。
- 状态筛选保留「全部 / 待领取 / 进行中 / 已完成」，并显示每项数量；切换筛选后只影响当前列表与标题数字。
- 任务行和现有详情保持不变，仍显示预警等级色点与关联预警解除提示。
- 删除列表底部重复的「查看全部任务」入口；无任务时保持原空态。

### 全量任务抽屉

默认态按以下顺序展示：统计筛选 → 搜索 → 任务表格 → 分页。

| 列 | 规则 |
|---|---|
| 序号 | 当前页内的连续编号。 |
| 任务编号 | 显示 YJ 业务域编号。 |
| 任务名称 | 主列，显示完整任务名称。 |
| 类型 | 显示任务类型。 |
| 状态 | 使用现有语义状态徽标。 |
| 村 | 显示关联村。 |
| 创建时间 | 显示既有创建时间。 |

- 顶部统计保持受灾预警实际状态：总任务、待领取、进行中、已完成；点击统计项会应用筛选并回到第一页。
- 搜索覆盖任务名称和村名，沿用现有搜索语义；无结果时显示空态。
- 默认单页展示目标为约 12 条任务；表头在任务区域滚动时固定。
- 点击表格任一行后，抽屉不关闭，切换为既有的「左侧任务卡片 + 右侧详情」双栏态。
- 详情的返回按钮恢复表格默认态，保留搜索关键词、状态筛选和页码。

### 详情边界

详情继续承载受灾预警特有字段：预警等级、关联预警解除提示、处置说明、变化记录和影像资料。上述字段不进入默认表格，避免表格列过多并保持与农情监测的默认阅读密度一致。

## 验收标准

1. 任务列表顶栏同时可见标题、当前数量、状态数量和「查看全部任务」入口。
2. 全量任务首次打开即展示七列表格，表头含序号、任务编号、任务名称、类型、状态、村和创建时间。
3. 搜索、统计筛选和分页仍可用；默认表格每页约展示 12 条任务。
4. 点击表格行后打开双栏详情，详情字段不丢失；返回后表格的筛选、搜索与页码不丢失。
5. 任务生成、派发、状态流转、地图定位和影像查看的现有行为不回归。
