## 1. 目标与产品定位

在"查看降水"（V1，已实现）基础上，实现**参保区域灾害前预防闭环**：用户进"查看降水"看到的不只是降水热力图，而是**参保村当前预报窗口的风险等级**（综合降水、台风、预警三源信号）与**对应防灾措施建议**，支撑灾害前预防与减损调度。

**业务口径（2026-08-10 用户明确）**：再次查看村子的降雨量数字意义不大；农险场景要看"**当前这个地方存在什么风险、应采取什么措施**"，才能灾害前预防、降低理赔。

粒度决策（用户确认）：**以村为单位**；地块级（4500+ 参保地块逐个描边）不符合业务实际，不做。

## 2. 范围

### 2.1 做

- **参保村风险标注**：13 个参保村高亮，高亮颜色 = **风险等级色**（灰/绿/黄/红四档），地图上 13 村风险分布一眼可见；
- **村级风险判定**：三源综合——降水（7 天峰值 + 连续降雨信号）+ 台风（上游预报覆盖时长内路径 + 实时风圈）+ 该村所属区县当前生效气象预警（详见 §3）；
- **风险等级四档**：无风险 / 低 / 中 / 高（灰 / 绿 / 黄 / 红）；
- **点击参保村 → 风险卡片**：村名 + 风险等级 + 风险依据 + 防灾措施清单 + "查看 7 天降水趋势"展开项；
- **入口形态**：查看降水的增强，进入自动叠加、退出全清；
- **显示层级**：乡镇级起显（乡镇级=村标记，村级=村高亮，省市不显示）；
- **防灾措施**：按双季连作生育期阶段取标准化措施（内容见 §5）。

### 2.2 明确不做

- 不做地块级标注/描边；
- 不做未参保地块、未参保村的标识；不区分参保强度（13 村比例约 90%，有参保即标）；
- 不做保单详情、地块详情的联动（不进保单抽屉）；
- **不做自动处置结论、风险评分/灾损概率/赔付金额计算**（遵守 PRODUCT.md 边界）：风险等级由固定规则映射得出，措施为标准建议文本，卡片标注参考性质；
- 不做历史台风参与定级（历史只影响过去）；
- **不做超出上游数据能力的判定**：台风预报只用上游实际返回的 forecast 时长（通常 72h 左右，以数据实测为准），不虚构 7 天台风预报；预报点无风圈字段，风圈只对实时路径判定；
- 不改变降水 V1 已定稿的 19 条验收行为（色斑、时间轴、播放、可见度、悬停浮窗、互斥、三锁等沿用）；
- 不新增服务端数据源：三源数据均为现有接口/快照，村级计算前端完成（若实施中性能不可控再评估服务端预计算，不作默认路径）。

## 3. 村级风险判定规则

### 3.1 三源信号

| 信号源 | 参与方式 | 信号等级 |
|---|---|---|
| **降水**（7 天峰值 + 连续降雨） | 村级降水口径见 §3.3；**峰值信号** = 7 天窗口最大日降水；**连续降雨信号** = 7 天窗口内存在连续 3 日累计 ≥50mm（连阴雨/渍涝场景，2026-08-10 拷打后新增） | 峰值：0~24.9mm→0；25~49.9mm→1；50~99.9mm→2；≥100mm→3。连续降雨信号成立 → 峰值信号 +1（封顶 3） |
| **台风**（上游预报覆盖时长内路径 + 实时风圈） | 预报/实时预测点**点-线段距离**距村 ≤50km（预报点间隔大，点-点距离会漏判，用路径线段求最近距离）或**实时风圈覆盖** → 信号 2；**强热带风暴级及以上**（wind ≥24.5m/s 或强度文本强热带风暴以上）路径临近 → 信号 3；历史台风不参与 | 无影响→0；路径/风圈覆盖→2；强热带风暴及以上临近→3 |
| **预警**（NMC 浙江预警，按区县匹配） | 该村所属区县当前生效预警（村→区县用村码前 6 位推导，实施时核实），暴雨/台风/强对流类（具体类型清单实施时按 NMC 分类定稿） | 无→0；有相关预警→1（提级信号）；红色预警→直接 3 |

### 3.1b 风险等级定义（四档）

| 档 | 颜色 | 含义 |
|---|---|---|
| 无风险 | 灰 | 综合判定 0 |
| 低 | 绿 | 综合判定 1 |
| 中 | 黄 | 综合判定 2 |
| 高 | 红 | 综合判定 3 |

无风险村仍作为参保村参与标注（灰显），与不标注的未参保村/无数据村区分（图例见 §4.2）。

### 3.2 综合算法（单一算法，2026-08-10 拷打后定稿）

```text
P = 降水信号等级 0..3（峰值信号，连续降雨信号成立时 +1 封顶 3）
T = 台风信号等级 0..3
W = 预警提级信号 0 或 1（红色预警直接置 3 结束）

综合 = max(P, T)
若 W > 0：综合 = min(3, 综合 + 1)
若红色预警：综合 = 3
若 P ≥ 2 且 T ≥ 2：综合 = 3          # 暴雨 + 台风路径覆盖组合直接高（农险最危险组合）
封顶 3
```

- **台风不重复叠加**：台风已按强度定级（覆盖=2、强台风=3），不额外 +1（避免弱台风覆盖被双重提级）；
- **预警是独立提级信号**：任何相关预警使综合 +1（封顶 3）；红色预警直接 3；
- 算法以单测形式锁定（实施计划含全部组合用例），演示口径稳定不漂移；
- **时间维度：预报窗口峰值定级**——风险等级在数据快照有效期内固定，不随时间轴/播放变化；时间轴播放只驱动色斑与"7 天降水趋势"展开项。

### 3.3 村级降水数值口径（2026-08-10 拷打后修正）

- 村级降水取**村界覆盖的网格点值域**：村边界与 0.25° 网格求交，取覆盖到的全部网格点在 7 天各日的值；村级范围 = 覆盖网格点当日值的 min~max，均值 = 覆盖网格点当日值平均（不再用"参保地块质心插值"——一个村仅几 km²，全部地块质心大概率落同一网格点，范围退化，见拷打 C1）；
- 7 天峰值 = 7 天各日村级最大值（定级用，卡片显示其日期如"8/13"）；
- 趋势展开项显示逐日范围+均值（同一口径）。

### 3.4 数据源失败降级（2026-08-10 拷打后新增）

| 场景 | 行为 |
|---|---|
| 台风代理不可用/超时 | 用降水 + 预警判定，卡片风险依据区标注"台风数据暂不可用" |
| 预警快照失败/过期 | 用降水 + 台风判定，标注"预警数据暂不可用" |
| 降水快照 stale（V1 已有标注） | 用 stale 快照继续判定，标注沿用 V1 stale 文案 |
| 两源及以上不可用 | 可判定的单源照常显示；全部不可用 → 卡片显示"风险暂不可评定"（标注不显示） |
| 任一源恢复 | 下次刷新/进入自动恢复全源判定 |

- 降级不影响地图标注显隐（灰/绿/黄/红仍按可用源判定显示）；降级状态在卡片风险依据区呈现，不新增全局横幅。

## 4. 交互行为

### 4.1 入口与退出

- 查看天气 → 降雨量（沿用 V1）；进入即自动叠加 13 参保村风险标注；
- 退出（关闭面板/进入天气/最后一个活动模式退出）：标注、风险卡片、展开项、选中态全部清除；
- 播放中退出：先停止播放再清除（沿用 V1 第 17 条）。

### 4.2 风险标注

- 乡镇级起显：省市不显示，乡镇级显示参保村标记，村级显示村高亮（标记→高亮切换点实施时定稿）；
- **视觉（2026-08-10 确认）**：乡镇级=等级色圆点标记（白边，悬停显村名）；村级=村面淡色填充（等级色约 25% 透明度）+ 等级色描边 2px；颜色对照 DESIGN.md 令牌（红=danger-red/error-bg、黄=warning-yellow 系、绿=success-green/#dcfce7、灰=disabled-slate/#f1f5f9）；
- **图例（拷打后新增）**：进入降水且乡镇级及以上时，面板或角落显示最小图例：四档色块 + "未参保村不标注"说明，避免"灰显参保村"与"不标注未参保村"混淆；
- **事件穿透（拷打后新增）**：村级高亮填充层不得拦截地块点击（点村面仍可点到底下地块，点村高亮边界/标记才开卡片；实现上高亮 pane 置于地块 pane 之下或不拦截事件）；
- 悬停标注（标记/高亮）显示村名（不重复显示风险数值——数值在卡片里）；
- 风险等级为快照固定值，不随时间轴变化。

### 4.3 点击参保村 → 风险卡片

**卡片形态（2026-08-10 确认）**：360px 白色浮窗、3px 蓝实线边框（专题模式，沿用预警/台风浮窗模式）、**蓝底白字头部**（村名 + 等级徽标）、**贴村浮动**（优先停村右侧留 12px、空间不足切左侧，避让重叠；再点该村或点地图空白关闭）。

**卡片结构（自上而下）**：

```text
┌────────────────────────────────────┐
│ 清潭村                      [高风险] │ ← 蓝底白字头部：村名+等级徽标(pill)
├────────────────────────────────────┤
│ 风险等级                              │
│  ███ 高 · 大暴雨级                   │ ← 等级色块+大字（等宽数字）
│  预报窗口 7 天峰值 112mm（8/13）      │
├────────────────────────────────────┤
│ 风险依据                              │ ← 触发信号逐行，无信号不显示该行
│  降水   峰值 112mm（8/13 大暴雨）     │
│  降水   连续 3 日累计 58mm（8/10-12） │ ← 连阴雨信号（若有）
│  台风   'XX' 8/12 距村 40km（预报72h）│ ← 显示实际预报覆盖时长
│  预警   暴雨橙色预警生效              │
├────────────────────────────────────┤
│ 防灾措施 · 当前阶段：晚稻孕穗抽穗      │ ← 按 §5 双季连作取列
│  › 深水护稻、强台风前排水防倒          │
│  › 台风过后扶秧洗苗、补肥防病          │
│  › 加强巡查、关注预报更新             │
├────────────────────────────────────┤
│ ▸ 查看 7 天降水趋势            [展开] │ ← 默认收起
├────────────────────────────────────┤
│ 风险按预报窗口峰值定级，措施仅供参考，以官方发布为准 │
└────────────────────────────────────┘
```

- **等级徽标**：色底 pill + 色字（高=红、中=黄、低=绿、无=灰，复用 policy chip 形态）；
- **措施条目（2026-08-10 确认）**：▸ 单行列表；高/中风险最多 3 条，低/无风险 1~2 条；
- **数值规则**：卡内所有数值等宽数字（The Numbers Still Stay Rule）；
- **口径注记（拷打后新增）**：底部固定注记"风险按预报窗口峰值定级"——向用户解释徽标固定、趋势展开项随日期移动的原因（徽标=窗口固定值，柱状=逐日值）；
- 交互：再点该村收起/关闭；点地图空白关闭；键盘可操作（沿用无障碍约定）；
- 点击卡片不触发现有地块详情点击逻辑。

### 4.4 互斥与地块编辑

- 沿用 V1 全部互斥规则与地块编辑三锁；台风与降水可叠加（叠加时风险标注随降水保留）；
- 进入天气关闭降水（含风险标注与卡片）。

## 5. 水稻生长周期（双季连作）与防灾措施映射表

> **周期口径（2026-08-10 用户确认）**：双季连作模型——同一块田早稻种完收完才种晚稻，两季接力、时间上不交叉：**早稻 3~7 月 → 连作晚稻 7 月底~11 月**。浙江另有单季稻田块（5~11 月）并存，本口径**不建模单季稻**（简化，后续可扩展）。措施按生育阶段统一给出，当前日期 → 查周期表取在田阶段 → 取该阶段措施。

### 5.1 双季连作周期表（按月，无交叉）

| 月份 | 在田作物与阶段 |
|---|---|
| 3 月 | 早稻育秧播种期 |
| 4 月 | 早稻移栽返青期 |
| 5 月 | 早稻分蘖期 |
| 6 月 | 早稻拔节孕穗→抽穗期 |
| 7 月 | 早稻灌浆→收获期；月底连作晚稻移栽 |
| 8 月 | 晚稻分蘖→拔节孕穗期 |
| 9 月 | 晚稻孕穗抽穗期 |
| 10 月 | 晚稻灌浆成熟期 |
| 11 月 | 晚稻成熟收获期 |
| 12~2 月 | 冬闲期 |

- **在田判定**：每月一个在田阶段（无交叉），当前日期查表取当月阶段措施；7 月为过渡月（早稻收、晚稻栽，措施按当月两动作并集，实施时定稿具体条目）；
- 灾害敏感期：**抽穗扬花 > 灌浆成熟 ≈ 成熟收获 > 分蘖 > 苗期**（抽穗扬花遇暴雨/大风授粉受阻、结实率大降；灌浆遇台风倒伏穗发芽；收获遇连阴雨穗上霉变无法机收；分蘖遇洪水淹苗）。

### 5.2 降水风险措施（按生育阶段取列）

| 风险档 | 苗期/分蘖期 | 孕穗/抽穗扬花期 | 灌浆期 | 成熟收获期 |
|---|---|---|---|---|
| 无风险 | 常规田间管理 | 保持正常水层 | 正常管理 | 按计划安排收获 |
| 低 | 巡查排水沟 | 关注预报、备排涝 | 防倒伏巡查 | 关注收获窗口 |
| 中 | 疏通沟渠、预排降水位、防淹苗 | 深水护胎、强排水防倒、备抢收预案 | 强排降水位、加固防倒伏 | 成熟地块提前抢收 |
| 高 | 提前排水防淹、备补苗 | 优先保穗：排水防涝、大风后扶秧洗苗、雨后防稻瘟/纹枯 | 防倒伏为主，能收则抢收 | 连夜抢收、防穗发芽霉变、晒场/烘干安排 |

### 5.3 台风叠加措施（按生育阶段取列）

| 情形 | 苗期/分蘖期 | 孕穗/抽穗扬花期 | 灌浆期 | 成熟收获期 |
|---|---|---|---|---|
| 路径/风圈覆盖（中） | 加固大棚、转移棚内设备；秧田覆膜防冲刷 | 提前深水护稻、强台风前排水防倒 | 加固防倒伏、抢排积水 | 抢收、防穗发芽 |
| 强台风临近（高） | 以上全部 + 人员撤离低洼棚舍、物资转移、防海水倒灌（沿海村） | 以上全部 + 台风过后尽快扶秧洗苗补肥防病 | 以上全部 + 倒伏稻尽早收割止损 | 以上全部 + 收割机/烘干线调度预案 |

### 5.4 预警提级提示

- 区县生效暴雨/台风预警时卡片提示预警类型与等级（"当前暴雨橙色预警生效"），措施按对应风险档执行。

### 5.5 动态机制

- 以系统当前日期查 §5.1 周期表取当月在田阶段（无交叉）；措施取对应阶段列；
- 7 月过渡月（早稻收 + 晚稻栽）：措施按当月两动作并集（实施时定稿）；
- **冬闲期（拷打后定稿）**：12~2 月风险等级仍按三源正常判定（气象风险本身存在），但卡片显著标注"当前非水稻生长期（12~2 月）"，措施区显示"非水稻生长期，无田间措施建议"，风险等级徽标与依据照常显示（语义：提示气象风险，不关联作物）；
- 7 天窗口跨阶段边界时，措施按窗口内最敏感阶段取用，卡片可标注窗口跨阶段（如"9/28~10/4 跨晚稻灌浆→收获"）。

## 7. 验收标准（实施前定稿）

1. 进入"查看降水"：13 参保村自动叠加风险色标注（灰/绿/黄/红四档），退出后全部清除无残影；
2. 乡镇级起显：省市不显示，乡镇级村标记、村级村高亮，切换点稳定；**悬停标记/高亮显示村名**；图例显示四档 + 未参保村不标注说明，且**图例仅在乡镇级及以上显示**；
3. 风险等级=预报窗口固定值，切换日期/播放不改变标注颜色；色斑与趋势展开项仍随日期变化；卡片底部口径注记存在；
4. **综合算法单测**：覆盖峰值/连续降雨/台风覆盖/强台风/预警提级/红警/暴雨+台风组合/封顶，全部组合与 §3.2 一致；
5. 村级口径正确：村界覆盖网格取数，范围+均值与手算抽查一致（选 1~2 村抽样核对）；单网格村范围=单值可接受；**卡片峰值行显示对应日期（如"112mm（8/13）"）**；
6. 台风判定正确：点-线段距离用例（两预测点均 >50km 但路径线段穿过 ≤50km 判中）；**实时风圈覆盖用例判中**；预报覆盖时长显示实际值；
7. 连阴雨信号：构造连续 3 日累计 ≥50mm 用例，验证 +1 封顶；
8. 失败降级：台风代理不可用/预警失败/降水 stale 三种场景，风险依据区显示对应标注且用剩余源判定；全源不可用显示"风险暂不可评定"；**任一源恢复后下次刷新/进入自动恢复全源判定**；
9. 点击村弹风险卡片：村名、等级徽标、风险依据（含预警行"当前 XX 预警生效"）、措施清单（按当前生育期）、趋势展开项齐全；**卡片贴村停靠：右侧留 12px，右侧空间不足切左侧，不覆盖村标记**；**措施条数符合上限（高/中≤3，低/无 1~2）**；再点/点空白关闭；不触发地块详情；村高亮填充不拦截地块点击；
10. 措施映射表内容与 §5 固版一致；**月份→阶段→措施列映射正确（抽检 3/6/8/9/11 月各取对应阶段列）**；**窗口跨阶段时取最敏感阶段并标注（如"9/28~10/4 跨晚稻灌浆→收获"）**；12~2 月显示冬闲标注与"非水稻生长期"措施；
11. 无参保数据村不标注；**台风与降水叠加时风险标注随降水保留**；互斥/三锁/播放切模式（含播放中退出先停播放再清除）无回归（web test、build 全绿）；
12. 无障碍：新增对象（圆点标记、卡片、展开项）键盘可操作、读屏可识别，不以颜色为唯一反馈；
13. 服务端接口不变（若变更则单独验收）。
