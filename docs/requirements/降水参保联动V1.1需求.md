## 1. 目标与产品定位

实现**参保区域灾害前预防闭环**：用户点击"降雨量"，立刻看到**未来 7 天可能受灾的参保区域**（概览浮窗），并可**进入具体村查看风险与防灾措施建议**。核心回答保险业务的两个问题：**"未来 7 天哪些参保区域会受灾、影响多大承保责任"** 与 **"进了这个村该怎么防灾"**。

**业务口径（2026-08-10 用户明确）**：再次查看村子的降雨量数字意义不大；农险场景要看"**未来可能受灾的区域**"和"**进了村该采取什么措施**"，才能灾害前预防、降低理赔。

粒度决策（用户确认）：**以村为单位**；地块级（4500+ 参保地块逐个描边）不符合业务实际，不做。

## 2. 范围

### 2.1 做

- **入口交互（用户 2026-08-10 定稿）**：点击"查看天气 → 降雨量"→ 地图显示色斑（**保持 V1 现状：时间轴/播放/逐日切换保留，默认第 1 天；不与风险概览联动**）+ 13 参保村风险标注，同时**右上共用面板自动切到"风险概览"tab**；
- **共用面板 + tab（用户 2026-08-10 确认）**：右上角 390px 单一面板容器，两个 tab——**"台风路径"** 与 **"风险概览"**；跟随模式联动（进台风→台风 tab、进降水→风险 tab、两者同开→两 tab 并存默认显示后进入的模式；tab 手动切换不改变模式状态）；关闭按钮 = 退出当前 tab 对应模式（台风 tab 关闭=退台风，风险 tab 关闭=退降水）；
- **风险概览 tab 内容（统揽 7 天风险，用户确认）**：
  - 高风险/中风险参保村数量统计；
  - **受灾区域敞口统计**：受影响参保面积（亩）、保额（元）、户数（被保险人去重数），口径=高+中风险村合计（用户确认）；
  - **受灾区域列表**（按风险等级排序）：村名 + 风险徽标 + 面积 + 保额 + 户数，行可点击；
- **进入具体村（用户确认）**：点击列表行（或地图村标记/高亮）→ **下钻该村** + 打开**风险卡片**（风险依据 + 按双季连作生育期的防灾措施建议 + 7 天趋势展开项）；
- **村级风险判定**：三源综合——降水（7 天峰值 + 连续降雨信号）+ 台风（上游预报覆盖时长内路径 + 实时风圈）+ 该村所属区县当前生效气象预警（详见 §3）；
- **风险等级四档**：无风险 / 低 / 中 / 高（灰 / 绿 / 黄 / 红）；
- **显示层级**：乡镇级起显（乡镇级=村标记，村级=村高亮，省市不显示）；
- **防灾措施**：按双季连作生育期阶段取标准化措施（§5），卡片标注参考性质。

### 2.2 明确不做

- 不做地块级标注/描边；
- 不做未参保地块、未参保村的标识；不区分参保强度（13 村比例约 90%，有参保即标）；
- **不做被保险人触达清单**（姓名/电话清单本期不做，用户确认；仅统计户数）；
- 不做保单详情、地块详情的联动（不进保单抽屉）；
- **不做自动处置结论、风险评分/灾损概率/赔付金额计算**（遵守 PRODUCT.md 边界）：风险等级由固定规则映射得出，措施为标准建议文本；"受灾面积/保额/户数"是承保责任敞口统计（描述暴露，非赔付预测）；
- 不做历史台风参与定级（历史只影响过去）；
- **不做超出上游数据能力的判定**：台风预报只用上游实际返回的 forecast 时长（通常 72h 左右，以数据实测为准），不虚构 7 天台风预报；预报点无风圈字段，风圈只对实时路径判定；
- **降水面板保持 V1 现状**（时间轴/播放/逐日切换/可见度保留，色斑不与风险概览联动）；**台风+降水叠加 = 共用面板两 tab 并存**（无位置冲突，2026-08-10 tab 方案）；不新增服务端数据源：三源数据均为现有接口/快照，村级计算与保单汇总前端完成。

## 3. 村级风险判定规则（沿用 v2.7，已实施）

### 3.1 三源信号

| 信号源 | 参与方式 | 信号等级 |
|---|---|---|
| **降水**（7 天峰值 + 连续降雨） | 村级降水口径见 §3.3；**峰值信号** = 7 天窗口最大日降水；**连续降雨信号** = 7 天窗口内存在连续 3 日各有雨（≥0.1mm）且累计 ≥50mm（连阴雨/渍涝） | 峰值：0~24.9mm→0；25~49.9mm→1；50~99.9mm→2；≥100mm→3。连续降雨成立 → 峰值 +1（封顶 3） |
| **台风**（上游预报覆盖时长内路径 + 实时风圈） | 预报/实时预测点**点-线段距离**距村 ≤50km 或**实时风圈覆盖** → 2；**强热带风暴级及以上**（wind ≥24.5m/s 或强度文本）路径临近 → 3；历史不参与 | 无影响→0；路径/风圈覆盖→2；强台风临近→3 |
| **预警**（NMC 浙江预警，按区县匹配） | 村→区县 = 村码前 6 位；暴雨/台风/大风/雷电/冰雹类（RISK_RELEVANT_ALARM_EVENTS）提级 | 无→0；有相关→1；红色→直接 3 |

### 3.1b 风险等级定义（四档）

| 档 | 颜色 | 含义 |
|---|---|---|
| 无风险 | 灰 | 综合判定 0 |
| 低 | 绿 | 综合判定 1 |
| 中 | 黄 | 综合判定 2 |
| 高 | 红 | 综合判定 3 |

无风险村仍作为参保村参与标注（灰显），与不标注的未参保村/无数据村区分（图例见 §4.2）。

### 3.2 综合算法（单一算法，已实施）

```text
P = 降水信号 0..3；T = 台风信号 0..3；A = 预警信号 0/1/3（红警=3）
综合 = max(P, T)
若 A > 0：综合 = min(3, 综合 + 1)
若 A == 3：综合 = 3
若 P ≥ 2 且 T ≥ 2：综合 = 3          # 暴雨 × 台风覆盖组合直接高
封顶 3
```

- 台风不重复叠加（已按强度定级）；预警是独立提级信号；算法以单测锁定；
- **时间维度：预报窗口峰值定级**——风险等级在数据快照有效期内固定，不随 V1 时间轴日期切换/播放变化（色斑日期切换不影响风险等级）。

### 3.3 村级降水数值口径（已实施）

- 村级降水取**村界覆盖的网格点值域**（0.25° 网格与村界求交；单元关联保证小村 ≥1 点），min/max/mean；
- 7 天峰值 = 各日村级 max 的最大值（定级用，卡片显示日期）；
- 趋势展开项显示逐日范围+均值（浮窗/卡片内）。

### 3.4 数据源失败降级（已实施）

| 场景 | 行为 |
|---|---|
| 台风代理不可用 | 用降水+预警判定，卡片标注"台风数据暂不可用" |
| 预警失败/过期 | 用降水+台风判定，标注"预警数据暂不可用" |
| 降水 stale | 用 stale 快照判定，沿用 V1 stale 标注 |
| 两源及以上不可用 | 可判定单源照常；全不可用 → "风险暂不可评定" |
| 任一源恢复 | 下次刷新/进入自动恢复全源判定 |

- 降级不影响地图标注显隐；**保单数据加载失败分级处理（2026-08-10 拷打修正）**：单村保单文件失败 → 该村敞口显示 0/"—"（浮窗列表行与卡片保单概况），其余村不受影响；全部失败 → 浮窗统计区与卡片保单概况显示"保单数据暂不可用"，风险标注与判定不受影响。

## 4. 交互行为

### 4.1 入口与退出

- 查看天气 → 降雨量（沿用 V1 入口）；进入即：色斑（V1 现状）+ 13 村风险标注 + **共用面板切到"风险概览"tab**；
- 退出（关闭 tab 面板/进入天气/最后一个活动模式退出）：色斑、标注、tab、卡片、选中态全部清除；

### 4.2 风险标注（沿用 v2.7，已实施）

- 乡镇级起显：省市不显示，乡镇级村标记、村级村高亮；悬停显示村名；
- 视觉：乡镇级=等级色圆点标记（白边）；村级=村面淡色填充 + 等级色描边 2px；**当前下钻村保留原有黄色轮廓，不叠加风险描边**（2026-08-10 用户反馈修复）；
- 图例：乡镇级及以上显示（四档 + 未参保村不标注说明）；
- 事件穿透：村高亮填充不拦截地块点击。

### 4.3 共用面板与风险概览 tab

- **共用面板（用户 2026-08-10 确认）**：右上角 390px 单一面板（蓝实线边框专题容器，沿用台风面板规格），顶部 tab 栏：**台风路径** / **风险概览**；
- **tab 与模式联动**：进入台风模式 → 自动显示并激活"台风路径"tab（内容 = 现有台风路径面板完整搬入：台风卡片列表、蓝色头部、时间轴抽屉从底部展开、hover 浮窗，全部原样保留）；进入降水 → 激活"风险概览"tab；两者同开 → 两个 tab 并存，默认激活后进入的模式；手动点 tab 仅切换视图，不改变模式状态；
- **关闭按钮** = 退出当前激活 tab 对应的模式（台风 tab 激活时关闭=退台风；风险 tab 激活时关闭=退降水）；另一个模式单独退出时对应 tab 消失；
- **面板收起**：标题栏可点击收起为仅 tab 条（不退出模式），再次点击展开；村级视图时默认保留面板（可手动收起），风险卡片贴村打开且按既有避让规则不与面板重叠；
- **风险概览 tab 内容（自上而下）**：
  ```text
  ┌──────────────────────────────────────┐
  │ 未来 7 天受灾风险概览           ⟳ ✕ │ ← 蓝底头部：刷新 + 关闭(=退降水)
  ├──────────────────────────────────────┤
  │ 高风险区 4 村 · 中风险区 3 村        │ ← 统计（等宽数字）
  │ 受影响参保 2,860 亩                │
  │ 保额 ¥8,420万 · 213 户             │
  ├──────────────────────────────────────┤
  │ 受灾区域（点击进入村查看）           │ ← 列表行=峰值+敞口合并
  │ ● 清潭村  [高] 8/13 大暴雨 112mm   │
  │     640亩 · 保额¥1,890万 · 42户     │
  │ ● 大钱村  [高] 8/12 暴雨 98mm      │
  │     520亩 · 保额¥1,430万 · 35户     │
  │ ● 新三联村 [中] 8/13 大雨 45mm     │
  │     480亩 · 保额¥1,210万 · 28户     │
  │ （无高/中风险村时显示"未来 7 天无   │
  │   高风险参保区域"）                 │
  ├──────────────────────────────────────┤
  │ 降水预报数据 © Open-Meteo / ECMWF   │
  │ 台风按上游预报覆盖时长评估（约 72h）  │
  └──────────────────────────────────────┘
  ```
- **列表行 = 峰值说明 + 受灾敞口合并（用户 2026-08-10 确认）**：每村两行式：第一行村名 + 风险徽标 + **峰值（峰值日 M/D + 降雨类型 + 雨量，如"8/13 大暴雨 112mm"）**；第二行面积（亩）+ 保额 + 户数；排序：风险等级降序 → 面积降序；无信号村不进入列表（灰/绿不列，仅高+中）；
- **点击行 → 进入该村**：`store.drill` 下钻到该村（村级视图）+ 打开该村风险卡片（§4.5）；再点已选中行收起卡片；
- **色斑不联动**：风险 tab 任何操作（列表选择/刷新）不改变色斑日期与时间轴状态；
- **数据时间**：风险 tab 显示降水快照 `updatedAt`（动态数据时间）；保单为静态业务数据（fixture businessDate），不并入"数据时间"展示；
- **列表滚动**：tab 内容最大高度约 60vh，受灾区域列表超出后内部滚动；
- **无障碍**：tab 栏/列表行键盘可操作，统计数字读屏可读，不以颜色为唯一反馈。

### 4.4 色斑（保持 V1 现状，2026-08-10 用户确认）

- **色斑保持 V1 全部行为**：时间轴/播放/逐日切换/可见度滑动条均在 V1 降水面板（底部），默认第 1 天；不改为峰值日、不与概览浮窗联动；
- 色斑 pane、省界裁剪、hover 浮窗沿用 V1 实现；
- 峰值与峰值日信息由概览浮窗说明（§4.3），色斑不做峰值展示。

### 4.5 风险卡片（沿用 v2.7，已实施）

- 360px 白卡 + 3px 蓝边框 + 蓝底白字头部（村名 + 等级徽标）+ 贴村停靠（右侧 12px，不足切左）；
- 内容（自上而下）：
  1. **风险依据（等级并入依据区，2026-08-10 用户确认）**：首行为等级 + 峰值合并（如"高风险 · 8/13 大暴雨 112mm"），其后为非峰值信号行（连阴雨/台风/预警逐行，无信号不显示；峰值只出现一次）；
  2. **保单概况（用户 2026-08-10 确认）**：承保概况（参保面积、保额、**参保户数**）+ 保单结构（保单数、**大户 X + 清单户 Y** 并列）；保额保留展示（接受单价固定 1,250 元/亩，保额=保障中面积×单价）；保单数据加载失败 → 该区块"保单数据暂不可用"，风险/措施不受影响；
  3. **防灾措施**：当前生育期取列，▸ 单行，高/中≤3 条低/无 1~2；
  4. "查看 7 天降水趋势"展开项（默认收起）；
  5. 底部口径注记"风险按预报窗口峰值定级，措施仅供参考"；
- **卡片定位（用户 2026-08-10 确认 C4）**：固定弹窗（贴村停靠一次锚定，不随相机移动，沿用天气浮窗行为）；
- 冬闲期标注"非水稻生长期"；失败降级行（台风/预警/降水不可用）。

### 4.6 互斥与地块编辑

- 沿用 V1 互斥规则与地块编辑三锁；**台风与降水可叠加 = 共用面板两 tab 并存**（台风 tab + 风险 tab，无位置冲突）；天气与台风/降水互斥（进入天气关闭对应模式与 tab）；
- 关闭当前激活 tab = 退出对应模式；进入天气关闭降水（含风险 tab 与卡片）。

## 5. 双季连作周期与防灾措施（沿用 v2.7，已实施）

- **周期口径**：早稻 3~7 月 → 连作晚稻 7 月底~11 月，两季接力不交叉（不建模单季稻）；
- 月份→阶段映射：3/4/5 月苗期分蘖、6 月孕穗抽穗、7 月成熟收获（最敏感）、8 月苗期分蘖、9 月孕穗抽穗、10 月灌浆、11 月成熟收获、12~2 月冬闲；
- 降水措施表（4 档 × 4 阶段列）+ 台风叠加措施（路径/强台风 × 阶段）+ 条数上限 + 窗口跨阶段取最敏感并标注；
- 冬闲期措施"非水稻生长期，无田间措施建议"。

## 6. 数据依赖

| 数据 | 来源 | 用途 |
|---|---|---|
| 7 天降水网格 | 现有 `/api/precipitation-grid` 快照 | 村级峰值/连续降雨、色斑（V1 现状） |

## 7. 验收标准

1. 点击"降雨量"：色斑（V1 现状）+ 13 村风险标注 + **共用面板自动切到"风险概览"tab**；退出后全部清除无残影；
2. 风险概览 tab：高/中风险村数、受影响参保面积/保额/户数（高+中口径，**仅保障中保单覆盖**）正确，与自动化单测断言一致（选 1~2 村手算核对）；
3. 受灾区域列表：仅高/中风险村，按等级降序→面积降序，行含村名/徽标/面积/保额/户数；无高/中风险村时显示空态文案；
4. **列表行 = 峰值 + 敞口合并（用户确认）**：每村行显示峰值（峰值日 + 降雨类型 + 雨量，如"8/13 大暴雨 112mm"）+ 面积 + 保额 + 户数，与自动化单测断言一致；且**色斑不显示峰值日、不与风险 tab 联动**（操作 tab 不改变色斑日期/时间轴状态）；
5. 点击列表行：下钻该村（村级视图）+ 打开风险卡片（依据/措施/7 天趋势）；面板默认保留（可手动收起为 tab 条）；再点行收起；点地图空白关闭；
6. **风险等级并入风险依据（用户确认）**：卡片无独立风险等级区，依据区首行为"等级 · 峰值（如 高风险 · 8/13 大暴雨 112mm）"，峰值只出现一次，其后为非峰值信号行（连阴雨/台风/预警/不可用行）；
7. **保单概况区块（用户确认）**：位于风险依据后、措施前；显示承保概况（参保面积/保额/户数）与保单结构（保单数/大户数/清单户数），与自动化单测断言一致；保单数据加载失败 → 区块显示"保单数据暂不可用"，风险/依据/措施不受影响；
8. **共用面板与 tab（用户确认）**：右上 390px 单面板、tab 栏（台风路径/风险概览）；跟随模式联动（进台风→台风 tab、进降水→风险 tab、同开→两 tab 并存默认后进入）；手动切 tab 不改变模式状态；关闭=退当前 tab 对应模式；台风 tab 内容与既有台风路径面板一致（卡片列表/时间轴抽屉/hover 浮窗原样），无回归（沿用台风 e2e）；
9. 色斑 V1 行为无回归：时间轴 7 日期、播放循环、可见度滑块、逐日切换、hover 均正常（沿用 V1 验收）；
10. 三源判定正确（综合算法单测全组合，沿用 v2.7 验收 4）；连阴雨/台风点-线段/风圈/预警提级/红警/暴雨×台风组合用例通过；
11. 村级口径正确（村界覆盖网格，范围+均值抽查）；单网格村=单值可接受；
12. 失败降级：台风/预警/降水不可用 → 卡片标注 + 剩余源判定；全源不可用"风险暂不可评定"；**保单加载失败分级：单村失败该村"—"，全部失败显示"保单数据暂不可用"（风险标注不受影响）**；
13. 当前下钻村保留黄色轮廓不叠加风险描边；其余村风险描边/填充正常；村高亮填充不拦截地块点击；
14. 措施映射表与 §5 固版一致；月份→阶段→措施列抽检；窗口跨阶段标注；12~2 月冬闲标注；
15. 无参保数据村不标注；台风叠加时两 tab 并存；互斥/三锁无回归（web test、build、e2e 全绿）；
16. 无障碍：tab 栏/列表行/卡片键盘可操作、读屏可识别，不以颜色为唯一反馈；
17. 服务端接口不变（若变更则单独验收）。
