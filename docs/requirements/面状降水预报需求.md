# 农险双精准地图 Demo —— 面状降水预报需求

> 版本：v0.7（2026-08-10，定稿悬停浮窗：仅降雨程度 + 降水数值）
> 状态：数据源与分辨率已定稿（Open-Meteo ECMWF 0.25° 全省统一），交互已定稿，可进入开发
> 适用范围：右下角"灾害风险"工具内新增的"查看降水"子功能

---

## 1. 目标与事实依据

在现有"灾害风险"工具内，以**网格数据源 + 连续色斑热力呈现**提供浙江省**未来 7 天逐日降水预报**：地图底部时间轴展示 7 个日期，点击某日期查看该日累计降水场，支持播放（逐天自动切换），与现有五级行政下钻联动。呈现形态：连续色斑渐变、半透明可透出底图要素（参考图 2026-08-10 确认的中央气象台产品风格）。这是灾害风险"面状灾害"方向的第一项：`PRODUCT.md` 所列"面状暴雨/洪水/干旱专题"中，首期仅实现**暴雨/累计降雨（未来预报场）**，洪水、干旱、地震不纳入本期。

### 1.1 数据源选型（2026-08-10 已核实并实测）

经调研与实测，候选源结论如下：

| 候选源 | 结论 |
| --- | --- |
| **Open-Meteo（选定）** | 免费、无需 key、无需注册；单请求最多 1000 位置，浙江 0.25° 网格 399 点一次取回（实测）；ECMWF 底层模型；JSON 接口服务端直接 fetch，无 GRIB 解析工具链 |
| GFS / NOMADS | 备选。免费但需下载 GRIB2 并经 herbie/wgrib2 解析，服务器环境重；中国区域降水预报质量逊于 ECMWF |
| 中央气象台 5km QPF | 无公开接口；中国气象数据网需实名注册且仅 7 天试用，不满足长期内部演示 |
| nmc.cn 瓦片 | 未发现公开瓦片/API 文档，排除 |

### 1.2 Open-Meteo 事实依据（2026-08-10 实测）

- 接口：`GET https://api.open-meteo.com/v1/forecast`，纯 HTTP GET，返回 JSON；
- 多位置语法：`latitude=lat1,lat2,...&longitude=lon1,lon2,...` 按索引配对，单请求最多 1000 位置；
- **浙江网格实测**：范围 `118.0°E–123.0°E × 27.0°N–31.5°N`，步长 0.25° → 21×19 = **399 点**；单请求 `hourly=precipitation&forecast_days=1` 实测响应 **341 KB**；返回**数组**，每元素含 `latitude`、`longitude`、`hourly.time[]`、`hourly.precipitation[]`；
- **网格分布实测（2026-08-10，仓库省界求交）**：399 点中仅 **153 点落在浙江省界内**，246 点在省外（东海 34、福建 21、江西/安徽 44、太湖/江苏 21、包围盒内省界外海域与岛礁间隙 126）；省内网格经纬范围 118.25–121.75E × 27.25–31.0N；
- 降水变量：`precipitation`（雨+阵雨+雪总量，mm/小时累计）、`rain`、`showers`、`snowfall`（cm）、`precipitation_probability`（%）；
- **预报长度：默认未来 7 天逐小时，最长 16 天（`forecast_days` 0–16，`forecast_hours` 精确控制时次数）；小时序列从今日 0:00 起**；`timezone=Asia/Shanghai` 返回北京时间；
- 模型：ECMWF IFS 0.25°（全球约 25 km）是浙江可用的最佳免费分辨率；1–2 km 级区域高分辨率模式（AROME/HRRR 等）仅覆盖欧洲/美国；默认 `best_match` 为坐标自动选最高分辨率可用模型；
- **分辨率决策（2026-08-10 实测后定稿）**：曾评估“下钻更精细”（市级 GFS 0.117°/约 13 km，实测可用）与“全省统一 13 km”两条路线后放弃，**全省统一 ECMWF 0.25°（25 km）**，下钻保持统一分辨率、不更换数据源。放弃理由（实测依据）：① 全省 13 km 网格 1677 点超单请求 1000 上限，需 5 区分片拉取，连续请求触发 429 限流，首次加载约 15–30 秒；② 7 天全量约 10 MB 原始/gzip 约 2 MB，加载与缓存成本高；③ 省/市两级换源（ECMWF↔GFS）存在数据拼接不一致风险。统一 25 km 单请求秒级加载，数据一致；市级 25 km 网格约 6–29 点、县级约 1–3 点，插值平滑呈现，界面标注真实分辨率 25 km，不把插值冒充更细数据；
- 更新频率：ECMWF 每 6 小时新起报（00/06/12/18 UTC），Open-Meteo 吸收后按约 3–6 小时级刷新；
- **免费层限制**：600 次/分钟、5,000 次/小时、10,000 次/天、300,000 次/月；无 uptime 保证；非商业用途免费，商用需付费订阅；
- **许可**：天气数据 **CC BY 4.0**（使用须署名）；服务端代码 AGPLv3（调用托管 API 不受传染）；
- 条款：Open-Meteo 不对数据准确性、完整性与可用性作保证。

## 2. 范围与非目标

### 2.1 本期范围

1. 服务端新增降水预报网格代理：固定拉取浙江 0.25° 网格未来 7 天（168 小时）逐小时降水，服务端聚合为 **7 段日累计**（每段 24h），归一化缓存，前端只访问本站 `/api`；
2. 前端新增"查看降水"灾害查看子项：进入后按**连续色斑渐变**呈现浙江全省降水场，与五级行政下钻联动（下钻聚焦当前行政区域）；
3. **地图底部时间轴**：7 个日期（第 1 天～第 7 天，标注日期与星期），点击某日期即切换显示该日累计降水场；
4. **播放**：播放/暂停按钮，按固定间隔逐天自动切换日期（逐天动画）；
5. 色斑渲染：canvas 插值平滑 + 半透明叠加，可透出底图行政要素；色阶按中国气象局 24h 雨量等级标准（见 3.2）；
6. 与"查看台风""查看天气"互斥，沿用灾害风险模式生命周期（进入切回浙江省级、退出恢复）与地块编辑禁用规则；
7. 上游失败优雅降级：保留上次成功数据并标注，无数据时显示"降水预报暂不可用"，不白屏；
8. 数据来源署名与演示边界文案（CC BY 4.0 署名 + "预报场仅供参考"）。

### 2.2 明确不做

- 不做洪水、干旱、地震等面状灾害（本期仅累计降雨）；
- 不做"24/48/72 小时"累计下拉（已按用户指示改为 7 天逐日时间轴）；不做逐小时强度时间轴与逐小时动画（本期粒度固定为逐日，逐小时动画列为后续可选项）；
- 不接入中国气象数据网/中央气象台付费、实名试用或受限数据；
- 不做历史降水回放、降水实况（本期仅未来预报场）；
- 不把 0.25° 网格插值平滑后的视觉效果描述为真实更高分辨率，界面必须标注真实网格分辨率；
- 不把降水预报场描述为实测结果、定损依据或理赔依据；不自动转换为地块灾损、承保风险或查勘指令；
- 不与其他灾害图层叠加（本期单日单一图层）；
- 不改动现有"查看台风""查看天气"的入口、互斥规则与面板行为。

## 3. 用户界面与交互

### 3.1 入口与模式

- 右下角"灾害风险"菜单新增子项 **"查看降水"**，与"查看台风""查看天气"并列；三者互斥，同一时间只允许一个灾害查看子功能处于活动状态；
- 点击"查看降水"后进入降水查看模式：行政状态和面包屑切回浙江省省级，并将地图视角定位为浙江省全景（与台风模式不同：降水是全省面状色斑场，需要全省视角）；行政边界按现役下钻逻辑显示省级图层；
- 进入时立即关闭已打开的地块详情、种植档案、保单抽屉与天气/台风面板，取消任何地块编辑态；影像和地块图层开关保持不变；
- 地块处于筛选、绘制、批量编辑、修形或未保存种植档案状态时，沿用现有灾害风险入口禁用规则；
- 退出按钮关闭面板、色斑图层、选中日期、播放计时与请求计时，不改变退出瞬间的行政层级与地图视角。

### 3.2 色斑呈现与色阶

- 数据网格：ECMWF IFS 0.25°（约 25 km），浙江 399 点；
- 渲染：canvas 双线性插值将 0.25° 网格插值到约 0.05° 像素级平滑色斑，连续渐变、边界柔化，**半透明叠加**在天地图底图上，可透出省界、市界、地名与地块要素；插值仅为视觉平滑，不代表真实分辨率提升；
- **渲染范围（方案 A，2026-08-10 用户确认）**：省级视图渲染**整个 0.25° 矩形网格（399 点，含东海、邻省边缘）**，色斑连续不被省界切断，并叠加省界线保持浙江边界清晰（参考中央气象台产品惯例；全矩形渲染也为插值提供边缘点，避免省内 153 点边界插值伪影）；下钻后视口聚焦当前行政面、色斑连续不裁剪（见 3.3）；
- **可见度滑动条（2026-08-10 用户确认）**：面板内提供色斑**可见度（不透明度）滑动条**，范围 0–100%，拖动实时调节色斑图层透明度；**默认 60%**（半透明可见底图），拉至 0% 时色斑完全隐藏（仅保留底图、边界与地块），便于对照底图/参保地块查看；调节只改变图层整体透明度（不重绘、不影响播放与日期切换），退出模式不记忆个性化值（每次进入回到默认）；
- 色阶：按**中国气象局 24h 雨量等级标准**映射**当日累计降雨量**（7 段均为"24h 累计"口径，同一色阶保证跨日视觉可比，参考中央气象台产品色带，具体色值在实施计划定稿）：

| 当日累计降雨 | 等级 | 色带方向 |
| --- | --- | --- |
| < 0.1 mm | 无雨 | 透明 |
| 0.1–9.9 mm | 小雨 | 浅绿 |
| 10–24.9 mm | 中雨 | 绿→青绿 |
| 25–49.9 mm | 大雨 | 青蓝 |
| 50–99.9 mm | 暴雨 | 蓝 |
| 100–249.9 mm | 大暴雨 | 紫 |
| ≥ 250 mm | 特大暴雨 | 深紫/近黑 |

- 图例：面板内展示色阶图例条与分级刻度，标注"当日累计降雨量 mm"（参考图无图例，但内部演示必须有数值对应，避免误导）；
- **悬停浮窗（2026-08-10 用户定稿）**：鼠标悬停在地图上（色斑区域）时显示小浮窗，**仅两项内容**——① 降雨程度分级文字（按中国气象局 24h 雨量等级：无雨/小雨/中雨/大雨/暴雨/大暴雨/特大暴雨）；② 当日累计降水数值（如"24.6 mm"）。不显示行政地址、经纬度、日期标题、7 天一览或任何其他信息；浮窗跟随鼠标位置（偏移避让），离开色斑区域或移出地图即消失；数值由鼠标经纬度 → 最近网格点插值得到，0.25° 网格插值仅为示意；
- pane 层级：色斑属于面状底图性质，**低于天地图文字注记层级**（沿用现役约定，注记 `pane 450`，色斑 `pane` 低于 450；具体值在实现时与现有边界/影像 pane 协调，不得遮挡行政边界与地块）；
- 行政边界、影像、地块图层在降水查看模式下保持可加载、可开关、可查看详情；地块工具继续显示但编辑操作不可用（沿用台风模式规则）。

### 3.3 跟随行政区域联动

- 省级：渲染浙江全省 399 点矩形色斑场（含海域/邻省边缘，方案 A）+ 省界线叠加；
- **下钻统一（2026-08-10 用户定稿）**：下钻到市、县、乡、村保持与省级同一分辨率（ECMWF 0.25°/25 km），不更换数据源、不重新请求上游；色斑保持全矩形连续渲染（不被行政面硬切），地图视口聚焦当前行政区域，行政边界高亮叠加（方案 A'，参考中央气象台放大查看方式）；农险用户在任一层级看到的是统一分辨率的风险场，行政面高亮表明“我的参保区域落在哪个风险带”；
- 切换日期/层级不重新请求上游（数据已在服务端缓存为全省全 7 天网格，前端裁剪即可）；

### 3.4 地图底部时间轴与播放

- **时间轴位置**：浮在地图底部中央，雾白面板风格（沿用 `DESIGN.md` 的 `panel-slate`、细边框、紧凑间距、地图优先规则）；与面板图例同属降水查看模式的界面元素；
- **时间轴内容**：7 个日期标签，从当前整点小时起每 24h 为一天，标注日期与星期（如"8/10 周一"）；当前选中日期高亮；无滚动（7 项固定，窄屏等比压缩）；
- **点击交互**：点击某日期立即切换色斑为该日累计场，不重新请求上游；播放进行中点击日期则暂停并跳转到该日；
- **播放**：播放/暂停按钮；播放时按固定间隔（默认 1.2 秒/天，实施时定稿）逐天切换至第 7 天后自动停止回到播放暂停态；播放中禁止其他模式入口操作但地图缩放/平移保持可用；
- 日期标签与图例标注"当日累计降雨量"，第 1 天从当前整点小时起算（服务端聚合口径见 4.2），不得把今日已过时次计入累计。

### 3.5 数据标注与演示边界

- 面板内常驻标注：**"降水预报数据 © Open-Meteo / ECMWF（0.25° 网格，约 25 km）"**，满足 CC BY 4.0 署名要求；
- 面板内常驻提示：**"预报场仅供参考，不作定损依据"**（沿用天气模块的演示边界口径，见 `PRODUCT.md`）；
- 数据时间显示上游预报数据的发布时间或新鲜度，不得把点击刷新时间冒充上游数据时间（沿用天气需求口径）。

### 3.6 加载、刷新与异常

- 进入模式时显示加载态，保留进入前的地图状态；
- 面板提供手动刷新按钮：刷新尊重服务端缓存新鲜期，仅过新鲜期的缓存访问上游；刷新期间保留上次成功数据并显示"正在更新"，失败时保留旧数据并标注"更新失败，上次成功获取于 …"，不得先清空容器（沿用天气需求口径）；
- 上游超时、失败、结构异常：有缓存时返回缓存快照并标注数据时间；无缓存时显示"降水预报暂不可用"空状态，不降级成"无降水"误导；
- 首期不做自动定时刷新（预报场更新频率为小时级，进入取一次 + 手动刷新足够）。

## 4. 数据与服务端

### 4.1 上游请求（服务端固定拼装，浏览器不控制）

```text
GET https://api.open-meteo.com/v1/forecast
  ?latitude=<浙江 399 点纬度串>
  &longitude=<浙江 399 点经度串>
  &hourly=precipitation
  &forecast_hours=168
  &timezone=Asia/Shanghai
```

- 网格范围、步长、变量、预报时次数（168 = 7 天逐小时）均由服务端固定，浏览器不得修改；
- 只请求 `precipitation` 单变量；7 天原始响应约 2.3 MB，服务端归一化为紧凑结构（去掉逐点重复字段名）后预计约 0.5–1 MB，前端一次拉取可接受；若仍超标启用压缩传输（gzip/brotli）；
- 上游访问仅发生在 `server/`；前端只调用本站 `/api/precipitation-grid`。

### 4.2 归一化、聚合与缓存

- 服务端将上游数组归一化为单快照结构，并**聚合 7 段日累计**：

```jsonc
{
  "grid": [{ "lat": 27.0, "lon": 118.0, "values": { "d1": 12.4, "d2": 8.1, "d3": 0.0, "d4": 0.0, "d5": 3.5, "d6": 20.7, "d7": 6.2 } }, ...], // 399 点 × 7 日
  "days": ["2026-08-10", "2026-08-11", "2026-08-12", "2026-08-13", "2026-08-14", "2026-08-15", "2026-08-16"],
  "model": "ECMWF IFS 0.25°",
  "updatedAt": "2026-08-10T08:12:00+08:00", // 服务端快照时间（上游拉取时间）
  "aggregateFrom": "2026-08-10T08:00:00+08:00" // 第 1 天累计起算整点小时
}
```

- 聚合口径：**第 1 天 = 从当前整点小时起的未来 24 个逐小时 `precipitation` 求和；第 2 天 = 未来 25–48 小时求和；……第 7 天 = 未来 145–168 小时求和**；小时序列不足对应长度时（预报边界）按实际可得时次求和并在响应中标注实际覆盖天数，不得用 0 补足冒充完整 24h；
- 缓存新鲜期：默认 30 分钟（ECMWF 6 小时起报 + Open-Meteo 3–6 小时吸收，30 分钟足够覆盖进入模式的低频请求）；新鲜期内重复请求直接返回缓存；
- 手动刷新尊重新鲜期；缓存失效或刷新时合并同键在途请求，避免并发打上游（沿用天气模块缓存与合并规则）；
- 缓存键：固定全省网格为单一键（网格范围不随层级变化，层级聚焦由前端裁剪完成）；
- 错误边界：超时、响应过大、结构异常、上游 429/5xx 一律不向浏览器泄露原始错误，按 3.6 降级文案处理；日志不得包含任何凭据（Open-Meteo 无 key，但沿用统一脱敏边界）。

### 4.3 前端数据流

- 前端控制器负责：请求快照 → 构建 7 日索引 → 按当前行政范围裁剪网格 → canvas 插值渲染色斑 → 日期切换重渲 → 播放计时逐日切换 → 退出清理；
- 渲染性能：399 点 × 插值渲染在当前地图视口内可控；地图 move/zoom 时按视口局部重绘；播放切换仅重渲当前日图层，不得拖慢交互；
- 播放计时器：进入播放创建、停止/退出/日期点击/刷新/关闭时清除；计时回调不得在退出后继续写入图层（沿用 `weatherMarkerLayerController` 闭包快照清理教训：`clear()` 必须同时重置快照，残留计时器必须显式清除）。

## 5. 验收标准

1. 右下角"灾害风险"菜单出现"查看降水"，与"查看台风""查看天气"互斥，进入/退出生命周期与台风模式一致（进入切回浙江省级、退出恢复）；
2. 打开"查看降水"：浙江全省显示连续色斑渐变累计降雨场，默认选中第 1 天（今天），色斑半透明可透出底图，加载态→成功数据流程无白屏；
3. 地图底部时间轴显示 7 个日期标签（日期+星期），点击任意日期立即切换色斑为该日累计场，且不重新请求上游；
4. 播放按钮：逐天自动切换，默认间隔 1.2 秒/天，播放到第 7 天后自动停止；播放中点击日期暂停并跳转；
5. 下钻到市/县/乡/村：色斑聚焦当前行政区域，行政边界保留，切换日期/层级不重新请求上游；
6. 图例展示色阶与分级刻度（含 mm 数值），面板常驻"降水预报数据 © Open-Meteo / ECMWF（0.25° 网格，约 25 km）"与"预报场仅供参考，不作定损依据"标注；
7. 色斑位于天地图文字注记之下，不遮挡行政边界与地块；
8. 手动刷新：新鲜期内不访问上游，过期后访问并成功更新；刷新失败保留旧数据并标注失败时间；
9. 上游不可用（模拟超时/5xx）：有缓存返回缓存快照，无缓存显示"降水预报暂不可用"，不降级成"无降水"；
10. 退出后色斑图层、选中日期、播放计时器、请求计时器全部清除，地图交互恢复正常；
11. 服务端单测覆盖：参数固定（浏览器不可改）、聚合口径（7 段各 24h = 当前整点起 N 小时求和、预报边界处理）、缓存新鲜期、合并在途请求、降级路径、响应体积上限；前端单测覆盖：控制器渲染/日期切换/裁剪/播放计时/清理与互斥。
