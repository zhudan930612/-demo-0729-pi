# 农险双精准地图 Demo —— 浙江省气象预警数据接入需求

> 版本：v0.4（2026-08-04，需求拷打决策已确认）
> 状态：已实现（2026-08-04；自动验证见服务端与前端测试）
> 适用范围：浙江省当前气象预警列表、浙江地图预警定位与服务端数据代理

---

## 1. 目标与事实依据

在现有“查看天气”能力之内，提供一份**浙江省当前生效气象预警清单**，用于内部风险态势核查，并与现有浙江地图上下文联动。服务端读取上游全量快照后，只保留行政代码属于浙江省的记录，浏览器绝不接收或展示省外预警。本需求**接管并取代**原和风天气的“行政代表点命中预警”逻辑（见 2.1.2）：和风预警请求、行政代表点预警标牌与旧预警面板均已移除，天气工具另一项“实时天气”继续使用和风天气，数据来源、空间语义和刷新策略彼此独立。

经 2026-08-04 实测：

- `https://weather.cma.cn/web/alarm/map.html` 对程序化请求返回 WEB 应用防火墙人机验证页，**不得**用浏览器直连、后端爬虫绕过验证，或依赖该页面 HTML/地图脚本；
- 中央气象台页面 `https://www.nmc.cn/publish/alarm.html` 正常使用下列 JSON 接口：

```text
GET https://www.nmc.cn/rest/findAlarm?pageNo=1&pageSize=10000
```

- `pageSize=10000` 是获取当前完整列表的必要请求参数，不能省略或降为常规小页大小；该参数由服务端固定拼入请求，浏览器不得控制；
- 本次实测返回 `code=0`、`data.page.count=1,271`、`data.page.pageSize=10000`、`data.page.totalPage=1`、`data.page.list.length=1,271`，即一份完整单响应快照；预警数量会持续变化；
- 该接口响应包含 `data.page.count`、`data.page.list[]`、`data.provinceAlarms[]`、`data.stat`。单条列表已确认含 `alertid`、`issuetime`、`title`、`url`、`pic`。

本接口是官方网站当前使用的公开网页接口，**不是承诺稳定、可商用的开放 API**。首期仅限内部 Demo 验证；正式长期使用前必须改用取得授权的中国气象数据网/CIMISS 服务或获得国家级气象数据提供方书面许可。

## 2. 范围与非目标

### 2.1 本期范围

1. 拉取上游全量快照后，按 `alertid` 前 6 位行政代码过滤、规范化并缓存**浙江省当前预警完整列表**；不分页、不筛选，浏览器仅接收浙江记录；
2. 将现有“气象预警”菜单项完全改接为 NMC 浙江预警，在地图右侧展示固定高度的全省完整列表；和风天气预警请求、行政代表点预警标牌和旧预警面板全部移除；
3. 浙江省、省内市、县记录在省、市、县、乡、村、地块任一当前地图层级均展示完整浙江快照中全部可定位的预警图标（见 3.4.1），图标固定锚定经核验政府驻地坐标，并与现役浙江行政下钻联动；
4. 地图浮窗仅展示标题、发布时间和官方预警正文；不提供外链或跳转；
5. 所有上游访问仅发生在 `server/`；前端只调用本站 `/api/national-weather-alarms`、详情接口和受控的手动刷新接口，三者均只处理浙江记录。

### 2.2 明确不做

- 不抓取、破解或自动通过 `weather.cma.cn` 的 WAF/滑块验证；
- 不把 `alertid` 行政代码转换成未验证的精确坐标，不为浙江县区伪造预警点位；
- 不展示预警详情页的原文外链、跳转按钮、防御指南、失效时间或其他未确认字段；预警正文仅用于本地浮窗显示。
- 不向浏览器输出、显示、筛选、统计或地图化任何省外预警；
- 不将浙江预警自动转换为地块灾损、承保风险、查勘指令、理赔结论或推送通知；
- 不在浙江省外加载行政边界、影像或地块，也不改变现有五级行政下钻的浙江范围；
- 不承诺历史预警、撤销预警追溯或“浙江全部预警永不遗漏”的数据服务等级。

## 3. 用户界面与交互

### 3.1 入口与模式

- 右下角“查看天气”菜单保留现有名称“气象预警”，但其数据源和全部交互替换为本需求的 NMC 浙江预警；菜单另一项“实时天气”继续使用和风天气。不得新增第三个预警入口，也不得改动“查看台风”的独立入口与互斥规则；
- 打开“气象预警”时立即关闭已打开的地块详情、种植档案和保单抽屉，取消任何地块编辑态；将现有行政导航切回浙江省级，并将地图视角定位为浙江省全景；不自动选中任何预警或打开浮窗；影像和地块图层开关保持不变；
- NMC 气象预警与实时天气、台风查看均互斥；选择任一项立即关闭其他模块的面板、标记、选中态、浮窗和请求计时；
- 退出按钮关闭面板、浙江地图标记、选中态、浮窗和刷新状态，不改变退出瞬间的行政层级与地图视角；
- 地块处于筛选、绘制、批量编辑、修形或未保存种植档案状态时，沿用现有灾害风险入口禁用规则。

### 3.2 固定全省预警列表

面板固定在地图右上边缘，遵循参考图的“标题栏 + 连续单行预警列表”信息结构，以及 `DESIGN.md` 的雾白、细边框、紧凑间距和地图优先规则；不得逐像素复制参考图的蓝色、字体、尺寸或品牌样式。桌面宽度固定 360px、高度固定 520px；面板自身不随预警数量增高或缩短。520px 以下改为左右各 12px 的近全宽面板，高度为 `min(520px, calc(100vh - 24px))`。

```text
气象预警                                 刷新  关闭
数据时间：YYYY/MM/DD HH:mm
────────────────────────────────────────────
[图标] 杭州市……发布暴雨黄色预警信号
[图标] 绍兴市……发布大风蓝色预警信号
                         ↕ 列表内部滚动
```

- 打开模块后固定显示**本次浙江完整快照中的全部预警记录**；不按当前地图市、县、乡、村层级自动隐藏记录，不提供层级、灾种、等级或省份筛选，不分页；列表与地图图标的层级筛选规则彼此独立；
- 默认按 `issuedAt` 倒序，时间相同按 `id` 稳定排序；刷新完成时保留已选记录，若其已不在新快照中则关闭浮窗并清除选中态；
- 标题栏固定显示“气象预警”、数据时间与刷新、关闭按钮；刷新与关闭按钮始终可见，只有记录区 `overflow-y: auto`；刷新进行中时刷新按钮呈旋转态并禁用；
- 每条记录是一行可点击控件：左侧是官方图标或通用预警图标，右侧只显示完整上游 `title`；长标题可在最多两行内换行，不能用灾种/等级猜测替换标题；行需有发布时间、完整标题和行政代码的可访问名称；
- 点击可定位行后添加清晰的边框/背景选中态，并仅执行 3.3 节行政导航和居中；列表点击不直接打开浮窗，也不会重新拉取 NMC 全量快照；
- 仅在用户点击刷新按钮时访问 NMC 全量列表；不做定时、页面恢复或层级切换自动刷新。手动刷新强制尝试上游更新，但 60 秒共享冷却内静默返回当前缓存；刷新期间保留旧列表并显示“正在更新”，失败时显示“更新失败，上次成功获取于 …”，不得把失败清空显示为“无预警”；
- 无浙江记录时，记录区显示“当前未查询到浙江省生效预警”；图标、颜色和选中态均不得作为唯一信息。

### 3.3 列表点击：行政进入与地图定位

点击一条可定位的浙江预警后，必须以该记录的 `adminCode` 作为唯一导航依据：

| 预警行政层级 | 导航结果 |
|---|---|
| `province`（`330000`） | 切回浙江省级，地图适配浙江省可信边界 |
| `city` | 切入对应市级，地图适配该市可信边界 |
| `county` | 切入对应县级，地图适配该县可信边界 |
| `unknown` 或未匹配 | 保持当前地图层级和视角，仅在列表提示无法定位 |

- 导航必须复用现役行政下钻/面包屑状态和对应可信边界；不能只改变地图视角而让面包屑仍停在旧行政对象；
- 完成导航后使用 `fitBounds` 将目标行政边界置于地图可视区域中心，并留出右上固定列表和地图浮窗的安全边距；不得使用行政几何中心、`bbox` 中心或地图中心替代边界适配；
- 导航动画完成后仅保持该记录的列表选中态；浮窗只能由 3.4 节当前可见的地图预警图标打开。快速连续点击时取消/忽略前一个导航，最后一次点击唯一生效；
- 同一行政对象的多条预警在列表中仍各自独立可定位；点击任一条后进入同一行政层级，但不自动打开该条浮窗；
- 浙江乡、村、未知层级或无法匹配的记录不改变视角、不自动降级到上级行政区；列表保持可选，并在地图顶部中央显示短时通知“该预警暂无法定位到当前地图”；
- 点击列表预警是本功能的明确例外：允许进入目标市/县并居中显示；这不改变普通预警图标点击、列表滚动或当前行政边界点击的既有规则。

### 3.4 地图预警图标与信息浮窗

每个预警图标锚定其所属行政对象的**经核验政府驻地坐标**：省级预警使用省人民政府驻地，市级预警使用市人民政府驻地，区县级预警使用对应区县人民政府驻地。政府驻地坐标由离线一次性生成的私有坐标表提供，并必须位于该行政对象及完整父级链的可信边界内；运行时不得调用天地图或其他外部地理编码服务。正常情况下同一行政对象仅有一条预警，绘制一个图标；若上游未来同时返回同一 `adminCode` 的多条预警，则各条图标以该政府驻地为共同锚点水平并列。该偏移只为防止视觉重叠，不代表不同地理位置，浮窗必须持续显示相同的行政对象归属。

#### 3.4.1 图标与当前地图层级的对应

地图在浙江省、市、县、乡、村和地块任一当前地图层级，均展示**当前浙江完整预警快照中全部可定位记录**；列表同样始终保留完整记录。图标固定锚定各自经核验的政府驻地，不随当前地图层级重定位、复制、继承或降级：

| 当前地图层级 | 地图显示的预警图标 |
|---|---|
| 浙江省、市、县、乡、村、地块 | 当前完整浙江快照中全部可定位的省、市、县预警 |

- 地图层级变化只能通过现役边界点击、面包屑、缩放下钻/返回或 3.3 节的列表点击导航触发；每次变化后从已缓存的完整浙江预警快照重绘全部图标，不重新请求 NMC，并清除已打开的浮窗和选中态；
- 坐标缺失、行政树不匹配或未通过政府驻地边界校验的记录仍保留在列表中，但不得绘制地图图标；
- 同一行政对象多个图标以同一政府驻地为共同锚点水平并列：图标宽 34px、相邻图标保留 4px 间隔，并围绕共同锚点居中展开（两条为 `-19px/+19px`，三条为 `-38px/0/+38px`）；偏移仅防止视觉重叠，不代表不同地理位置；
- 图标超出当前可视地图范围时不作伪造移动或聚合；用户可通过现役地图导航或列表定位进入该行政区查看。

#### 3.4.2 信息浮窗

- 点击当前层级可见的单条地图预警图标，不改变行政层级、地图中心或缩放；它只打开该图标对应预警的信息浮窗；
- 同一行政对象多条预警以独立并列图标呈现；浮窗不提供上一条/下一条切换器，用户点击对应图标切换预警；每次点击更新列表选中态，但不移动地图视角；
- 点击列表后完成 3.3 节导航，浮窗锚定该条预警所属行政对象的经核验政府驻地；点击地图图标后，浮窗同样锚定该政府驻地；浮窗靠近屏幕边缘或右上列表时调整自身位置，不移动地图相机；
- 浮窗采用参考图的“有色标题栏、白色正文、关闭按钮”信息结构，但颜色、圆角、阴影、字号遵循 `DESIGN.md`，不逐像素复制；
- 浮窗按固定顺序只展示三项：完整上游 `title`、`issuedAt` 格式化后的“发布时间：YYYY/MM/DD HH:mm”、按需取得并清洗后的官方预警正文；标题或时间缺失显示 `--`，正文缺失或读取失败显示“预警正文暂不可用”；
- 浮窗**不显示**“查看详情”、原文链接、外部跳转按钮、预警图标、行政对象、灾种/等级、预警数量、加载骨架或任何由标题推测出的信息；
- 用户首次打开某条预警浮窗时，浏览器只请求本站详情接口；服务端按该记录的已校验 `sourcePath` 从 NMC 详情页按需读取并提取正文，缓存成功结果。不得在加载完整浙江列表时预取详情页；
- 正文缓存键为 `alertId + title + issuedAt`；最新快照中该 ID 消失时立即删除其正文缓存，标题或发布时间任一变化时立即使旧正文失效并重取。新版正文重取失败时只显示新标题、新时间与“预警正文暂不可用”，不得回退或混用旧正文；
- 服务端只允许读取当前浙江快照中该条记录已校验的 `/publish/alarm/*.html` 路径，固定 NMC HTTPS 主机、禁止重定向、限制 10 秒超时与 512 KiB 响应；解析器仅从经人工确认、受测试覆盖的 NMC 正文白名单容器提取段落和换行，输出 HTML 清洗、长度上限 4,000 字符的纯文本。正文容器缺失、WAF、超时、结构漂移或内容超限均返回脱敏详情错误，不能阻塞列表与地图标记；结构漂移必须由开发者更新白名单容器和测试后恢复，不做智能正文猜测；
- 正文首次失败时显示一次“重试”按钮；同一浮窗打开生命周期内只允许手动重试一次，重试再次失败后保留“预警正文暂不可用”且不再显示按钮；
- 点击浮窗关闭、地图空白或按 `Esc` 仅关闭浮窗和选中态，不退出浙江预警模块；地图拖动、缩放或相机移动期间，已打开的预警浮窗持续按其预警图标的新容器坐标定位，直到用户关闭浮窗；正文超出可视高度时只在浮窗正文区内部滚动，标题栏和关闭按钮始终可达。

### 3.5 浙江地图联动

- 本期列表和地图均仅展示浙江省。服务端过滤后仅保留 `adminCode` 以 `33` 开头的记录；在这些记录中，只有可与本仓可信浙江行政树精确匹配的记录才允许地图定位；
- 服务端由 `alertid` 前 6 位提取 `adminCode`，在服务端私有 `WEATHER_DATA_DIR/weather/index-v2.json` 及其可信边界引用中查找同码省、市或县对象；不得从预警标题解析、模糊匹配或猜测行政归属；
- 每个可匹配浙江行政对象使用私有 `government-seats-v1.json` 中、由天地图地理编码 API 按“对应行政层级人民政府”名称一次性查询并通过边界校验的政府驻地坐标定位；该表覆盖浙江省、省内 11 市和 90 个区县。生成时必须保存行政代码、名称、层级、查询名称、坐标、匹配分与生成时间；运行时只读本地表，绝不重复查询天地图。坐标缺失、低于约定匹配分、名称/层级不一致或不在该行政面及父链内时，拒绝加载预警空间索引并不发布地图点，不能退回代表点、几何中心、`bbox` 中心、地图中心或省会；
- 同一浙江行政对象命中多条预警时，各条以同一经核验政府驻地为共同锚点绘制独立并列图标，视觉偏移仅用于防止重叠，不代表不同地理位置（见 3.4.1/3.4.2）；浮窗不提供上一条/下一条切换器，点击对应图标切换预警；
- 浙江的乡、村、未知层级或行政树无法匹配记录只保留列表展示，并显示“当前地图仅展示浙江省可定位预警”；省外记录必须在服务端过滤，不得传至浏览器；不得为任何省外记录加载边界、创建点或面；
- 列表点击浙江省/市/县记录按 3.3 节进入对应行政层级并 `fitBounds` 居中；地图预警图标点击不得改变行政层级、视角或缩放。两种入口的选中态都按 `adminCode + alertid` 同步；
- 本功能不提供全国概览、全国列表或全国地图功能。

## 4. 数据模型与口径

### 4.1 上游读取规则

服务端每次刷新只能发起一个固定的全国全量请求；该响应仅在服务端内存中处理并立即过滤为浙江记录：

```text
GET https://www.nmc.cn/rest/findAlarm?pageNo=1&pageSize=10000
```

1. `pageNo=1`、`pageSize=10000` 均为服务端常量，不能被浏览器参数覆盖、删除或降级；
2. 响应必须满足 `code=0`、`data.page.pageNo=1`、`data.page.pageSize=10000`、`data.page.totalPage=1`、`data.page.count === data.page.list.length`，才可作为完整快照发布；
3. 以 `alertid` 去重；若出现重复 ID 且字段冲突，保留发布时间更晚的一条并记录脱敏结构告警；去重后数量必须等于上游 `count`，否则中止本轮刷新并保留旧快照；随后仅保留 `adminCode` 前两位为 `33` 的记录作为浙江快照；
4. 上游 `code !== 0`、全量参数被改写、总页数不为 1、总数与列表数不一致、JSON 无法解析、响应体超限或字段异常，均视为本轮失败，不发布可能不完整的新快照；
5. 若未来上游不再支持该全量参数，必须先重新实测并更新本需求；不得静默退化为 `pageSize=500` 加多页抓取，以免放大对官方站点的请求量。

`pageSize=10000` 是当前实测有效、但非官方稳定契约的全量参数。实现可将该常量集中配置以便受控调整，但不能让浏览器传入页号、页大小或任意上游 URL。

### 4.2 规范化记录

服务端内部保留用于详情读取的受控字段；浏览器仅接收下列白名单字段：

```ts
interface NationalWeatherAlarm {
  id: string                 // 上游 alertid，非空且最长 128 字符
  issuedAt: string | null    // 上游 issuetime，不能解析时保留 null
  title: string              // 上游 title，经长度和控制字符校验
  iconUrl: string | null     // 已校验的 image.nmc.cn HTTPS 图标地址
  adminCode: string | null   // 从 alertid 前 6 位提取；无效为 null
  adminLevel: 'province' | 'city' | 'county' | 'unknown'
  provinceCode: '33'              // 服务端过滤后仅可为浙江
  provinceName: '浙江省'           // 服务端过滤后仅可为浙江省
  eventType: string | null   // 仅由标题按受控规则识别；不能识别为 null
  severity: 'red' | 'orange' | 'yellow' | 'blue' | 'unknown'
  mappableInZhejiang: boolean
  mapLocation: {
    status: 'mapped' | 'unmapped'
    point?: [number, number] // 仅浙江可信行政对象的 [longitude, latitude]
    groupCount?: number      // 同一浙江行政对象的预警数量，仅前端并列图标计数使用
  }
}


interface ZhejiangAlarmDetail {
  id: string
  issuedAt: string | null
  body: string | null        // NMC 原文页按需提取、HTML 清洗后的纯文本
}
```

- 行政代码只可从符合 `^\d{6}` 的 `alertid` 前 6 位解析；不得从标题猜测并作为地图定位依据；
- 行政层级依据标准行政区划代码末尾规则和本仓行政树双重确认；两者冲突时为 `unknown`；
- `mapLocation` 只允许在 `adminCode` 以 `33` 开头且可信浙江行政对象、对应政府驻地坐标均匹配并通过边界校验时输出；同码多条预警共享完全相同的政府驻地坐标，前端以该点为共同锚点绘制独立并列图标，并通过 `groupCount` 计数；其余记录固定输出 `{ status: 'unmapped' }`；
- 省份名称由受版本控制的行政代码映射生成，不信任标题中的省市县文字；
- 灾种、等级可从标题按受控词表识别，无法识别时保留 `null/unknown`；它们只用于筛选与显示，不能改变原始标题，也不生成风险判断；
- 服务端内部 `sourcePath` 必须匹配 `^/publish/alarm/[A-Za-z0-9_-]+\.html$`，且仅可按当前快照中 `alertId` 查得；它不进入列表、详情或任何浏览器响应。`iconUrl` 必须为 `https://image.nmc.cn/` 下允许路径；不符合则置空；
- 不向浏览器返回 `sourcePath`、上游响应原文、请求头、Cookie、完整抓取 URL、内部日志或未白名单字段。

### 4.3 本站接口

```http
GET /api/national-weather-alarms
POST /api/national-weather-alarms/refresh
GET /api/national-weather-alarms/{alertId}
```

- 列表接口不接受任何查询参数；参数重复、未知或非空查询串一律返回 `400 INVALID_NATIONAL_ALARM_REQUEST`；
- 列表接口恒定只返回完整浙江快照，成功响应包含 `items`、`summary`、`fetchedAt`、`expiresAt`、`source`；`summary.total` 与 `summary.snapshotTotal` 均为完整浙江快照数；不得分页、筛选、返回全国总数或省外记录；
- 详情接口只接受当前浙江快照内的 `alertId`；未知 ID、路径格式错误或携带查询参数返回脱敏 `400/404`，不得请求任意详情 URL；成功响应仅返回白名单 `ZhejiangAlarmDetail`，不得返回外链、HTML 或其他详情字段；
- `POST /api/national-weather-alarms/refresh` 是唯一允许强制更新列表的入口，不接受请求体或查询参数；受 60 秒共享冷却保护，冷却内返回当前快照且不访问 NMC；
- 列表缓存未就绪且首次请求正在刷新时返回 `503 NATIONAL_ALARM_UNAVAILABLE`；有旧快照时，刷新失败仍返回旧快照并以 `stale=true` 和 `refreshError` 明示；
- 不配置 CORS；由 Vite 开发代理或同源部署转发。

## 5. 服务端、安全与缓存

### 5.1 实施职责

在 `server/` 中新增独立的浙江预警上游客户端、快照缓存和路由；不得把逻辑堆入 `web/src/components/MapView.vue`。建议职责：

- `national-alarm-upstream.js`：固定 NMC 列表/详情域名与允许路径、`pageNo=1&pageSize=10000`、超时、响应大小、全量快照 JSON 校验和白名单正文容器安全提取；
- `national-alarm-service.js`：去重、以行政代码过滤浙江记录、规范化、手动强制刷新、完整列表缓存、按 `alertId + title + issuedAt` 版本化的详情缓存和在途请求合并；
- `app.js`：只负责路由、参数校验、错误映射与审计日志；
- `web/src/features/`：列表、详情与浙江地图联动；`web/src/stores/`：状态、取消请求和筛选状态。

### 5.2 防护要求

- 上游地址固定为 `https://www.nmc.cn/rest/findAlarm`，禁止代理任意 URL，禁止重定向到其他主机；
- 列表请求使用 HTTPS、10 秒单请求超时、1 MiB 单页压缩后响应上限、3 MiB 解压/文本处理上限；详情正文请求使用 HTTPS、10 秒超时、512 KiB 响应上限和 4,000 字符清洗后正文上限；大小、状态码、JSON 与字段校验失败均不得泄露上游原文；
- 同一快照刷新全局只允许一个在途任务；多名用户访问时复用同一任务，不能放大为多轮全国爬取；
- 成功完整快照在普通读取中可复用 5 分钟；只允许用户显式调用刷新入口强制访问上游。不得定时、页面恢复或层级切换自动刷新；刷新失败时旧快照最多可服务 15 分钟，超过后返回明确不可用；
- 服务端每 IP 限流沿用现有代理策略；强制刷新任务另设 60 秒共享最小间隔，冷却内静默返回当前缓存且不访问上游；
- 仅记录请求 ID、路由、状态、耗时、快照条数和错误类别；不得记录用户 IP、完整上游 URL、Cookie、完整响应或预警原文；
- Node 服务仅监听 `127.0.0.1`；内网用户只能经现有受控同机反向代理或应用网关访问，复用既有内网认证和网络隔离；不得将 Node 服务直接绑定内网网卡；
- 该数据源无密钥也不得因此让浏览器直连。代理用于缓存、稳定性、统一结构、同源安全和避免将访问量放大到官方站点。

### 5.3 归因与许可

界面面板底部标注“数据来源：中央气象台（NMC）”；接口响应 `source` 标注“数据来源：中央气象台（NMC），仅展示浙江省预警”。浮窗展示的正文标明为官方预警正文，但不提供原文外链。本期允许经现有内网认证和网络隔离直接发布；项目负责人仍须留存网站使用条款、内部正文再展示许可、访问频率与使用边界的确认记录。不得部署到对外网络。

## 6. 异常状态

| 情形 | 面板行为 | 服务端行为 |
|---|---|---|
| 首次源站超时/拒绝/结构异常 | 显示“浙江预警数据暂不可用”与稍后重试 | 返回脱敏 `503/504/502` |
| 已有旧快照刷新失败 | 显示旧数据、上次成功时间和“更新失败” | 返回 `stale=true`，不清缓存 |
| 上游完整响应合法但过滤后无浙江记录 | 显示“当前未查询到浙江省生效预警” | 发布总数为 0 的浙江快照 |
| 当前浙江快照中没有记录 | 显示“当前未查询到浙江省生效预警” | 正常 `200` |
| 浙江行政匹配失败 | 浙江列表保留，提示不可地图定位 | 不生成坐标或地图对象 |
| 源站字段变更或全量参数失效 | 显示服务不可用或保留旧快照 | 中止发布新快照并记录脱敏结构错误 |

严禁将“接口失败”“全量快照校验失败”“浙江无法定位”表达成“没有预警”。

## 7. 验收标准

### 7.1 自动测试

1. 上游客户端只接受固定 NMC HTTPS 地址与固定 `pageNo=1&pageSize=10000`，拒绝重定向、超时、超限、非 JSON、`code !== 0` 和无效全量快照结构；
2. 仅当 `pageNo=1`、`pageSize=10000`、`totalPage=1`、`count===list.length` 时发布快照；任一参数被改写、总数不一致或重复 ID 冲突均不会发布不完整新快照；
3. 规范化仅输出白名单字段，非法 `sourcePath`、`iconUrl`、行政代码和标题控制字符均被拒绝或安全降级；
4. 列表接口携带任意查询参数一律返回 `400`；详情接口只允许当前浙江快照内的 ID，不能构造任意 NMC URL；手动刷新接口只接受无请求体、无查询参数的 `POST`；
5. 详情解析只接受当前记录已校验的 NMC HTTPS 路径，拒绝重定向、超时、超过 512 KiB 的响应和危险 HTML 节点；只从人工确认的白名单正文容器提取，保留段落和换行，返回清洗后最多 4,000 字的正文纯文本，绝不返回外链、HTML 或其他详情字段；白名单容器失效时必须失败，人工更新容器与测试后才可恢复；
6. 上游全量 fixture 同时包含浙江和省外记录时，服务端响应、缓存序列化和前端数据源只含行政代码以 `33` 开头的浙江记录；`summary` 不得泄露全国总数或省外统计；
7. 缓存覆盖 5 分钟普通列表读取、列表/详情在途合并、手动强制刷新、列表刷新失败保留旧数据、15 分钟过期失效和 60 秒共享刷新冷却；详情正文未打开时不得访问详情页，详情失败不影响列表；同 ID 标题或发布时间变化、或 ID 从快照消失时正文缓存立即失效；
8. 浙江定位仅对可信行政树匹配且代码以 `33` 开头的省、市、县记录返回 `mappableInZhejiang=true` 和面内代表点；省外、名称相似、乡村、未知层级绝不返回伪坐标；同一行政区多条预警生成并列的独立图标，视觉偏移不改变共同的可信代表点语义；
9. 给定同一浙江完整预警快照，断言省、市、县、乡、村、地块任一当前地图层级均展示快照中全部可定位记录（与 `nationalAlarmSelectors.spec.ts` 一致）；层级切换只清除已打开的浮窗和选中态、从本地缓存快照重绘全部图标，不重新请求 NMC；
10. `pnpm --dir server test`、`pnpm --dir web test`、`pnpm --dir web build` 与 `git diff --check` 全部通过。

### 7.2 手工验收

1. 启动服务和前端后，点击“查看天气 → 气象预警”，关闭已打开的业务抽屉与编辑态并切回浙江省全景；右上显示固定 360×520px 面板和完整浙江预警列表；列表与汇总中没有任何省外记录、分页、筛选器或全国统计，超出高度的记录区可独立滚动；
2. 点击一条可信浙江市/县记录后，面包屑同步进入对应市/县，地图 `fitBounds` 居中显示对应可信边界，固定列表保持打开、被点行选中但不自动打开浮窗；快速点两条时只以最后一条为准；不可定位记录保持原视角并显示地图顶部通知；
3. 验证任一地图层级（省、市、县、乡、村、地块）均展示当前浙江完整快照中全部可定位预警图标，图标固定锚定各自经核验政府驻地，不随层级变化迁移、复制或过滤；层级切换立即重绘本地快照全部图标、清除浮窗与选中态且不访问 NMC；
4. 点击地图单条预警图标后不改变层级、中心或缩放，只打开该图标对应的预警浮窗；浮窗在地图拖动或缩放时持续跟随对应图标，点击地图空白、浮窗关闭按钮或按 `Esc` 仅关闭浮窗和选中态；同一行政区多条预警并列于同一代表点旁且各自可点击；浙江乡村或不可匹配记录不产生地图点或导航；
5. 浮窗仅显示标题、发布时间和官方预警正文；不显示“查看详情”、外链、行政对象、图标、灾种/等级或预警数量。首次打开该预警时正文通过本站详情接口按需加载，并保留段落和换行；网络面板证明浏览器未直接请求 NMC 详情页；
6. 详情上游超时、WAF 或正文结构异常时，浮窗保留标题与发布时间，并显示“预警正文暂不可用”和一次重试；重试失败后保留失败提示且不再显示按钮。列表、地图图标和其他预警浮窗不受影响；
7. 用户点击刷新时强制尝试更新上游；冷却 60 秒内静默显示缓存。刷新后选中预警不在新快照时直接关闭浮窗；同 ID 标题或发布时间变化后正文重新获取失败时只显示新标题、新时间和失败提示；
8. 断开列表上游或使用超时 fixture 后，已有浙江数据保留并标明更新失败；首次无缓存时显示不可用，不显示“无预警”；
9. 浏览器构建产物、网络响应和服务日志中不含 Cookie、WAF 绕过参数、任意上游 URL、私有环境变量、未白名单上游字段或省外预警记录。
