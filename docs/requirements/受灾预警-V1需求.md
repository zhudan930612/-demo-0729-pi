## A. 总览

### A1 业务目标

台风邻近（预警期），保险公司需要提前掌握**哪些区域未来可能受灾**，提前做准备。本模块以真实历史台风「巴威」为案例，在五级行政区划地图上联动呈现台风轨迹与过程累计雨量热力图，随台风节点逐帧推演降雨发展，据此触发村级预警提示，并联动灾损预评估与防灾减损任务派发。对应业务闭环"台风逼近 → 降雨联动 → 预警提示 → 灾损预估 → 任务派发 → 取证留痕"。

### R2 台风×降雨联动可视化

#### B1 需求描述

以真实历史台风**巴威**（2026 年第 9 号）为唯一演示案例：地图同时呈现**台风轨迹**（轨迹线 + 当前位置风圈）与**过程累计雨量热力图**（自影响窗口起点累计至当前节点）。播放按**台风节点逐帧推进**（海上约 6h、近岸 3h/1h，节点即帧），台风位置与热力图同步刷新；**循环播放不自动停**。播放控件为**底部居中迷你浮窗**（播放/暂停切换 + 当前节点时间 + 关闭按钮，**无时间轴**）。

- 播放范围：影响窗口 **2026-07-09 00时 ~ 2026-07-13 00时**（北京时间）。
- 不提供台风选择/列表入口，进入模式即默认加载巴威。
- 台风侧不显示节点表、预报路径对比等分析型面板（属台风模式职责）。
- 降雨渲染、降雨悬停浮窗、台风节点浮窗、风圈浮窗**全部复用现有实现**。

#### B2 场景与操作路径

- 核心路径：进入受灾预警 → 地图显示巴威轨迹起点 + 7/9 00时 累计雨量热力图 → 点迷你浮窗 ▶ → 台风沿轨迹逐节点移动、风圈跟随、热力图逐节点刷新为过程累计雨量（雨势随逼近登陆增强）→ 播到最后节点自动回起点重播 → 用户点 ⏸ 暂停，画面停在当前节点 → 再点 ▶ 继续。
- 悬停路径：鼠标移到热力图 → 显示该点过程累计雨量浮窗；移到台风节点 → 节点浮窗（时间/强度等）；移到风圈 → 风圈浮窗。
- 边缘路径：点浮窗关闭按钮 → **直接退出受灾预警模式**（清理轨迹/热力图/浮窗等本模式状态，恢复正常地图）；历史降雨接口失败/超时 → 提示错误文案，不显示热力图；某节点无对应降雨数据 → 该帧热力图保持上一份（不闪空）。

### R3 村级预警

#### B1 需求描述

台风播放推进过程中，系统按**未来 24h 预报雨量**（当前台风节点时刻往后 24h 的降雨量，历史归档数据充当"预报"）对**村级**自动触发预警，无需人工操作。分级：**≥50mm 黄 / ≥100mm 橙 / ≥150mm 红**（阈值定稿前按 ERA5 真实数据分布校准，校准记录留档）。预警**可升可降**：台风逼近、预报雨大 → 触发/升级；过境或转向、预报雨停 → 降级/解除。

- 预警对象：**同一村 + 同一台风过程 = 同一条预警**（等级是其状态属性，等级变化不产生新预警条目）。
- 地图呈现：预警村以**脉冲圆点标记**（颜色对应等级），点击定位到村并显示预警详情；**村无边界数据，不生成伪村界**。
- 预警列表：右上角「受灾预警」面板，行 = 村名 + 未来 24h 预报雨量 + 等级色，点击定位到村。
- 口径并存说明：热力图显示过程累计雨量（R2，"已经下了多少"），预警用未来 24h 预报雨量（"还要下多少"），两个视角有意并存，非矛盾。

#### B2 场景与操作路径

- 核心路径：播放推进 → 某村未来 24h 预报雨量 ≥50mm → 地图该村出现黄色脉冲标记、预警列表新增该村 → 预报雨量继续增大 → 预警升级橙/红（标记与列表等级色同步变化）→ 点脉冲标记或列表行 → 地图定位到村 + 预警详情（村名 + 等级 + 未来 24h 预报雨量 +「派发任务」入口，联动 R5）。
- 边缘路径：预报雨量降至阈值以下 → 预警降级/解除（脉冲标记消失、列表移除该村）；循环播放回到起点 → 预警状态随播放帧重置；降雨数据缺失时预警不触发。

### R5 防灾减损任务派发联动（部分已定稿）

> 状态：预警-任务联动规则已定稿（2026-08-27）；自动/人工切换语义、任务类型、任务呈现体系待沟通。

#### B1 需求描述（已确认部分）

每条预警可派发任务：预警详情含「派发任务」入口，点击生成任务并进入任务列表。核心原则：**预警可撤销，任务不撤销**——任务一旦生成即独立走自身生命周期，不随预警变化。

**已确认规则**：

3. 去重：同一村 + 同一台风过程 + 同一任务类型只生成一次；预警解除后再次触发不重复生成（可追加「预警再次触发」说明）。
4. 任务卡片显示当前预警等级色（随升级刷新）+ 说明区按时间追加变化记录（生成/升级/解除各一条）。
