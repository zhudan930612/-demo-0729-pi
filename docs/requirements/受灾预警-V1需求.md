## A. 总览

### A1 业务目标

台风邻近（预警期），保险公司需要提前掌握**哪些区域未来可能受灾**，提前做准备。本模块以真实历史台风「巴威」为案例，在五级行政区划地图上联动呈现台风轨迹与过程累计雨量热力图，随台风节点逐帧推演降雨发展，据此触发村级预警提示，并联动灾损预评估与防灾减损任务派发。对应业务闭环"台风逼近 → 降雨联动 → 预警提示 → 灾损预估 → 任务派发 → 取证留痕"。

### R3 村级预警

#### B1 需求描述

台风播放推进过程中，系统按**未来 24h 预报雨量**（当前台风节点时刻往后 24h 的降雨量，历史归档数据充当"预报"）对**村级**自动触发预警，无需人工操作。分级：**≥170mm 低风险 / ≥175mm 中风险 / ≥180mm 高风险**（沿用 village-risk 四级风险体系与配色：低=绿/中=黄/高=红，无风险=不触发；阈值已按 ERA5 真实数据分布校准定稿，校准依据见 C3）。预警**可升可降**：台风逼近、预报雨大 → 触发/升级；过境或转向、预报雨停 → 降级/解除。

- 预警对象：**同一村 + 同一台风过程 = 同一条预警**（等级是其状态属性，等级变化不产生新预警条目）。
- 地图呈现：预警村**按预警等级给村边界面上色高亮**（**移除放射点脉冲标记**；村界几何来自真实村庄边界 `/data/villages/{townshipCode}.geojson`，非村点位伪造；与等级同色：中=黄/高=红，面填充=同级色半透明 + 边线加粗；图层 pane 低于天地图文字注记）；**仅中/高风险（待处理）上图并进入预警监测列表，低风险（待观察）不显示边界高亮、也不进入预警监测列表（预警监测仅显示触发中、高风险的村）**；**防密集聚合**：省/市级视角按区县聚合为预警徽标（⚠+中/高风险村数，底色=该县最高等级色，落在区县政府位置，无源数据时用边界质心），县/乡镇级展开为具体村边界高亮；点击聚合徽标=下钻到对应区县，点击村边界=进入村级视角。
- 预警监测 tab：右上角「受灾预警」面板的「预警监测」tab，**参考农情监测异常 top tab 结构**——表头（预警村概览 + 触发规则ⓘ悬停提示 + 一键派发）+ 预警村卡片列表。卡片 = 行头（村名 + **状态标签** + 等级色点）+ **AI 建议文案**行（含触发规则）+ 「派发任务」按钮；**预警无独立详情页**，信息全部在村卡片展示；点击卡片或村边界 → 地图进入村级视角（下钻聚焦该村）。
- 口径并存说明：热力图显示过程累计雨量（R2，"已经下了多少"），预警用未来 24h 预报雨量（"还要下多少"），两个视角有意并存，非矛盾。

### R4 灾损预评估

#### B1 需求描述

提供受影响区域的灾损预评估统计，呈现在面板「灾损预估」tab，随播放推进动态刷新：**预估受灾面积（万亩）、预估涉及户数、预估赔偿金额（万元）**，按区域下钻（省→市→县→乡镇→村，随当前层级刷新）。

**业务规则与口径**：
- 统计对象：当前层级内**处于预警状态**的村（低/中/高）。
- 预估受灾面积 = Σ（预警村承保面积 × 村级风险系数 × 损失率），单位万亩；村级风险系数由 village-risk 域村级风险等级映射，损失率按预警等级 mock（高 > 中 > 低）。
- 预估赔偿金额 = Σ（预警村保额 × 村级风险系数 × 损失率），单位万元。
- 预估涉及户数 = 预警村承保户数合计（不折算）。
- 承保面积/保额/户数口径：有真实保单的村用**现有保单口径**数据，无承保数据的村**按农情监测造数口径生成演示承保数据**（造数留档），全部预警村均计入预评估；村级可查看承保基础（承保面积/保额/户数）。
- 所有数字一律标注「**预估**」。

#### B2 场景与操作路径

- 核心路径：进入受灾预警 → 右上角面板默认显示「灾损预估」tab（当前层级省级汇总：三项数字 +「预估」标注）→ 播放推进、预警村增加/升级 → 数字随之刷新 → 下钻到某市/县/村 → 预评估按当前层级刷新。

### R5 防灾减损任务派发联动（部分已定稿）

> 状态：已定稿（2026-08-27）。

#### B1 需求描述（已确认部分）

每条预警可派发任务：预警村卡片含「派发任务」入口，点击生成任务并进入任务列表。核心原则：**预警可撤销，任务不撤销**——任务一旦生成即独立走自身生命周期，不随预警变化。

**已确认规则**：
1. 预警解除 → 已派发任务保留，任务列表/详情显示「关联预警已解除」提示。
2. 预警升级（如低→中）→ **不重复生成同类型任务**；旧任务刷新预警等级标记，并追加升级说明（时间 + 等级变化，如「7/10 14时 预警由低升级为高」）。
3. **任务类型按预警等级绑定**：低/中 → 预防指令类（通知加固大棚）；高 → 预防指令类 + 核查类（抢收抢割核查）。升级后若新等级对应**新任务类型** → 生成新类型任务（高风险村最多两条：预防指令类 + 核查类各一）。
4. 去重：同一村 + 同一台风过程 + 同一任务类型只生成一次；预警解除后再次触发不重复生成（可追加「预警再次触发」说明）。
5. 任务卡片显示当前预警等级色（随升级刷新）+ 说明区按时间追加变化记录（生成/升级/解除各一条）。
6. **任务状态沿用农情监测四态线性模型**（待下发→待领取→进行中→已完成）：生成时=待领取，自生成节点起至播放窗口结束**均分三段**（第一段末→进行中、第二段末→已完成），流转至「已完成」后自动挂预生成证据；待下发态本模式不出现（状态模型保留四态）。
7. **循环播放回起点 = 演示状态全部重置**（预警 + 任务 + 灾损预估清零），每轮都是完整演示；「任务不撤销」仅在单轮播放内生效（不重置则第二轮所有派发入口被去重规则禁用，演示坏掉）。
8. 有意取舍：**待领取任务在预警解除时保留不取消**（现实中可能取消；demo 简化为保留，避免任务在观众眼前消失）。

## C. 全局约束

### C1 架构约束

- **复用优先（用户明确强调）**：台风轨迹加载/播放/节点与风圈悬停复用现有台风模块（`web/src/features/typhoon/`、`web/src/map/typhoonLayerController.ts`）；降雨热力图渲染与悬停复用现有降水模块（`web/src/features/precipitation/`）；**不重写已实现功能**，受灾预警只做组装与新增业务逻辑层。
- 受灾预警模式装配逻辑放入对应 composable（`web/src/features/disaster-warning/useDisasterWarningMode.ts`，若新增），不堆回 `MapView.vue`。
- server 端历史降雨服务复制现有降水服务（`server/src/precipitation-service.js`）模式，改指 Open-Meteo 历史归档端点；**仅作开发期取数工具**——运行期数据走静态固化产物（见 C3），模式运行零网络依赖。

### C2 范围边界

- 本期不做：台风选择/列表入口（仅巴威）、播放时间轴（节点过多，仅播放/暂停）、台风节点表/预报对比等分析面板、「受灾评估」二级（仍灰显）、真实灾损定损（预评估数字均标「预估」）。

### C3 数据依赖

- 台风轨迹：巴威（2026 年第 9 号），走现有台风 API 链路（`/api/typhoons?year=2026` + `/api/typhoons/{no}`，APIHz 代理）；观测节点含逐小时级时间戳（`timeYmdh`）。
- 历史降雨：Open-Meteo 历史归档接口（ERA5），2026-07-09 ~ 07-13 逐小时降水，0.25° 浙江网格；**2026-08-27 已实测可用**（影响窗口过程累计：玉环 174.6mm / 温州 164.1mm / 杭州 51.7mm；地市村均 台州 145.5mm > 温州 137.3mm > 丽水 93.1mm > 金华 91.7mm > 衢州 70.7mm ≈ 宁波 70.5mm > 杭州 65.1mm ≈ 绍兴 64.9mm > 湖州 41.5mm > 嘉兴 30.6mm > 舟山 24.1mm，空间格局与实况一致）。
- **阈值校准依据（2026-08-27 形态预检实测留档）**：以 398 个真实 ERA5 格点 × 窗口内 71 个巴威节点 × 33898 村面计算未来 24h 预报雨量矩阵，**全省全窗口最大值仅 191.8mm**（出现在 7/11 09时前后）；且未来24h 分布存在悬崖（>=170→1073 村、>=180→444、180~189 真空）。用户要求三档分明，故阈值须在悬崖前；**选定 低≥170/中≥175/高≥180（方案 A），峰值 1036 村（高444·中217·低375）、17/71 节点有预警、曾达 高444/中217/低412**。
- 已知偏差：ERA5 对台风极端降雨系统性低估（实况单点 300~497mm，ERA5 明显压低）；空间分布与面雨量格局正确，演示可用；所有雨量与灾损数字标「预估」口径。
- 就绪状态：台风链路现成；历史降雨需新增 server 端点（复制现有降水服务改造）+ 节点聚合；村级承保/风险数据复用现有 village-risk 与保单口径（R4 用）。
- **村点位（政府驻地）**：源数据 `01-行政区划/浙江四级边界加村点/` 有村点位，需预处理脚本补充进 `web/public/data/`（当前处理后数据仅有村界 Polygon）；区县政府位置无源数据时用区县边界质心。
- **非参保村承保数据**：全省 33898 村（含社区）均参与预警；无真实承保数据的村按农情监测造数口径生成演示承保数据（面积/保额/户数），造数规则留档。
- **ERA5 格点近似**：0.25° 网格一格约 25km、覆盖数十村，同格内村雨量相同——村级预警为**格点近似**，文档与演示讲解中不表述为村精确雨量。
- **静态固化**：所有演示数据（历史降雨、巴威轨迹、每节点预警村清单、承保造数、任务、证据）由 scripts 离线预生成进 `public/data/`；预警村清单按节点离线计算（33898 村 × **71 节点**——影响窗口 7/9 00时~7/13 00时内巴威实况观测点，间隔 3h×12 + 1h×58），前端播放仅查表渲染，无运行时聚合计算。
- **村政府驻地点位可用性（2026-08-27 形态预检实测）**：源点位层（锐多宝 zip `村级/村位置_点数据_*.geojson`）共 25475 条，`cuncode` 退化不可用、名称与村面属不同行政年代（三元组名称匹配仅 46.3%），**必须用空间连接**：村面内含点位 52.4% + 同县同乡归一化名称匹配 4.6% + 质心 1.5km 内最近点位兜底 26.9% = **83.9% 取到真实驻地**；剩余 16.1%（5447 村）用**村面多边形质心兜底**并在产物中标 `seatSource`（seat/name/nearest/centroid），不得表述为确权驻地。
- **承保造数规模（2026-08-27 用户拍板）**：全省 33898 村演示承保面积总量锚定 **1100~1300 万亩**（2025 年浙江粮食播种面积 1584.6 万亩，承保率约七至八成），村均 **325~384 亩**、长尾分布；保额沿用仓库现有口径 **1250 元/亩**（官方水稻完全成本保险 1400 元/亩同量级）。不得按龙江村真实 2882 亩量级平铺全省（将达约 9800 万亩，超粮食播种面积 6 倍）。
- 预警阈值校准：低/中/高阈值 **≥170/≥175/≥180mm** 已按 ERA5 巴威时段真实数据分布校准定稿（见上条校准依据与 A4 形态预检记录）。

### C4 非功能约束

- 降雨热力图 pane 层级低于天地图文字注记（pane < 450），不遮挡行政边界与地块。

- 性能：预警计算离线预生成，前端播放仅查表渲染；静态数据可缓存。
