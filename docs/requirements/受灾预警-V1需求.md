## A. 总览

### A1 业务目标

台风邻近（预警期），保险公司需要提前掌握**哪些区域未来可能受灾**，提前做准备。本模块以真实历史台风「巴威」为案例，在五级行政区划地图上联动呈现台风轨迹与过程累计雨量热力图，随台风节点逐帧推演降雨发展，据此触发村级预警提示，并联动灾损预评估与防灾减损任务派发。对应业务闭环"台风逼近 → 降雨联动 → 预警提示 → 灾损预估 → 任务派发 → 取证留痕"。

### R2 台风×降雨联动可视化

#### B1 需求描述

以真实历史台风**巴威**（2026 年第 9 号）为唯一演示案例：地图同时呈现**台风轨迹**（轨迹线 + 当前位置风圈）与**过程累计雨量热力图**（自影响窗口起点累计至当前节点）。播放按**台风节点逐帧推进**（海上约 6h、近岸 3h/1h，节点即帧），台风位置与热力图同步刷新；**循环播放不自动停**。播放控件为**底部居中迷你浮窗**（播放/暂停切换 + 当前节点时间 + 关闭按钮，**无时间轴**）。

- 播放范围：影响窗口 **2026-07-09 00时 ~ 2026-07-13 00时**（北京时间）。
- 不提供台风选择/列表入口，进入模式即默认加载巴威。
- 台风侧不显示节点表、预报路径对比等分析型面板（属台风模式职责）。
- 降雨渲染、降雨悬停浮窗、台风节点浮窗、风圈浮窗**全部复用现有实现**。

#### B2 场景与操作路径

### R3 村级预警

#### B1 需求描述

台风播放推进过程中，系统按**未来 24h 预报雨量**（当前台风节点时刻往后 24h 的降雨量，历史归档数据充当"预报"）对**村级**自动触发预警，无需人工操作。分级：**≥50mm 低风险 / ≥100mm 中风险 / ≥150mm 高风险**（沿用 village-risk 四级风险体系与配色：低=绿/中=黄/高=红，无风险=不触发；阈值定稿前按 ERA5 真实数据分布校准，校准记录留档）。预警**可升可降**：台风逼近、预报雨大 → 触发/升级；过境或转向、预报雨停 → 降级/解除。

- 预警对象：**同一村 + 同一台风过程 = 同一条预警**（等级是其状态属性，等级变化不产生新预警条目）。
- 地图呈现：预警村以**脉冲圆点标记**（颜色对应等级，复用 village-risk 四级配色：低=绿/中=黄/高=红），点击定位到村并显示预警详情；**村无边界数据，不生成伪村界**。
- 预警监测 tab：右上角「受灾预警」面板的「预警监测」tab，**参考农情监测异常 top tab 结构**——表头（预警村概览 + 触发规则ⓘ悬停提示 + 一键派发）+ 预警村卡片列表。卡片 = 行头（村名 + **状态标签** + 等级色点 + 未来 24h 预报雨量）+ **AI 建议文案**行 + 「派发任务」按钮；等级 + 雨量即触发条件说明，不另加触发条件文案行。点击卡片或脉冲标记 → 面板内切换为**预警详情视图**（带返回键），含村名 + 等级 + 未来 24h 预报雨量 + 承保基础 +「派发任务」入口。
- 口径并存说明：热力图显示过程累计雨量（R2，"已经下了多少"），预警用未来 24h 预报雨量（"还要下多少"），两个视角有意并存，非矛盾。

#### B2 场景与操作路径

- 核心路径：播放推进 → 某村未来 24h 预报雨量 ≥50mm → 地图该村出现低风险（绿）脉冲标记、预警监测列表新增该村 → 预报雨量继续增大 → 预警升级中/高（标记与列表等级色同步变化）→ 点脉冲标记或列表卡片 → 地图定位到村 + 预警详情（村名 + 等级 + 未来 24h 预报雨量 +「派发任务」入口，联动 R5）。

### R4 灾损预评估

#### B1 需求描述

提供受影响区域的灾损预评估统计，呈现在面板「灾损预估」tab，随播放推进动态刷新：**预估受灾面积（万亩）、预估涉及户数、预估赔偿金额（万元）**，按区域下钻（省→市→县→乡镇→村，随当前层级刷新）。

**业务规则与口径**：
- 统计对象：当前层级内**处于预警状态**的村（低/中/高）。
- 预估受灾面积 = Σ（预警村承保面积 × 村级风险系数 × 损失率），单位万亩；村级风险系数由 village-risk 域村级风险等级映射，损失率按预警等级 mock（高 > 中 > 低）。
- 预估赔偿金额 = Σ（预警村保额 × 村级风险系数 × 损失率），单位万元。
- 预估涉及户数 = 预警村承保户数合计（不折算）。
- 承保面积/保额/户数一律用**现有保单口径**，不另造口径；村级可查看承保基础（承保面积/保额/户数）。
- 所有数字一律标注「**预估**」。

#### B2 场景与操作路径

- 核心路径：进入受灾预警 → 右上角面板默认显示「灾损预估」tab（当前层级省级汇总：三项数字 +「预估」标注）→ 播放推进、预警村增加/升级 → 数字随之刷新 → 下钻到某市/县/村 → 预评估按当前层级刷新。
- 边缘路径：无预警村时显示 0/空态；承保数据缺失的预警村不计入并在明细中标注。

### R5 防灾减损任务派发联动（部分已定稿）

> 状态：已定稿（2026-08-27）。

#### B1 需求描述（已确认部分）

每条预警可派发任务：预警详情含「派发任务」入口，点击生成任务并进入任务列表。核心原则：**预警可撤销，任务不撤销**——任务一旦生成即独立走自身生命周期，不随预警变化。

**已确认规则**：
1. 预警解除 → 已派发任务保留，任务列表/详情显示「关联预警已解除」提示。
2. 预警升级（如低→中）→ **不重复生成同类型任务**；旧任务刷新预警等级标记，并追加升级说明（时间 + 等级变化，如「7/10 14时 预警由低升级为高」）。
3. **任务类型按预警等级绑定**：低/中 → 预防指令类（通知加固大棚）；高 → 预防指令类 + 核查类（抢收抢割核查）。升级后若新等级对应**新任务类型** → 生成新类型任务（高风险村最多两条：预防指令类 + 核查类各一）。
4. 去重：同一村 + 同一台风过程 + 同一任务类型只生成一次；预警解除后再次触发不重复生成（可追加「预警再次触发」说明）。
5. 任务卡片显示当前预警等级色（随升级刷新）+ 说明区按时间追加变化记录（生成/升级/解除各一条）。
6. **任务状态沿用农情监测四态线性模型**（待下发→待领取→进行中→已完成）：任务生成后随播放推进呈现状态变化，流转至「已完成」后自动挂预生成证据；不以节点数写死流转规则。
7. **循环播放回起点 = 演示状态全部重置**（预警 + 任务 + 灾损预估清零），每轮都是完整演示；「任务不撤销」仅在单轮播放内生效（不重置则第二轮所有派发入口被去重规则禁用，演示坏掉）。
8. 有意取舍：**待领取任务在预警解除时保留不取消**（现实中可能取消；demo 简化为保留，避免任务在观众眼前消失）。

### C3 数据依赖

- 台风轨迹：巴威（2026 年第 9 号），走现有台风 API 链路（`/api/typhoons?year=2026` + `/api/typhoons/{no}`，APIHz 代理）；观测节点含逐小时级时间戳（`timeYmdh`）。
