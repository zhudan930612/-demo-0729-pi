针对水稻倒伏评估功能的优化点

1. 受损率：受损面积/参保总面积
省级受损率 = 全省受损面积 / 全省参保总面积
市级受损率 = 全市受损面积 / 全市参保总面积
区/县级受损率 = 全区/县受损面积 / 全区/县参保总面积
乡镇级受损率 = 全乡镇受损面积 / 全乡镇保总面积
村级受损率 = 全村受损面积 / 全村参保总面积

7. 区域统计的列表排序优化：受损程度（重>中>轻）>受损率（按大小倒序排序）
8. 所有统计都基于参保地块进行计算，因为这是给保险公司看预估赔付金额的
9. 演示环境造的数据要接近真实数据，每一层级之间的数据都要有关联；村级造的受损地块不要随机选，天灾造成的伤害区域基本都是连在一起的一片
