## 验证层级与证据标准约定

| 验证层级 | 证据标准 |
|----------|----------|
| [单测] | 测试命令 + 实际输出 |
| [数据脚本] | 命令 + 真实数据跑通输出 |
| [E2E-自动化] | 启动服务 + 浏览器/接口自动化操作 + 输出/截图 |
| [E2E-人工] | 验证人（用户或指定验收人）+ 操作步骤 + 观察结果 + 记录 + 确认 |

## 编码 agent 自测边界（供开发流程引用）

- 编码 agent 自测跑 [单测] / [数据脚本] 类验收项；[E2E-自动化] 可冒烟（启动服务基本验证），但最终证据由验收 agent 出具。
- 完成一个独立模块且该模块自测通过 → 提交（checkpoint）。
