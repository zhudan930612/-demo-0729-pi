# 农险双精准地图 Demo —— 需求文档

> 版本：v1.7（2026-08-02 现役范围同步）
> 状态：地图与地块 V1 已实现；详情/保单和灾害风险/台风见独立 V1 文档

---

## 1. 项目背景

参照"参考截图"，搭建农业保险地图演示页面。**用途：内部技术验证**（非客户演示，UI 不追求大屏效果）。本期只做**基础地图下钻能力**，后续在此基础上叠加承保、理赔、长势等业务功能，因此要求工程化搭建。

## 2. 需求概述

以天地图**卫星影像**为底图，支持 **省 → 市 → 县 → 乡 → 村** 五级逐层下钻查看，每个层级展示对应行政边界；在乡一级可以看到该乡所有村的边界；到村一级时，若该村在示范区范围内，在底图上叠加吉林一号 0.5m 高分影像。龙江村试点叠加由 Delineate Anything v2 从影像自动识别的演示地块。村为下钻终点。

演示主线（边界下钻路径示例）：

```
浙江省 → 绍兴市 → 上虞区 → 上浦镇 → 某村
```

高分影像叠加演示路径（已实测影像覆盖范围 2026-07-29）：

```
浙江省 → 绍兴市 → 上虞区 → 章镇镇 → 龙江村/泰山村 等 11 村之一（叠加高分影像）
```

> 注：吉林一号影像实测覆盖上虞区**章镇镇**（11 村）和嵊州市**三界镇**（6 村），
> 不含上浦镇；上浦镇路径用于验证"无影像村静默不叠加"分支。

## 3. 功能需求

### 3.1 地图底图

- 天地图**卫星影像底图**（img_w）+ 影像注记（cia_w）
- Token 从 `.env.local` 读取（已有 `TIANDITU_TOKEN`）
- 演示环境有网，天地图在线服务可用，不做离线兜底

### 3.2 五级下钻

| 当前层级 | 地图显示 | 点击行为 |
|---|---|---|
| 省 | 浙江省全图 + 11 个地市边界 | 点市 → 进入市级 |
| 市 | 该市范围 + 区县边界 | 点县 → 进入县级 |
| 县 | 该县范围 + 乡镇边界 | 点乡 → 进入乡级 |
| 乡 | 该乡范围 + **全部村界** + 吉林一号高分影像（若该乡与影像相交） | 点村 → 进入村级 |
| 村 | 该村范围 + **叠加吉林一号高分影像**（若覆盖）+ AI 识别地块（有产物时） | 无（村为终点，不再响应点击） |

- 顶部面包屑导航（如：浙江省 / 绍兴市 / 上虞区 / 上浦镇 / 某村），可回跳任意层级
- 左上角"回到上级"按钮（截图同款）
- 乡镇/村级高分影像：当前乡镇或村范围与影像覆盖范围相交时，**半透明叠加**在天地图影像底图之上（非替换底图），通过右下角眼睛图标开关；开启时固定 70% 不透明度；进入相交乡镇且当前缩放低于 z13 时自动抬升到 z13 以保证影像可见
- 影像未覆盖的村：不叠加影像，照常显示村界，左下角**文字角标**提示"该村不在高分影像覆盖范围内"（不弹窗）
- 村界加载：**按需加载**——进入乡级时才请求该乡的村界 GeoJSON，不做全省一次性加载
- 地块：AI 地块只在村级按村代码加载；正常模式下浅蓝色半透明展示、不响应点击；有已保存地块时显示独立地块图标按钮；用户界面统一使用“地块”，不显示“AI识别”或“候选”等字样。地块详情展示编号遵循 `DK-{12位村代码}-B-{基础地块稳定ID}` 或 `DK-{12位村代码}-M-{村内人工递增序号}`；人工序号删除后永不复用。
- 地块统计与图例：正常查看态且地块图层开启时，左下角内容自适应宽度的紧凑卡片显示“当前地块 / 合计面积”，不显示卡片标题，卡片底部与右侧缩放控件水平对齐；汇总本机未隐藏普通地块和已保存人工地块，保存更改后实时更新，关闭地块图层时同步隐藏。进入新增或筛选模式后，同一位置不再显示统计，改为两列紧凑“图示说明”：新增模式解释普通地块、已隐藏普通地块、人工地块、本批新增地块；筛选模式解释可见地块、待隐藏、已隐藏、待恢复；线框颜色、填充和虚实样式必须与地图一致。影像说明仅在正常查看态合并到统计卡片底部；新增或筛选模式的“图示说明”卡片不显示影像说明；无地块数据且不在操作模式时仍单独显示
- 村级地块操作：正常查看态将独立“地块工具”图标显示在右下角功能栏首位，并与其余图标使用一致的悬停提示样式；鼠标悬停只显示“地块工具”提示，点击后在图标左侧弹出包含“新增地块”和“筛选地块”的紧凑同色小浮窗。点击任一操作后先关闭浮窗，将“地块工具”图标保留为不可点击状态，再进入互斥的对应模式并在右上角显示完整模式工具栏；保存或取消退出模式后恢复右下角图标可用。点击图标外部或按 `Esc` 可关闭浮窗。无可筛选地块时“筛选地块”保留但禁用并说明原因
- 地块筛选：当地块图层显示且当前村存在普通地块或已保存人工地块时可进入；保持当前地图中心和缩放不变。普通地块与人工地块使用同一套筛选交互：点击可见地块标记为“待隐藏”，点击本机已隐藏地块标记为“待恢复”，再次点击取消对应标记。右上角工具栏显示“已隐藏 N / 全部恢复 / 待隐藏 N / 待恢复 N / 保存更改 / 取消”；“全部恢复”和各项计数同时覆盖普通、人工地块
- 保存与恢复：保存时按“原隐藏地块 + 待隐藏地块 - 待恢复地块”计算普通、人工地块共用的最终隐藏集合，并按村写入当前浏览器 `localStorage`；隐藏人工地块只影响显示，不删除或修改其几何记录；不修改原始 GeoJSON、不上传服务器、不记录隐藏原因。保存后退出编辑模式并提示本次隐藏、恢复数量；保存失败时保留本轮选择。“全部恢复”将当前村全部已隐藏普通和人工地块标记为待恢复，仍需点击“保存更改”才生效；取消编辑不修改已有记录
- 编辑展示：正常地图查看状态下，已保存人工地块与普通地块统一使用浅蓝边界和填充，不以来源区分。进入“新增地块”后使用半透明深色遮罩：普通既有地块使用高对比青蓝样式，已隐藏普通地块使用黄色粗虚线；所有已保存人工地块无论当前是否隐藏都使用紫色实线，本批次待保存新地块使用紫色虚线；这套新增模式视觉在手掌查看态和选点绘制态之间保持不变。筛选模式继续使用高对比青蓝、待隐藏红橙、隐藏黄色、待恢复绿色及操作提示；新增模式不触发隐藏/恢复操作
- 编辑视野：进入筛选、绘制或修形时保持当前视角不变，期间最小缩放固定为 z=15.25（高于村级 z≤15.0 的自动退出阈值）；允许平移、放大及缩小到该下限，但禁止自动返回上一层级；保存或取消后恢复原缩放规则
- 手动画地块：任意村均可连续逐点新增多个无孔单 Polygon，不依赖高分影像或地块产物。点击“新增地块”后默认进入查看状态，鼠标为手掌，可选择本批次已闭合地块；同时展示普通地块与本机已隐藏地块，隐藏地块沿用黄色粗虚线样式，确保重叠校验对象在地图上可见。点击右上角“绘制”或按第一次 `N` 才进入选点绘制状态；每次点击立即显示与编辑模式一致的紫色圆心、白色外圈顶点，但顶点不可拖动，边界保持开放折线。至少 3 个不同顶点后，点击第一个顶点或再次按 `N` 闭合当前地块并加入本批次待保存集合，随后自动回到查看状态
- 批量新增工具栏：右上角不显示“正在绘制”；查看状态显示“已绘制 X 地块 / 绘制 / 撤销 / 保存 / 取消”，进入绘制后“绘制”原位切换为“退出绘制”。地图顶部中央固定显示“按 `N` 开始绘制，再次按 `N` 完成操作”快捷键浮窗。X 只统计已闭合待保存地块，开放草稿不计入。点击“退出绘制”只丢弃当前未闭合折线并返回查看状态，保留本批次已闭合新地块、历史人工地块修形和待移除项；在查看态或绘制态按 `Esc` 均与点击顶部“取消”完全一致，取消整个新增批次。“撤销”优先撤销开放草稿最后一点，无开放草稿时撤销最近闭合地块；`Ctrl/Cmd + Z` 同行为
- `N` 状态规则：查看状态按 `N` 进入绘制；绘制状态尚未添加任何顶点时再次按 `N`，退出绘制并返回查看；已有 1～2 个不同顶点时按 `N`，提示至少需要 3 个不同顶点并保持绘制；已有至少 3 个不同顶点时按 `N`，闭合当前地块并返回查看
- 人工地块批次管理：查看状态不仅可选择本批次待保存地块，也可选择以前已保存的人工地块；选中后显示顶点并允许拖动修形，同时在地块最下方显示“移除”操作。选中地块后按 `Delete` 与点击“移除”完全一致：待保存新地块从本批次移除，历史人工地块标记为待移除，均需点击顶部“保存”才正式生效。地块失去焦点（点击地图空白）时将修形写回本批次内存暂存并恢复查看状态；新增、历史人工地块修改与移除都只在点击顶部“保存”后一次性写入 `localStorage`，点击“取消”或按 `Esc` 放弃整个批次且不改变历史数据。待保存新地块使用紫色虚线且不计入正式统计
- 人工地块面积：新地块闭合后立即在地块内部常显亩数；本批次待保存地块和以前保存的人工地块在新增查看态均显示亩数。选中地块拖动任意顶点时实时重新计算面积和内部标注点，亩数标签随节点变化动态更新
- 人工地块保存：“保存”一次性将本批次全部闭合新地块、历史人工地块修形结果和移除结果按村写入当前浏览器独立 `localStorage`；当前仍有未闭合地块时阻止保存并提示点击首点或按 `N`。保存失败保留整批现场且不部分生效，成功后才更新正式地块数量、面积和图层并退出新增模式。保存唯一 ID、村代码、`source: manual`、几何、平方米/亩、内部标注点及创建/修改时间；另外按村维护人工地块展示序号 `display_no` 与永不回退的 `next_display_no`，删除后不复用编号；不修改原始地块 GeoJSON、不上传。首次使用明确提示清理浏览器数据后无法恢复
- 人工几何校验：每块闭合或待保存修形完成时校验；少于 3 个不同有效顶点、自相交、零面积、非法坐标禁止加入待保存。与正式地块或同批待保存地块重叠、部分越过当前村界时，显示数量/原因并允许用户确认后继续；不自动裁剪或合并
- 取消与未保存保护：点击顶部“取消”或在新增查看态/绘制态按 `Esc` 使用同一逻辑，均放弃开放草稿和本批次全部待保存操作；有内容时使用项目内自定义确认弹窗，用户确认后退出，拒绝后保留现场；无内容时直接退出。地块重叠/越界警告和人工地块删除同样使用项目内自定义弹窗，不调用浏览器原生确认框。以上操作不影响以前保存的地块。开放草稿、批量待保存地块、正在修形的待保存地块、已修改正式人工边界或待保存筛选更改存在时，返回上级、点击面包屑、刷新或关闭页面前提示；未产生修改时不提示
- 人工地块 V1 不包含导入、导出、后端同步、多人共享、切割、合并、挖洞、自动吸附和 AI 地块几何修改

### 3.3 交互动效（内部验证版，精简动效）

1. **悬停高亮**：鼠标移入任一子区域时，该区域边界加粗点亮，并显示区域名称标签
2. **下钻/返回动效**：Leaflet flyToBounds 平滑飞入/飞出（约 1 秒），不做边界交错淡入和选中闪烁
3. **边界样式**：五级统一主题色，仅以线宽区分层级

### 3.4 缩放下钻（2026-07-29 追加）

除点击下钻外，支持通过缩放自动进出层级：

| 当前层级 | 放大自动进入 | 缩小自动退回 |
|---|---|---|
| 省 | z≥9.5 → 进中心点所在市 | — |
| 市 | z≥11.5 → 进县 | z≤9.0 → 退省 |
| 县 | z≥13.5 → 进乡 | z≤11.0 → 退市 |
| 乡 | z≥15.5 → 进中心点所在村 | z≤13.0 → 退县 |
| 村 | — | z≤15.0 → 退乡 |

- 判定时机：仅在 zoomend 触发，平移不触发；进入/退出阈值差 0.5 级防抖
- 全局缩放范围：地图在行政下钻、地块查看和灾害风险模式下统一允许缩小到 z=3.5，不得低于该级别；地块筛选、绘制或修形期间仍使用编辑专属最小缩放 z=15.25
- 当前缩放反馈：地图右下角紧邻天地图版权标识显示同高度的简洁 `Z x.xx` 标签；初始化后立即显示，并在每次 `zoomend` 后更新；行政级别面包屑不再重复显示缩放信息
- 目标区域：地图中心点落在哪个子区域进哪个（射线法）
- 自动切换不重排视野，只换边界层与面包屑；点击下钻保持 flyTo 动画

## 4. 数据现状与约束

### 4.1 已有数据

| 数据 | 位置 | 说明 |
|---|---|---|
| 省/市/县/乡边界 + 村点位 | `01-行政区划/浙江四级边界加村点/` | 省界 GeoJSON + 11 地市 zip 包（锐多宝，2020~2023 年数据） |
| 村界面数据 | `01-行政区划/浙江村界数据/` | 3 份 Shapefile，采用第 3 份"备注省市县乡"版（440MB，CGCS2000 / EPSG:4490） |
| 遥感影像 | `05-遥感数据/` | 吉林一号 0.5m 影像一景（845MB TIF，2025-04-02，0% 云量，覆盖绍兴上虞约 5km×5km） |
| 参考截图 | `参考截图/` | 17 张，作为 UI 与功能参照 |

### 4.2 村界 SHP 字段（已验证 2026-07-29）

DBF 实测字段：`省级`、`市级`、`市代码`、`区县级`、`区县码`、`乡镇级`、`乡镇码`、`村级`、`村代码`（另有 `省代码` 为冗余浮点列，弃用）。共 **34,225 条村记录**，编码均为 12 位（如 上浦镇 = `330604102000`），与锐多宝乡级 `code` 同体系，可直接关联。

### 4.3 四级边界 GeoJSON 结构（已验证 2026-07-29）

- 省/市/县级：含 `地名`、`区划码`、`县级码`(6 位) 等完整字段；绍兴实测 6 区县、119 乡镇，与官方数量吻合
- 乡级：含 `name` + 12 位 `code`
- ⚠️ **含冗余 `geom` 属性**（PostGIS WKB 十六进制串，约占文件一半体积），预处理时必须剥离
- 压缩包内 `村位置_点数据` 本需求不使用

### 4.4 编码一致性校验结论（已验证 2026-07-29，`scripts/check-codes.py`）

| 检查项 | 结果 |
|---|---|
| 乡级 12 位编码直接匹配 | **1379 / 1390（99.2%）**，0 例同名异码 |
| 锐多宝有、SHP 无 | 11 个，均为中心城区街道（古荡、鼓楼等，无村域，农险场景无影响） |
| SHP 有、锐多宝无 | 0 |
| 演示路径 | 上浦镇两边均为 `330604102000`，下辖 13 村；上虞区 21 乡镇、423 村 |

### 4.5 AI 地块识别试点（2026-07-29）

- 工具：Delineate Anything v2（AGPL-3.0），作为仓库外离线预处理工具
- 输入：吉林一号 0.5m、4 波段 UTM 影像，模型读取真彩波段 `[3,2,1]`
- 试点：龙江村 `330604102014`，裁片 4821×5043（村界外扩 128m）
- 运行：CPU 推理 2143 秒，原始识别 2477 个面；裁回村界并过滤 `<200㎡` 和 `>10ha` 后保留 1533 个演示地块
- 产物：`web/public/data/parcels/{村代码}.geojson`，与影像派生瓦片一样不提交、不公开分发
- 定位：零样本 AI 演示结果，不是确权、承保或测绘成果
- 业务筛选口径：目标为影像上用于农业种植的田块候选，宽口径包含在种、翻耕、规则裸地、休耕及疑似待耕田块；果园、茶园暂不纳入
- 人工筛选：前端可在本机隐藏森林、房屋等误识别面；隐藏结果只影响当前浏览器展示，清除浏览器数据后丢失
- 地块面积：预处理为每个地块写入平方米、亩（`1亩=666.6667㎡`）和内部标注点；地图在 z≥18.5 时只为当前视野内地块显示“X.XX 亩”，缩小后隐藏标签，降低文字拥挤和重叠
- 数据安全：重新导出或补充面积前必须备份当前前端 GeoJSON 和模型 GPKG，并记录文件大小、SHA-256 与恢复说明；面积补充不得改变地块数量、ID、顺序和几何

### 4.6 硬约束

1. **坐标系无需纠偏**：村界 SHP 为 CGCS2000（EPSG:4490），与天地图同源；GeoJSON 为 WGS84，两者偏差在厘米级，直接叠加
2. **村界不可全量加载**：440MB SHP 必须预处理后按乡拆分，前端按需请求
3. **遥感 TIF 浏览器不可直读**：845MB 16bit 4 波段 TIF 必须预切片为 XYZ 瓦片（需 GDAL 或 Python rasterio）
4. **版权限制**：锐多宝边界数据仅限学术研究；本期为内部验证可接受，**对外演示或上正式环境前必须取得授权**
5. **村点 ≠ 村界**：锐多宝包内村点位不代表村域范围，禁止用村点生成伪村界；村界一律使用 Shapefile 数据

### 4.7 已知风险

- ✅ ~~编码一致性~~：已验证通过，见 4.4
- ✅ ~~区划年代错配~~（已修复 2026-07-29）：县级层是 2023 数据、乡级层是 2020 数据，区划调整（撤销下城区/江干区、新设临平/钱塘/龙港）导致 41 个乡按编码归错县或不可达；预处理已改为**质心空间归属**（乡质心落在哪个县就归哪个县），村界文件按乡码命名不受影响
- ⚠️ **影像覆盖范围有限**：吉林一号高分影像仅一景（绍兴上虞约 5km×5km）。全省均可下钻看边界（天地图影像底图本身覆盖全省），只有示范区的村叠加 0.5m 高分影像；范围外的村静默不叠加
- ⚠️ 锐多宝 README 指出其 `cuncode` 大量重复不可靠，村代码一律以村界 SHP 的 `村代码` 为准
- ⚠️ **几何套合未验证**：村界面是否落在乡界内、与天地图叠加是否有肉眼可见偏移，预处理时抽查（原《基础校验结果.md》同列为未检项）
