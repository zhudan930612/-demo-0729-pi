# 演示demo方案

**方案说明**：本方案按"没有台风（平时）→ 台风邻近（预警期）→ 台风过后（灾后）"三个阶段描述需求。贯穿主线为五步业务闭环：多元数据接入 → 综合分析 → 任务生成派发 → 协保员实地取证 → 回传校验留存。执行角色统一为协保员，灾害信息员是补充协保员的来源之一。

---

## 一、阶段一：没有台风（平时）

**业务闭环**：监测 → AI 自动识别异常 → 系统提示 → 一键转任务（人工确认）→ 优先派发重点对象 → 协保员现场核查/处置回传 → 证据留痕。

**需求描述**：

1. **日常监测**：对承保区域进行遥感长势监测、病虫害监测，并提供重点对象名单标记。
2. **异常自动识别与提示**：AI 自动识别长势偏差、疑似病虫害等异常，系统自动提示（大屏高亮 + 异常列表），并展示判断依据（遥感影像、气象/物候数据）。
3. **一键转任务**：异常提示后可一键转为核查任务（人工确认），任务带 SOP 动作与执行要求。
4. **重点对象优先派发**：重点对象为**任务派发的优先级标签**（非独立监测/触发源）；任务触发后优先派发给重点对象（名单含风险标签：历史理赔异常、面积与地块不符、多保重保等）。因**线下核查人力资源有限**，先核重点对象。
5. **农事节点任务**：按农事时间节点计划下发任务（如打药时期打药核查），不依赖异常、主动取证留痕；同样优先派发给重点对象。
6. **协保员执行取证**：协保员通过小程序接收任务，现场拍照、定位、时间留痕，完成规定动作（如核查是否用足农药、农药瓶拍照上传）；未正常打药留痕标记。
7. **结果呈现与留痕**：已完成任务的照片/证据可点击查看；任务全程记录进入证据链。

**业务价值**：平时积累的取证证据（如未正常打药导致长势不好）在后续理赔中可引用，**区分管理不善与灾害责任**（与阶段二"通知加固大棚取证"同一套举证逻辑）。

---

## 二、阶段二：台风邻近（预警期）

**核心诉求**：帮助保险公司分析**哪些区域未来可能受灾**，提前做准备；提供**灾损预评估统计**（预估受灾面积、赔偿金额、户数等）。

**需求描述**：

1. **台风与降雨可视化**：基于真实历史台风案例呈现台风轨迹（动态逼近），叠加**实况降雨图斑**（用历史降雨数据模拟实时）+ **未来预报降雨图斑**。
2. **预警自动触发**：根据**台风临近情况 + 预报降雨**，系统自动触发预警提示（无需人工操作）——影响区域高亮 + 预警列表（哪些乡镇/村可能受灾）。
3. **灾损预评估**：提供受影响区域 + **预估受灾面积（万亩）、预估涉及户数、预估赔偿金额（万元）**；按区域下钻可查看承保基础（承保面积、保额、户数）与预估口径（承保数据 × 风险等级 × 历史损失率，标注"预估"）。
4. **防灾减损任务下发**：
   - **预防指令类任务**：台风来前**通知农户加固大棚**等——任务含通知要点 + 取证要求，协保员现场通知农户并拍照取证；
   - **核查类任务**：抢收抢割核查、加固/物资核查。
5. **派发方式可切换**：支持"自动派发 / 人工派发"切换。
6. **协保员执行留痕**：已完成任务的照片/证据可点击查看。

**业务价值**：灾前知道"可能影响谁、大概赔多少"→ 提前准备（防灾减损动作 + 资金/人力准备）；**通知留痕可举证**——预估有风险 → 通知农户预防 → 农户不作为导致受灾扩大 → 取证形成"已通知 + 未采取预防措施"证据，**后续理赔时与农户协商**（损失扩大部分的责任与赔付口径）。

---

## 三、阶段三：台风过后（灾后）

**核心诉求**：快速掌握实际受灾情况，查勘取证形成可举证、可定损的证据链，支撑理赔处置。

**需求描述**：

1. **灾后遥感评估**：展示受灾范围、倒伏识别、损失分级。
2. **灾前/灾后对比**：**双图并列 + 横轴左右滑动**查看同一区域灾前灾后差异。
3. **预估 vs 实际对比**：阶段二灾前预估（受灾面积/赔偿金额）与灾后实际评估结果数字对比。
4. **查勘任务**：自动生成并派发查勘/取证任务，协保员现场查勘拍照取证（已完成任务照片可点击查看）。
5. **证据链调取**：一张图/时间线调出全过程证据——平时监测取证（打药核查）→ 灾前减损与通知留痕 → 灾后查勘。
6. **报告输出**：生成查勘报告/证据链报告（含"已通知未预防""未正常打药"等举证点），支撑定损、争议处置与理赔协商。

**业务价值**：该赔的赔得清楚，不该赔的有据可拒。
