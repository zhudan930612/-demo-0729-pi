# 农险双精准地图 Demo —— 需求文档

> 版本：v1.4（2026-07-30 地块双向编辑）
> 状态：开发中

---

## 1. 项目背景

参照"参考截图"，搭建农业保险地图演示页面。**用途：内部技术验证**（非客户演示，UI 不追求大屏效果）。本期只做**基础地图下钻能力**，后续在此基础上叠加承保、理赔、长势等业务功能，因此要求工程化搭建。

## 2. 需求概述

以天地图**卫星影像**为底图，支持 **省 → 市 → 县 → 乡 → 村** 五级逐层下钻查看，每个层级展示对应行政边界；在乡一级可以看到该乡所有村的边界；到村一级时，若该村在示范区范围内，在底图上叠加吉林一号 0.5m 高分影像。龙江村试点叠加由 Delineate Anything v2 从影像自动识别的演示地块。村为下钻终点。

演示主线（边界下钻路径示例）：

```
浙江省 → 绍兴市 → 上虞区 → 上浦镇 → 某村
```

高分影像叠加演示路径（已实测影像覆盖范围 2026-07-29）：

```
浙江省 → 绍兴市 → 上虞区 → 章镇镇 → 龙江村/泰山村 等 11 村之一（叠加高分影像）
```

> 注：吉林一号影像实测覆盖上虞区**章镇镇**（11 村）和嵊州市**三界镇**（6 村），
> 不含上浦镇；上浦镇路径用于验证"无影像村静默不叠加"分支。

## 3. 功能需求

### 3.1 地图底图

- 天地图**卫星影像底图**（img_w）+ 影像注记（cia_w）
- Token 从 `.env.local` 读取（已有 `TIANDITU_TOKEN`）
- 演示环境有网，天地图在线服务可用，不做离线兜底

### 3.2 五级下钻

| 当前层级 | 地图显示 | 点击行为 |
|---|---|---|
| 省 | 浙江省全图 + 11 个地市边界 | 点市 → 进入市级 |
| 市 | 该市范围 + 区县边界 | 点县 → 进入县级 |
| 县 | 该县范围 + 乡镇边界 | 点乡 → 进入乡级 |
| 乡 | 该乡范围 + **全部村界** + 吉林一号高分影像（若该乡与影像相交） | 点村 → 进入村级 |
| 村 | 该村范围 + **叠加吉林一号高分影像**（若覆盖）+ AI 识别地块（有产物时） | 无（村为终点，不再响应点击） |

- 顶部面包屑导航（如：浙江省 / 绍兴市 / 上虞区 / 上浦镇 / 某村），可回跳任意层级
- 左上角"回到上级"按钮（截图同款）
- 乡镇/村级高分影像：当前乡镇或村范围与影像覆盖范围相交时，**半透明叠加**在天地图影像底图之上（非替换底图），通过右下角眼睛图标开关；开启时固定 70% 不透明度；进入相交乡镇且当前缩放低于 z13 时自动抬升到 z13 以保证影像可见
- 影像未覆盖的村：不叠加影像，照常显示村界，左下角**文字角标**提示"该村不在高分影像覆盖范围内"（不弹窗）
- 村界加载：**按需加载**——进入乡级时才请求该乡的村界 GeoJSON，不做全省一次性加载
- 地块：只在村级按村代码加载；正常模式下浅蓝色半透明展示、不响应点击；有地块数据时显示独立地块图标按钮；用户界面统一使用“地块”，不显示“AI识别”或“候选”等字样
- 地块统计：地块图层开启时，左下角内容自适应宽度的紧凑卡片显示“当前地块 / 合计面积”，不显示卡片标题，卡片底部与右侧缩放控件水平对齐；影像说明合并到卡片底部；仅汇总本机未隐藏地块，保存更改后实时更新，关闭地块图层时同步隐藏；无地块数据时影像说明仍单独显示
- 本机地块编辑：仅当地块图层处于显示状态时，右上角显示“编辑地块”；进入后保持当前地图中心和缩放不变。点击普通可见地块标记为“待隐藏”，点击本机已隐藏地块标记为“待恢复”，再次点击取消对应标记。右上角工具栏显示“已隐藏 N / 全部恢复 / 待隐藏 N / 待恢复 N / 保存更改 / 取消”
- 保存与恢复：保存时按“原隐藏地块 + 待隐藏地块 - 待恢复地块”计算最终隐藏集合，并按村写入当前浏览器 `localStorage`；不修改原始 GeoJSON、不上传服务器、不记录隐藏原因。保存后退出编辑模式并提示本次隐藏、恢复数量；保存失败时保留本轮选择。“全部恢复”将当前村所有已隐藏地块标记为待恢复，仍需点击“保存更改”才生效；取消编辑不修改已有记录
- 编辑展示：编辑模式使用半透明深色遮罩降低影像底图干扰；普通地块为高对比青蓝边界，待隐藏为红橙色，已隐藏为黄色粗虚线和淡黄色填充，待恢复为绿色实线和淡绿色填充；悬停提示当前可执行的隐藏、恢复或取消操作；正常模式样式不变并继续过滤已隐藏地块
- 编辑视野：进入编辑时保持当前视角不变，编辑期间最小缩放固定为 z=15.25（高于村级 z≤15.0 的自动退出阈值）；允许平移、放大及缩小到该下限，但禁止自动返回上一层级；保存或取消后恢复原缩放规则

### 3.3 交互动效（内部验证版，精简动效）

1. **悬停高亮**：鼠标移入任一子区域时，该区域边界加粗点亮，并显示区域名称标签
2. **下钻/返回动效**：Leaflet flyToBounds 平滑飞入/飞出（约 1 秒），不做边界交错淡入和选中闪烁
3. **边界样式**：五级统一主题色，仅以线宽区分层级

### 3.4 缩放下钻（2026-07-29 追加）

除点击下钻外，支持通过缩放自动进出层级：

| 当前层级 | 放大自动进入 | 缩小自动退回 |
|---|---|---|
| 省 | z≥9.5 → 进中心点所在市 | — |
| 市 | z≥11.5 → 进县 | z≤9.0 → 退省 |
| 县 | z≥13.5 → 进乡 | z≤11.0 → 退市 |
| 乡 | z≥15.5 → 进中心点所在村 | z≤13.0 → 退县 |
| 村 | — | z≤15.0 → 退乡 |

- 判定时机：仅在 zoomend 触发，平移不触发；进入/退出阈值差 0.5 级防抖
- 目标区域：地图中心点落在哪个子区域进哪个（射线法）
- 自动切换不重排视野，只换边界层与面包屑；点击下钻保持 flyTo 动画

## 4. 数据现状与约束

### 4.1 已有数据

| 数据 | 位置 | 说明 |
|---|---|---|
| 省/市/县/乡边界 + 村点位 | `01-行政区划/浙江四级边界加村点/` | 省界 GeoJSON + 11 地市 zip 包（锐多宝，2020~2023 年数据） |
| 村界面数据 | `01-行政区划/浙江村界数据/` | 3 份 Shapefile，采用第 3 份"备注省市县乡"版（440MB，CGCS2000 / EPSG:4490） |
| 遥感影像 | `05-遥感数据/` | 吉林一号 0.5m 影像一景（845MB TIF，2025-04-02，0% 云量，覆盖绍兴上虞约 5km×5km） |
| 参考截图 | `参考截图/` | 17 张，作为 UI 与功能参照 |

### 4.2 村界 SHP 字段（已验证 2026-07-29）

DBF 实测字段：`省级`、`市级`、`市代码`、`区县级`、`区县码`、`乡镇级`、`乡镇码`、`村级`、`村代码`（另有 `省代码` 为冗余浮点列，弃用）。共 **34,225 条村记录**，编码均为 12 位（如 上浦镇 = `330604102000`），与锐多宝乡级 `code` 同体系，可直接关联。

### 4.3 四级边界 GeoJSON 结构（已验证 2026-07-29）

- 省/市/县级：含 `地名`、`区划码`、`县级码`(6 位) 等完整字段；绍兴实测 6 区县、119 乡镇，与官方数量吻合
- 乡级：含 `name` + 12 位 `code`
- ⚠️ **含冗余 `geom` 属性**（PostGIS WKB 十六进制串，约占文件一半体积），预处理时必须剥离
- 压缩包内 `村位置_点数据` 本需求不使用

### 4.4 编码一致性校验结论（已验证 2026-07-29，`scripts/check-codes.py`）

| 检查项 | 结果 |
|---|---|
| 乡级 12 位编码直接匹配 | **1379 / 1390（99.2%）**，0 例同名异码 |
| 锐多宝有、SHP 无 | 11 个，均为中心城区街道（古荡、鼓楼等，无村域，农险场景无影响） |
| SHP 有、锐多宝无 | 0 |
| 演示路径 | 上浦镇两边均为 `330604102000`，下辖 13 村；上虞区 21 乡镇、423 村 |

### 4.5 AI 地块识别试点（2026-07-29）

- 工具：Delineate Anything v2（AGPL-3.0），作为仓库外离线预处理工具
- 输入：吉林一号 0.5m、4 波段 UTM 影像，模型读取真彩波段 `[3,2,1]`
- 试点：龙江村 `330604102014`，裁片 4821×5043（村界外扩 128m）
- 运行：CPU 推理 2143 秒，原始识别 2477 个面；裁回村界并过滤 `<200㎡` 和 `>10ha` 后保留 1533 个演示地块
- 产物：`web/public/data/parcels/{村代码}.geojson`，与影像派生瓦片一样不提交、不公开分发
- 定位：零样本 AI 演示结果，不是确权、承保或测绘成果
- 业务筛选口径：目标为影像上用于农业种植的田块候选，宽口径包含在种、翻耕、规则裸地、休耕及疑似待耕田块；果园、茶园暂不纳入
- 人工筛选：前端可在本机隐藏森林、房屋等误识别面；隐藏结果只影响当前浏览器展示，清除浏览器数据后丢失
- 地块面积：预处理为每个地块写入平方米、亩（`1亩=666.6667㎡`）和内部标注点；地图在 z≥18.5 时只为当前视野内地块显示“X.XX 亩”，缩小后隐藏标签，降低文字拥挤和重叠
- 数据安全：重新导出或补充面积前必须备份当前前端 GeoJSON 和模型 GPKG，并记录文件大小、SHA-256 与恢复说明；面积补充不得改变地块数量、ID、顺序和几何

### 4.6 硬约束

1. **坐标系无需纠偏**：村界 SHP 为 CGCS2000（EPSG:4490），与天地图同源；GeoJSON 为 WGS84，两者偏差在厘米级，直接叠加
2. **村界不可全量加载**：440MB SHP 必须预处理后按乡拆分，前端按需请求
3. **遥感 TIF 浏览器不可直读**：845MB 16bit 4 波段 TIF 必须预切片为 XYZ 瓦片（需 GDAL 或 Python rasterio）
4. **版权限制**：锐多宝边界数据仅限学术研究；本期为内部验证可接受，**对外演示或上正式环境前必须取得授权**
5. **村点 ≠ 村界**：锐多宝包内村点位不代表村域范围，禁止用村点生成伪村界；村界一律使用 Shapefile 数据

### 4.7 已知风险

- ✅ ~~编码一致性~~：已验证通过，见 4.4
- ✅ ~~区划年代错配~~（已修复 2026-07-29）：县级层是 2023 数据、乡级层是 2020 数据，区划调整（撤销下城区/江干区、新设临平/钱塘/龙港）导致 41 个乡按编码归错县或不可达；预处理已改为**质心空间归属**（乡质心落在哪个县就归哪个县），村界文件按乡码命名不受影响
- ⚠️ **影像覆盖范围有限**：吉林一号高分影像仅一景（绍兴上虞约 5km×5km）。全省均可下钻看边界（天地图影像底图本身覆盖全省），只有示范区的村叠加 0.5m 高分影像；范围外的村静默不叠加
- ⚠️ 锐多宝 README 指出其 `cuncode` 大量重复不可靠，村代码一律以村界 SHP 的 `村代码` 为准
- ⚠️ **几何套合未验证**：村界面是否落在乡界内、与天地图叠加是否有肉眼可见偏移，预处理时抽查（原《基础校验结果.md》同列为未检项）

## 5. 技术方案

### 5.1 技术栈

- **前端**：Vue 3 + Vite + TypeScript + Leaflet + Pinia（pnpm）
- **数据预处理**：Python 一次性脚本，产物为静态文件，无需后端

### 5.2 目录结构（规划）

```
农险demo开发0729-pi/
├── scripts/                    # 数据预处理与校验
│   ├── check-codes.py          # ✅ 编码一致性校验（已跑通）
│   ├── validate-data.py        # ✅ 数据链路校验（13 项，模拟五级下钻）
│   ├── prepare-boundaries.py   # 解压 zip → 剥离冗余 geom → 按层级拆分 GeoJSON
│   │                           # 村界 SHP → 按乡镇码拆分 + 简化(约1m精度)
│   ├── prepare-rs-tiles.py     # TIF → 8bit 真彩 → XYZ 瓦片(z13~z19)
│   └── prepare-parcel-pilot.py # 龙江村裁片 + 模型结果裁界/过滤/导出
├── web/                        # Vue3 前端工程
│   ├── public/
│   │   ├── data/
│   │   │   ├── manifest.json       # 五级层级树（代码/名称/上下级/bbox）
│   │   │   ├── boundary/{level}/{code}.geojson
│   │   │   └── villages/{乡镇码}.geojson
│   │   └── tiles/rs/{z}/{x}/{y}.png
│   └── src/
│       ├── stores/drilldown.ts     # 下钻状态栈
│       ├── api/tianditu.ts         # 影像底图与注记
│       └── components/
│           ├── MapView.vue
│           ├── Breadcrumb.vue
│           ├── BoundaryLayer.vue
│           └── RsOverlay.vue       # 高分影像叠加 + 透明度滑块
└── docs/需求文档.md
```

### 5.3 动效实现要点

- 平滑缩放：Leaflet `flyToBounds`，时长约 1s（下钻与返回复用同一动效）
- 悬停高亮：stroke 加粗 + tooltip 显示区域名
- 边界样式：统一主题色，线宽随层级递减

## 7. 验收标准

1. 天地图影像底图正常加载，五级下钻全链路可走通（省→市→县→乡→村）
2. 每个层级边界显示正确，村界仅在进入乡级后按需加载
3. 高分影像路径（浙江→绍兴→上虞→章镇镇→龙江村等）从章镇镇乡镇级开始可见吉林一号高分影像叠加，乡镇/村级均可通过眼睛图标开关
4. 悬停高亮、flyTo 飞入/飞出动效生效，交互无卡顿
5. 影像未覆盖的村进入后正常显示村界、无报错、左下角角标提示无影像
6. 进入龙江村时按需加载 1533 个浅蓝演示地块；独立地块按钮可切换显隐，不影响高分影像；正常模式无点击/悬停交互
7. 地块图层显示时右上角可进入编辑模式；普通地块可多选为待隐藏，已隐藏地块可多选为待恢复，再次点击可取消标记；保存后结果立即生效，刷新页面后仍保持本机结果
8. 进入编辑模式时地图视角不移动；可缩小到固定下限 z=15.25，但不能继续缩小或自动返回乡级，保存或取消后恢复原缩放层级规则
9. 编辑模式展示全部原始地块；普通、待隐藏、已隐藏、待恢复样式明显不同，工具栏分别显示已隐藏、待隐藏和待恢复数量；悬停能识别当前点击操作
10. 点击“全部恢复”后，当前村所有已隐藏地块变为绿色待恢复状态；点击“保存更改”后才清空其本机隐藏记录，点击“取消”则不生效；原始 GeoJSON 始终不被修改
11. 所有地块均包含有效的 `area_m2`、`area_mu` 和内部标注点；z≥18.5 时当前视野地块显示亩数，缩小后标签消失
12. 面积处理前备份可按恢复说明还原；处理前后 1533 个地块的数量、ID、顺序和几何完全一致
13. 地块图层开启时显示“当前地块”和“合计面积”，仅统计本机未隐藏地块；隐藏、逐块恢复、全部恢复保存及图层开关后显示状态正确
14. 预处理脚本可重复执行，产物全静态
