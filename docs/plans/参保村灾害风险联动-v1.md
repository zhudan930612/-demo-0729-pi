## 4. 关键实现决策（实施中定稿）

- **月份→阶段列映射**（M2 单测锁定）：3/4/5 月→苗期/分蘖列；6 月→孕穗/抽穗扬花列；7 月→成熟收获期列（收获最敏感，覆盖灌浆）；8 月→苗期/分蘖列（分蘖主导）；9 月→孕穗/抽穗扬花列；10 月→灌浆期列；11 月→成熟收获期列；12~2 月→冬闲（措施"非水稻生长期"）。
- **台风点-线段距离**：预测点连线分段，村质心到每段的最短大圆距离 ≤50km → 信号 2；强热带风暴及以上（wind ≥24.5m/s 或强度文本含"强热带风暴"及以上）→ 3。
- **综合算法**：`综合 = max(P,T)`；W>0 → +1 封顶 3；红警 → 3；P≥2 且 T≥2 → 3（需求 §3.2）。
- **数据失效降级**：台风不可用 → 只用降水+预警，依据区标注"台风数据暂不可用"；预警不可用 → 只用降水+台风；全不可用 → "风险暂不可评定"。
- **卡片**：360px 白卡 + 3px 蓝边框 + 蓝底白字头部 + 贴村右侧 12px（不足切左）；措施 ▸ 单行（高/中≤3 条，低/无 1~2 条）；底部"风险按预报窗口峰值定级…仅供参考"。
- **风险等级固定**：随数据快照重算，不随日期切换/播放变化（标注颜色不变）；7 天趋势展开项随选中日高亮。
