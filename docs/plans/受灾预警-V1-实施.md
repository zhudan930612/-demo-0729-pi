## 0. 形态预检结论（2026-08-27，已用户确认，编码前置条件）

用**真实数据**跑通后拍板，三项已写回需求文档 A4/C3 与验收清单：

1. **阈值重校（方案 C）**：低 ≥130 / 中 ≥160 / 高 ≥185 mm 未来 24h 预报雨量。
   依据：398 个真实 ERA5 格点 × 窗口内 71 个巴威节点 × 33898 村面，**全省全窗口未来 24h 最大值仅 191.8mm**。
   原稿 ≥50/≥100/≥150 会使峰值 **24823 村（73% 全省）进入预警**、高风险 3434 村、一键派发约 9000 条任务 → 形态不可用。
   方案 C 实测：峰值节点 2026-07-11 06时 预警村 **4823（14.2%）** = 高 281 · 中 1031 · 低 3511；27/71 节点有预警；
   高风险峰值 444 村；全窗口曾达 高 444 / 中 1918 / 低 2525；一键派发峰值约 1593 条；省/市级聚合徽标 11 个区县
   （乐清 463 村·高、仙居 266·中、黄岩 202·高、临海 149·中、宁海 86、天台 62、洞头 34、永嘉 32…）。
2. **村驻地点位走空间连接**（新增 R3-23）：源点位 25475 条，`cuncode` 退化不可用、名称与村面异年代（三元组名称匹配仅 46.3%）。
   采用 村面内含点位 52.4% + 同县同乡归一化名称 4.6% + 质心 1.5km 最近点位 26.9% = **83.9% 真实驻地**，
   剩余 16.1%（5447 村）用村面质心兜底，逐村记 `seatSource ∈ {seat,name,nearest,centroid}`。
3. **承保造数规模锚定**（新增 R4-8）：全省 33898 村承保面积总量 **1100~1300 万亩**（2025 浙江粮食播种面积 1584.6 万亩）、
   村均 325~384 亩、长尾分布、保额沿用 1250 元/亩；13 个真实参保村用真实数据不覆盖；确定性种子（`stable_seed` 模式）。
   禁止按龙江村真实 2882 亩量级平铺（→ 9800 万亩，超粮食播种面积 6 倍）。

其他实测事实（编码可直接依赖，不必重测）：

- 巴威 `no1=3257931`（2609），上游 168 节点、2026-07-02 08时 ~ 07-14 19时；**影响窗口内 71 节点**（间隔 3h×12 + 1h×58）。
- 上游字段为 `time_ymdh`（前端 `typhoonAdapter.ts:78` 已映射为内部 `timeYmdh`）。
- ERA5 archive：多坐标逗号分隔返回 JSON 数组；**返回的 lat/lon 是吸附后的真实格点、非 0.25 整数倍**（如请求 28.11,121.23 → 28.084,121.220）；
  399 请求点去重后 398 唯一节点；`grid=` 参数被忽略。分块 50 点/请求，全网格 15s 拉完。
- 影响窗口过程累计（7/9 00 ~ 7/13 00）：玉环 174.6 / 温州 164.1 / 杭州 51.7 mm；
  地市村均 台州 145.5 > 温州 137.3 > 丽水 93.1 > 金华 91.7 > 衢州 70.7 ≈ 宁波 70.5 > 杭州 65.1 ≈ 绍兴 64.9 > 湖州 41.5 > 嘉兴 30.6 > 舟山 24.1（满足 R2-16）。
- 区县政府位置：`server/data/government-seats-v1.json` 有 90 个 county 条目（聚合徽标落点可直接用，缺源数据时按需求回退边界质心）。
- `web/public/data/` 已 gitignore（产物可重生成），版本化资产是 `scripts/`。

## 5. 风险与对策

| 风险 | 对策 |
|---|---|
| 台风播放控制器不循环，直接复用会导致播放到末节点停住（违反 R2-4） | 在受灾预警装配层包 wrap：末节点 onComplete 后重置到首节点并触发演示状态全部重置（R5-7） |
| 33898 村 × 71 节点静态产物体积 | 按节点存「预警村索引 + 等级」而非全量矩阵；无风险村不入表（峰值仅 4823 村有预警） |
| 峰值 4823 村列表 + 1593 条任务的前端渲染压力 | 列表默认 10 条 + 抽屉；抽屉内必须虚拟滚动或分页（对齐农情「全部任务」抽屉既有实现） |
| `agriMonitoring.spec.ts:102-103` 断言失效 | T3 同批改断言，并补受灾预警入口 spec |
| ERA5 格点近似（一格约 85 村同值） | 文档与 UI 不表述为村精确雨量（需求 C3 已标注） |
