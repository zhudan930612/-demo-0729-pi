## 0. 形态预检结论（2026-08-27，已用户确认，编码前置条件）

用**真实数据**跑通后拍板，三项已写回需求文档 A4/C3 与验收清单：

1. **阈值重校（方案 C）**：低 ≥130 / 中 ≥160 / 高 ≥185 mm 未来 24h 预报雨量。
   依据：398 个真实 ERA5 格点 × 窗口内 71 个巴威节点 × 33898 村面，**全省全窗口未来 24h 最大值仅 191.8mm**。
   原稿 ≥50/≥100/≥150 会使峰值 **24823 村（73% 全省）进入预警**、高风险 3434 村、一键派发约 9000 条任务 → 形态不可用。
   方案 C 实测：峰值节点 2026-07-11 06时 预警村 **4823（14.2%）** = 高 281 · 中 1031 · 低 3511；27/71 节点有预警；
   高风险峰值 444 村；全窗口曾达 高 444 / 中 1918 / 低 2525；一键派发峰值约 1593 条；省/市级聚合徽标 11 个区县
   （乐清 463 村·高、仙居 266·中、黄岩 202·高、临海 149·中、宁海 86、天台 62、洞头 34、永嘉 32…）。
2. **村驻地点位走空间连接**（新增 R3-23）：源点位 25475 条，`cuncode` 退化不可用、名称与村面异年代（三元组名称匹配仅 46.3%）。
   采用 村面内含点位 52.4% + 同县同乡归一化名称 4.6% + 质心 1.5km 最近点位 26.9% = **83.9% 真实驻地**，
   剩余 16.1%（5447 村）用村面质心兜底，逐村记 `seatSource ∈ {seat,name,nearest,centroid}`。
3. **承保造数规模锚定**（新增 R4-8）：全省 33898 村承保面积总量 **1100~1300 万亩**（2025 浙江粮食播种面积 1584.6 万亩）、

## 6. 数据契约（冻结，波1 两个编码 agent 共同遵守）

产物目录 `web/public/data/disaster/`（gitignored，可重生成；版本化资产是 `scripts/`）。
所有时间戳一律北京时间字符串 `"YYYY-MM-DD HH:00:00"`，与上游 `time_ymdh` 同格式。

### 6.1 `track.json` — 巴威轨迹固化（R2-17）
**保持上游 APIHz 原始字段名**，使 `features/typhoon/typhoonAdapter.ts` 零改动消费：
```jsonc
{ "code":200, "no1":"3257931", "no2":"2609", "no3":"2609", "no4":"",
  "namecn":"巴威", "nameen":"BAVI", "explanation":"位于越南北部的山脉", "type":"stop",
  "datas":[ { "time_ymdh":"2026-07-09 00:00:00", "lat":.., "lon":.., "position_text":"..",
              "intensity_code":"SuperTY", "intensity_text":"..", "pressure_hpa":.., "wind_speed_ms":..,
              "intensity_desc":"..", "move_dir_code":.., "move_dir_text":"..", "move_speed_kmh":.., "move_desc":"..",
              "wind_radius":[{"grade":7,"grade_text":"..","grade_desc":"..","ne_radius_km":..,"se_radius_km":..,"sw_radius_km":..,"nw_radius_km":..,"avg_radius_km":..}] } ] }
```
`datas` = 影响窗口内 **71 个**节点（上游 168 节点过滤 `2026-07-09 00:00:00` ~ `2026-07-13 00:00:00`），按时间升序。节点数组下标 `i` 即播放帧号。

### 6.2 `precip.json` — 每节点过程累计雨量网格（R2-14/R2-15）
```jsonc
{ "schemaVersion":1, "model":"ERA5 0.25° (Open-Meteo archive)",
  "aggregateFrom":"2026-07-09 00:00:00",
  "nodeTimes":["2026-07-09 00:00:00", "... 共 71 项，与 track.datas 一一对应"],
  "grid":[ { "lat":26.960, "lon":117.969, "cum":[0.0, 0.0, "... 71 项，单位 mm"] } ] }
```
- `grid` = **398 个真实 ERA5 节点**，`lat/lon` 用**接口返回的吸附值**（不是请求值、不是 0.25 整数倍）。
- `cum[i]` = 自 `aggregateFrom` 累计至 `nodeTimes[i]` 时刻（含该小时），**单调不减**。
- 前端适配为现有 `PrecipitationSnapshot` 复用渲染：每帧构造 `{grid:[{lat,lon,values:{d1:cum[i],…d7:cum[i]}}], days:[t,…7], coveredDays:1, model, updatedAt:t, aggregateFrom}` + `setDay('d1')`；
  **允许对 `map/precipitationLayerController.ts` 做最小参数化扩展**（如允许自定义值键），但**不得改变现有降水模式行为**（`precipitationLayerController.spec.ts` 与 `e2e/precipitation.spec.ts` 必须继续通过）。配色/图例/悬停/pane(395) 一律复用，禁止复制粘贴 `LEVEL_STOPS`。

### 6.3 `warnings.json` — 每节点村级预警清单（R3-5/R3-21/R3-23）
```jsonc
{ "schemaVersion":1,
  "thresholds":{"low":130,"mid":160,"high":185}, "hysteresisNodes":2,
  "nodeTimes":["... 71 项"],
  "villages":[ { "code":"330382…", "name":"…", "cityCode":"330300","countyCode":"330382","townshipCode":"330382001000",
                 "lon":120.5,"lat":28.3, "seatSource":"seat" } ],
  "nodes":[ { "i":0, "w":[ [0,1], [7,2], [13,3] ] } ] }
```
- `villages` **只含全窗口曾经达到低/中/高任一档的村**（实测基线 4887 村：高444+中1918+低2525），不含无风险村。
- `w` = `[村索引, 等级]`，等级 `1=低 2=中 3=高`；**无风险村不入表**（该节点无条目即无风险）。
- 等级已含**滞回防抖**：升级立即生效；降级需连续 2 个节点低于当前档阈值才生效。
- `lon/lat` = 脉冲标记落点（村政府驻地，空间连接结果）；`seatSource ∈ {seat,name,nearest,centroid}`。

### 6.4 `village-seats.json` — 全省村驻地产物（R3-23）
33898 村全量：`{ "code","name","townshipCode","lon","lat","seatSource" }` + 顶层 `stats` 记录四类占比（基线 seat 52.4% / name 4.6% / nearest 26.9% / centroid 16.1%）。
空间连接顺序（不可调换）：**① 点位落在村面内**（多点位取距村面质心最近者）→ **② 同县+同乡归一化名称匹配**（且距质心 <0.05°）→ **③ 质心 1.5km 内最近点位** → **④ 村面多边形质心兜底**。
名称归一化：去空白与 `（）()·、-_`，循环剥离后缀 `村民委员会/居委会/社区居民委员会/村委会/社区/街道/村/组`（长度 >2 才剥）。
**禁止**用村点生成伪村界；`centroid` 不得表述为确权驻地。

### 6.5 `underwriting.json` — 村级承保口径（R4-4/R4-5/R4-8）
```jsonc
{ "schemaVersion":1, "seed":"stable_seed(villageCode)", "unit":{"area":"亩","sumInsured":"元","rate":"元/亩"},
  "sumInsuredPerMu":1250,
  "villages":[ { "code":"…", "insuredAreaMu":318.4, "householdCount":96, "sumInsuredYuan":398000, "source":"mock" } ] }
```
- 覆盖全省 33898 村；**13 个真实参保村用现有保单口径真实值**（`/business/policy-{code}.json` 汇总，`source":"real"`），不得被造数覆盖。
- 造数目标：全省 `insuredAreaMu` 合计落在 **1100~1300 万亩**、村均 325~384 亩、长尾（少数大村 + 大量小村）；`householdCount` 与面积正相关且带抖动；`sumInsuredYuan = insuredAreaMu × 1250`。
- 必须确定性：同一 `stable_seed` 约定重跑结果逐字节一致。

### 6.6 灾损预估口径（R4-4/R4-5，登记 ADR）
需求公式 `预估面积 = Σ(承保面积 × 村级风险系数 × 损失率)` 中「村级风险系数」在既有 village-risk 域只覆盖 13 参保村，且 `precipPeakLevel()` 分档（5/10/25mm）是为**逐日雨量**标定的，直接用于 4 天**过程累计**（最高 224mm）会把全省判成高风险。故本模式定义：
- **村级风险等级** ← 该节点**过程累计雨量**分档：`<50mm=无(0) / 50–100=低(1) / 100–150=中(2) / ≥150=高(3)`；风险系数 `无0.2 / 低0.4 / 中0.7 / 高1.0`。
- **损失率** ← 该节点**预警等级** mock：`低 3% / 中 8% / 高 15%`（高>中>低，满足 R4-5）。
- 两个输入视角不重叠（已下多少 vs 还要下多少），与 A3「过程累计雨量」「未来 24h 预报雨量」双口径一致；系数映射由脚本导出留档。

### 6.7 区县级聚合徽标落点
`server/data/government-seats-v1.json` 的 90 个 `level=county` 条目与 `web/public/data/boundary/county/*.geojson` 的 90 个区县 code **一一对应（实测 90/90）**，直接按 `countyCode` 取 `point` 作徽标落点；缺失时回退区县边界质心。
