## 1. 目标与已确认范围

在"灾害风险"工具内新增"查看降水"子功能：Open-Meteo ECMWF 0.25° 网格数据源，浙江矩形 `118.0–123.0E × 27.0–31.5N` 共 399 点，未来 7 天（168h 逐小时）聚合为 7 段日累计；前端 canvas 连续色斑渐变渲染（全矩形 399 点 + 省界叠加，方案 A），地图底部时间轴（7 日期 + 点击切换 + 播放 1.2s/天），与五级行政下钻联动。

### 已确认决策（2026-08-10 用户逐项确认）

| 决策点 | 结论 |
| --- | --- |
| 数据源 | Open-Meteo ECMWF IFS 0.25°（免费无 key，非商业；天气数据 CC BY 4.0 须署名） |
| 分辨率 | **全省统一 0.25°/约 25 km，下钻保持统一、不更换数据源**（曾评估 GFS 0.117°/13 km 分级与全省 13 km，实测后放弃：全省 13 km 需 5 区分片拉取 + 429 限流 + 首载 15–30s + 10MB/2MB 体积；换源拼接不一致） |
| 灾害类型 | 暴雨/累计降雨（未来预报场）；洪水/干旱/地震不做 |
| 预报长度 | 未来 7 天逐小时（`forecast_hours=168`），聚合 7 段日累计 |
| 聚合口径 | 第 N 天 = 从当前整点小时起第 (N-1)×24+1 至 N×24 小时求和 |
| 呈现 | 连续色斑渐变（canvas 双线性插值到 0.05° 平滑 + 半透明叠加） |
| 色阶 | 中国气象局 24h 雨量等级（透明/浅绿/绿青/青蓝/蓝/紫/深紫；0.1/10/25/50/100/250mm） |
| 渲染范围 | 全省全矩形 399 点（含海域/邻省边缘）+ 省界线叠加；下钻保持统一分辨率，色斑连续 + 视口聚焦 + 行政面高亮（方案 A'），不裁剪、不换源 |
| 交互 | 地图底部时间轴 7 日期标签（日期+星期），点击切换，播放/暂停（1.2s/天，到第 7 天停止） |
| 入口与互斥 | "灾害风险"菜单新增"查看降水"；台风+降水可叠加（叠加时后进者接管相机、最后一个退出才恢复省界相机），天气与台风/降水互斥；进入切省级+全省视角 |
| 降级 | 上游失败：有缓存返回快照，无缓存"降水预报暂不可用"；不降级成"无降水" |

### 明确不做

- 不做洪水/干旱/地震、逐小时强度时间轴、历史回放、实况；
- 不接中国气象数据网/中央气象台受限数据；
- 不把插值平滑描述为真实更高分辨率；界面标注 0.25° 网格与 CC BY 署名；
- 不把预报场描述为实测/定损/理赔依据；
- 不改动"查看台风""查看天气"现有入口与互斥规则。

## 2. 当前实测与约束

1. **Open-Meteo 接口**（2026-08-10 实测）：`https://api.open-meteo.com/v1/forecast`，多位置 `latitude/longitude` 逗号配对，单请求 ≤1000 位置；浙江 399 点返回数组，每元素 `{latitude, longitude, hourly:{time[], precipitation[]}}`；`hourly=precipitation&forecast_days=1` 实测 **341 KB**；
2. **网格分布**（仓库省界求交实测）：399 点中 **153 点省内**、246 点省外（东海 34 / 福建 21 / 江西安徽 44 / 太湖江苏 21 / 包围盒内省界外 126）；省内范围 118.25–121.75E × 27.25–31.0N；
3. **预报长度**：Open-Meteo 默认 7 天、最长 16 天（`forecast_days` 0–16 / `forecast_hours` 精确控制）；小时序列从今日 0:00 起，聚合须从当前整点小时起算，避免把已过时次计入"未来累计"；
4. **响应体积**：168h × 399 点原始约 2.3 MB；服务端归一化为紧凑结构（去掉逐点重复字段名）后目标 ≤1 MB；必要时 gzip/brotli 压缩；
5. **免费层**：600/min、5,000/h、10,000/day、300,000/month；无 uptime 保证；进入模式 1 次 + 手动刷新，用量远低于限额；
6. **pane 约定**：注记 `pane 450`；天气标牌 455/456（高于注记）；台风 410–435；行政边界/影像为底图性质。降水色斑须**低于注记 450**且不遮挡行政边界与地块，建议 400–409 区间（实现时与边界 pane 协调）；
7. **现有入口**：`MapControlStack.vue` 的 typhoon-btn（"查看台风"）+ weather-btn 菜单（气象预警/实时天气）；互斥由 `MapView.vue` 装配控制；地块编辑态时入口禁用规则沿用；
8. **前端渲染约束**：`weatherMarkerLayerController` 的闭包快照清理教训——`clear()` 必须同时重置快照；播放计时器必须显式清除，退出后不得写入图层；
9. **分辨率评估实测（2026-08-10）**：GFS 0.117°（约 13 km）确认真实可用（请求 0.05° 密网格返回独立格点步长 0.117°）；但全省 1677 点超单请求上限需 5 区拉取，连续请求触发 429，7 天 gzip 约 2 MB；ECMWF 0.25° 399 点单请求 341 KB/24h 为统一方案依据。
9. 未跟踪受限数据不得提交：不提交 `.env.local`、Token、`web/public/data/`、`web/public/tiles/`、`web/dist/`。

## 3. 目标架构

```text
进入"查看降水"
  -> 前端请求 /api/precipitation-grid
  -> 服务端（无缓存/过期）请求 Open-Meteo ECMWF 0.25°（399 点，forecast_hours=168）
  -> 归一化 + 聚合 7 段日累计 + 缓存（新鲜期 30 分钟）
  -> 返回 { grid:[{lat,lon,values:{d1..d7}}], days:[7 个日期], model, updatedAt, aggregateFrom }
  -> 前端 controller 构建 7 日索引
      - 任意层级：canvas 渲染全矩形 399 点插值色斑 + 省界线叠加
      - 下钻：视口聚焦当前行政面 + 行政边界高亮（色斑不裁剪、不换源、不重新请求）
  -> 底部时间轴 7 日期标签：点击切换 / 播放逐日切换（1.2s/天）
  -> 退出：清除色斑图层、时间轴、播放计时器、请求计时器
```

## 4. 服务端实现

1. 新增 `server/src/precipitation-service.js`：
   - 上游拉取：固定拼装 399 点坐标串（`precip-grid-cfg`：范围 118.0–123.0E / 27.0–31.5N、步长 0.25°、`hourly=precipitation`、`forecast_hours=168`、`timezone=Asia/Shanghai`），Node fetch（复用 `weather-upstream.js` 的超时/压缩/错误边界模式或独立实现）；
   - 归一化：上游数组 → `{ lat, lon, hours[] }`，`hours` 与统一 `times[]`（北京时间）对齐；校验 399 点 × 168h 完整性；
   - 聚合：从当前整点小时定位起点，第 N 天 = 对应 24 个逐小时 `precipitation` 求和；预报边界不足 24h 时按实际可得求和并在响应标注实际覆盖天数，不补 0；
   - 缓存：单键（网格固定），新鲜期 30 分钟；合并同键在途请求；`updatedAt` 记录上游拉取时间；
   - 错误边界：超时/5xx/429/结构异常 → 有缓存返回缓存快照，无缓存抛降级错误；不向浏览器泄露原始错误；日志无凭据。
2. `server/src/app.js` 新增路由 `GET /api/precipitation-grid`：无查询参数（浏览器不可控制网格/变量/时次）；返回第 1 节结构；`Content-Type: application/json`，体积超标时启用 gzip。
3. 单测 `server/src/precipitation-service.spec.js`：参数固定、聚合口径（含起点定位与边界）、缓存新鲜期、合并在途、降级路径、体积上限。

## 5. 前端实现

1. `web/src/api/precipitation.ts`：`fetchPrecipitationGrid()`，超时与错误映射。
2. `web/src/features/precipitation/`：
   - `precipitationTypes.ts`：`PrecipitationSnapshot { grid, days, model, updatedAt, aggregateFrom }`、`DayIndex`；
   - `precipitationRepository.ts`：generation 守卫（沿用 weatherRepository 模式），请求合并/取消；
   - `precipitationStore.ts`（pinia）：`phase/selectedDay/playing/snapshot/errorMessage`，播放计时器生命周期。
3. `web/src/map/precipitationLayerController.ts`：
   - canvas 渲染：399 点 → 双线性插值到视口级平滑色斑（0.05° 目标），半透明叠加；全矩形渲染 + 省界线叠加；**下钻保持统一分辨率：视口聚焦当前行政面 + 行政边界高亮，色斑不裁剪、不换源、不重新请求**；
   - 色阶映射：中国气象局 24h 雨量等级（常量表，实施时定具体色值）；
   - pane：`precipitationPane` zIndex 400–409（低于注记 450，高于行政边界底层；实现时与 `MapView` 边界 pane 核对）；
   - 生命周期：`mount/updateDay/updateBounds/clear`；`clear()` 同时重置快照与选中日期；地图 move/zoom 视口局部重绘；
   - 单测：渲染数据裁剪、色阶映射、pane 顺序、clear 清理、与台风/天气互斥。
4. 面板组件 `web/src/components/precipitation/PrecipitationPanel.vue`：
   - 地图底部时间轴：7 个日期标签（"8/10 周一"），选中高亮；播放/暂停按钮；
   - **色斑可见度滑动条**：0–100%，默认 60%，拖动实时调节色斑图层整体透明度（不重绘、不影响播放/日期切换）；0% 隐藏色斑便于对照底图/地块；
   - 色阶图例条（mm 分级）、数据来源署名"降水预报数据 © Open-Meteo / ECMWF（0.25° 网格，约 25 km）"、"预报场仅供参考，不作定损依据"；
   - 手动刷新按钮（新鲜期控制）、加载/失败/降级文案（沿用天气面板口径）。
5. 悬停浮窗：`precipitationLayerController` 监听 mousemove → 经纬度反算 → 最近网格点插值 → 分级 + 当日累计数值，显示小浮窗（仅降雨程度文字 + 数值 mm），跟随鼠标偏移避让，移出即消失；不显示地址/经纬度/日期/7 天；
5. `MapControlStack.vue`：灾害风险相关入口区新增"查看降水"项（或独立按钮，与台风并列），沿用禁用/互斥规则；emit `open-precipitation` / `close-precipitation`。
6. `MapView.vue` 装配：模式状态、互斥（天气与台风/降水互斥；台风+降水可叠加、后进者接管相机、最后一个退出才恢复省界相机）、进入切回浙江省级、退出清理与恢复联动、地块编辑禁用三锁。

## 6. 测试与验收

对照需求第 5 节 11 条验收标准逐项执行：

1. 入口出现且三模式互斥，进入/退出生命周期正确；
2. 全省连续色斑 + 默认第 1 天 + 半透明可透底图，加载→成功无白屏；
3. 时间轴 7 日期标签点击切换且不重新请求上游；
4. 播放逐天切换 1.2s/天，到第 7 天自动停，播放中点日期暂停跳转；
5. 下钻到市/县/乡/村：色斑聚焦当前行政区域（视口聚焦 + 行政边界高亮，色斑连续不裁剪），切换日期/层级不重新请求上游；
6. 图例 + 署名 + "仅供参考"文案齐全；
6.1 可见度滑动条 0–100% 实时生效，默认 60%，拉至 0% 色斑完全隐藏（底图/边界/地块可见），拖动不影响播放与日期切换；
6.2 悬停浮窗仅显示降雨程度分级 + 当日累计数值（如"暴雨 / 24.6 mm"），无地址/经纬度/日期/7 天；跟随鼠标偏移，移出色斑/地图即消失；
7. 色斑低于注记 450，不遮挡边界/地块；
8. 手动刷新新鲜期与失败保留旧数据；
9. 上游模拟失败降级（有/无缓存两态）；
10. 退出全清理（图层/日期/播放计时/请求计时）；
11. 服务端单测 + 前端单测全绿。

## 7. 风险与缓解

| 风险 | 缓解 |
| --- | --- |
| 7 天响应体积超限 | 服务端归一化紧凑结构 + gzip；必要时降 `forecast_hours=120`（5 天）并同步需求 |
| Open-Meteo 无 uptime 保证 | 30 分钟缓存 + 降级文案 + 保留旧快照 |
| 0.25° 网格较粗、省内仅 153 点 | 插值平滑视觉 + 标注真实分辨率；省内下钻聚焦不承诺细粒度 |
| 免费层滥用风险 | 固定低频调用 + 缓存 + 手动刷新，避免循环拉取 |
| 播放计时器泄漏 | 统一生命周期：进入创建、退出/关闭/刷新/日期点击显式清除（沿用快照清理教训） |
| 与台风/天气互斥回归 | 复用现有 `weatherEntryState` 互斥模式扩展，E2E 覆盖三模式切换 |

## 8. 数据与版权

- 上游仅 `server/` 访问；前端只访问本站 `/api/precipitation-grid`；
- 界面标注数据来源（CC BY 4.0 署名）与演示边界；
- 不提交任何凭据与受限数据；Open-Meteo 无 key，无新增凭据文件。
