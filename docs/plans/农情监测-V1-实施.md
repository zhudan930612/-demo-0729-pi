## 0. 范围与目标

把「演示模式（顶层）→ 农情监测」在五级行政地图上落地：长势百米级连续热力图（多日期，2026-06 至 07 每 7 天，底部浮窗切换/播放）+ 右上角 tab（农情概况 / 异常top / 任务列表）+ 一键转任务 + 证据查看。独立互斥模式。

## 1. 数据模型（已生成，脚本在 `scripts/generate-agri-monitoring.py`）

产物在 `web/public/data/agri/`（gitignored，可再由脚本再生）：

### 1.1 `ndvi.json` — 长势连续栅格场（热力图渲染）
```json
{
  "dates": ["2026-06-01", ...],   // 9 期，每 7 天
  "grid": [ {"lat": 29.78, "lon": 120.86, "values": [62, 63, ...]}, ... ]  // values 为 NDVI×(×100) 整数，仅在省内
}
```
- 每点仅省内；值域约 0.30~0.90（值 = 数值 / 100）。

### 1.2 `villages.json` — 13 参保村聚合（异常/概况村级）
```json
[{ "code", "name", "centroid": {lon,lat,name}, "insuredAreaMu", "householdCount", "policyCount",
   "levels": {veryPoor,poor,normal,good,excellent},   // 承保面积占比，最近一期
   "anomalyRatio", "isAnomaly", "countyCode", "cityCode", "townshipCode", "data":true }]
```
- 异常 = levels.veryPoor + levels.poor > 0.30（只列超标村）。

### 1.3 `levels.json` — 省/市/县/镇 聚合（农情概况顶部）
```json
{ "byCode": { "330000": {code,name,insuredAreaMu,householdCount,levels,data}, "330600": {...}, ... } }
```
- 仅含省/绍兴市(330600)/上虞区(330604)/嵊州市(330683)/章镇镇(330604104000)/三界镇(330683104000)。无数据的子级区划不在 byCode 中（前端按承保面积降序、无数据者显示 0/空）。

### 1.4 `policy-growth-{村码}.json` — 村级保单维度长势
```json
[ { "policyId", "policyNo", "insuredName", "insuredPartyId", "insuredAreaMu", "levels": {...}, "premiumRate" } ]
```

### 1.5 `tasks.json` — 预生成任务
```json
[ { "id", "name", "type", "typeName", "villageCode", "villageName", "status",   // 待下发/待领取/进行中/已完成
    "createdAt", "executor": {name,role}|null, "remark",
    "sopAction", "requirement", "location": {name,lon,lat},
    "evidence": [ {url,time} ] } ]
```
- 待下发/待领取 → executor=null；已完成/进行中 → executor 绑协保员。

## 2. 前端装配（Web/Vue + Leaflet）

沿用「域 = useXxxMode composable + 专用 layer controller + store + 面板组件」的结构，不堆回 MapView。

### 2.1 新增文件
- `web/src/features/agri-monitoring/useAgriMonitoringMode.ts` — 模式装配（进入/退出/互斥/下钻/转任务/日期/播放）
- `web/src/features/agri-monitoring/agriMonitoringTypes.ts` — 类型与 5 级颜色/阈值常量

- `web/src/map/agriMonitoringLayerController.ts` — 热力图渲染（参照 `precipitationLayerController.ts` 的 value-grid + canvas 瓦片 + Catmull-Rom 插值 + 省界裁剪；pane zIndex < 450）

## 5. 关键决策

- 长势指数 = NDVI；5 级阈值：极差<0.4 / 较差0.4~<0.55 / 正常0.55~<0.7 / 较好0.7~<0.8 / 极好≥0.8（已按真实分布校准，五档均有数据）。
- 村级双口径：地图=百米级栅格热力图；村级面板=保单聚合 5 级占比（有意区分）。
- 异常top 只列超标村，靠热力图颜色表达，无判断依据区块。
- 任务状态四态线性，一键转任务初始「待领取」。
- 多日期浮窗仅样式参考降水控件，不共用组件/逻辑，保持模式互斥。
