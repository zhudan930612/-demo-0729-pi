# ADR-0010 巴威情景推演风险时序与渲染上限

状态：采纳

受灾预警仍使用巴威真实轨迹与历史降雨，只在既有 `26/71～43/71` 的 18 个影响节点离线生成确定性情景推演风险；至少 12 个节点具有不同的村级风险状态，完全相同状态最多连续 2 帧，中高风险村峰值不超过 600。省/市级继续仅绘制区县聚合徽标；县/乡镇级村界采用差量更新，单帧高亮不超过 250 村，避免为扩大演示变化而造成播放卡顿。若改用实时灾害模型、扩大到全省全时段风险或需要超过该渲染上限，应重新评审并新增 ADR。

关联需求：`docs/requirements/受灾预警-V1需求.md`（R2、R3、C3/C4）。
