# ADR-0006：龙江村数据重生成语义与成片聚类数据层约定

状态：采纳

## 背景

《地块成片划分-V1需求.md》（2026-08-19 定稿）要求龙江村（330604102014）与全部参保村按同一套成片聚类规则重新生成确认产物与保单 fixture。此前龙江村确认文件与保单 fixture 是"绝对不变"的受保护产物（`prepare-policy-confirmation.py` / `generate-policy-fixture.py` 检测到现有文件即跳过），与需求冲突。

## 决定

- **龙江村保护语义变更**：从"绝对不变、跳过生成"改为"授权重生成、保留未参保集合"。`prepare-policy-confirmation.py --village 330604102014 --force` 读取现有确认文件的未参保集合（83 块）并保留，参保地块归属按成片规则重排；未参保集合为空时拒绝覆盖。`generate-policy-fixture.py` 对龙江村同样授权重生成（legacy 文件名 `parcel-confirmation-v1.json` / `policy-v1.json` / `cultivation-v1.json` 保持不变，src/data 与 public/business 双写）。
- **成片聚类为确定性数据层算法**（固定输入 → 相同产物）：参保地块按质心距离 ≤200m 建邻接图、连通分量即链式成片组；面积 >500 亩的分量贪心 BFS 切分为多个 ≤500 亩相邻子组（种子取数值最小地块 id，遍历一律 sorted）；组分类面积（内部 4 位小数求和、四舍五入 2 位）>50.00 亩立大户（含单块大田），≤50.00 亩组内逐块一块一户进团单；未参保地块不参与聚类。产物 `assignmentModel = "spatial-chained-clustering-500mu-cap"`，spatialReview/report 记录每户地块数、面积、最大跨度、孤岛列表、大户覆盖占比。

## 原因

- 需求 A4 确认"龙江村受保护确认文件授权修改；龙江村 + 全部参保村重新生成"。
- 前端零改动（R4）：前端经 `/business/policy-{code}.json` 加载、`validatePolicyFixture` 不校验保单数量、不读 `assignmentModel/spatialReview`，数据层重生成不影响前端行为。

## 被否方案

- **维持龙江村绝对不变**：与需求冲突，无法统一 13 村口径。
- **前端新增分组/红框渲染**：需求 C1/C2 明确禁止，仅数据修正。

## 触发重开

- 未参保集合口径变更、聚类参数（200m/500 亩/50 亩）调整、或需要人工逐块确认新的龙江村分配时，需新 ADR 或需求变更流程。
