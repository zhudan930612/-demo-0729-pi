# ADR-0009 受灾预警演示数据静态固化

## 决定

受灾预警模式的全部演示数据（巴威台风轨迹、Open-Meteo 历史归档降雨、每节点村级预警清单、承保造数、任务与证据）由 scripts 一次性拉取/计算并固化为 `web/public/data/` 静态 JSON；模式运行期零网络依赖。server 端历史降雨服务（复制现有降水服务改指 Open-Meteo 历史归档端点）仅作开发期取数工具，不进运行链路。

## 为什么

- 历史数据是固定时段的死数据，实时拉取没有任何新鲜度收益，反而让演示现场依赖外网 + APIHz 两个外部服务，任一故障演示即崩。
- 预警村清单按节点离线预计算（33898 村 × 约 50 节点），前端播放只查表渲染，消除运行时聚合计算的性能风险。

## 什么触发重开

- 受灾预警接入实时台风/降雨数据（走出历史案例演示）；
- 或演示数据需要频繁更换案例（换台风、换时段）且脚本固化成本高于维护 server 实时链路。

关联需求：`docs/requirements/受灾预警-V1需求.md`（R2 模块 4、C3）。
