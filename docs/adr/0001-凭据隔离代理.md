# ADR-0001：第三方凭据与浏览器隔离（独立 Node 代理）

状态：采纳

## 背景

台风路径/预测（APIHz）、实时天气（和风天气）、可选地址增强（APIHz）均需凭据访问第三方在线服务。浏览器直接持有或携带这些凭据会泄露到前端 bundle 与网络请求中；仓库提交也会造成凭据外泄。

## 决定

- 所有第三方凭据只存在于独立 Node 代理 `server/`（process env 或已忽略的本地 `.env.local`），浏览器只访问本站 `/api` 路径。
- 禁止浏览器直连 APIHz/和风天气，禁止使用 `VITE_*` 注入第三方凭据。
- 代理统一负责：固定上游访问、输入/响应校验、统一错误、脱敏、超时/响应大小/限流边界、in-flight 合并与缓存。
- 凭据安全用"脱敏真实探针 + staged secret scan + bundle scan"三层验证（DevTools Network 只应出现本站 `/api`，bundle 不含凭据）。

## 原因

- 凭据不进浏览器 = 前端 bundle、网络抓包、日志都无法泄露真实凭据。
- 单一出口便于统一限流、脱敏、审计与错误边界，避免各前端模块各自直连上游。
- 依赖当前技术栈：`web/src/api/*.ts` 只封装本站 `/api`。

## 被否方案

- **浏览器直连第三方 API**：凭据进 bundle，无法撤销，放弃。
- **前端注入 `VITE_*` 凭据**：构建产物携带凭据，放弃。
