# ADR-0002：受限空间数据治理（私有仓库 + Git LFS + 不外泄）

状态：采纳

## 背景

行政边界（浙江五级）、吉林一号高分影像、AI 地块 GeoJSON 等空间数据受版权或商业授权约束（私有仓库 + 已授权数据），演示结果可能被误认为正式测绘/确权成果。

## 决定

- 受限源数据（`01-行政区划/`、`05-遥感数据/`）通过 **Git LFS** 入库私有仓库，拉取后需 `git lfs pull` 取得实体。
- 不提交：`参考截图/`、`web/public/data/`、`web/public/tiles/`、`web/dist/`、`.env.local`、天地图 Token、APIHz 凭据。
- 吉林一号影像、派生瓦片和 AI 地块 GeoJSON **不得公开分发**：不得转为公开仓库、公开导出或外发；锐多宝数据未获商业授权前不得对外发布。
- Delineate Anything 仅作为**仓库外离线工具**，不复制其源码、环境或模型权重。
- AI 地块不得描述为确权、承保或测绘成果。

## 原因

- 数据授权协议约束 + 防止受限数据经公开仓库/导出外泄。
- 私有仓库内可用但绝不外发，兼顾演示开发与合规。

## 被否方案

- **公开仓库托管**：违反数据授权约束，放弃。
- **大文件直接入库**：仓库膨胀且 LFS 跟踪缺失，放弃。
