# ADR-0011 受灾预警地图呈现与派发口径

## 决定

受灾预警演示模式（阶段二·台风邻近预警期）地图呈现与派发口径：

- **村级预警改用村边界面上色高亮**（移除放射点脉冲标记）：村界几何来自真实村庄边界 `/data/villages/{townshipCode}.geojson`（非村点位伪造）；县/乡镇/村级展开为村边界高亮，省/市级视角按区县聚合为**预警徽标**（⚠ + 中/高风险村数，底色=该县最高等级色）；点击村边界=进入村级视角，点击徽标=下钻该区县。低风险村不展示任何预警。
- **预警监测仅显示中/高风险村**：列表/概览/抽屉只含中/高风险触发村；低风险（待观察）仅保留定义，不上图、不入列表。
- **灾损预估风险分布无「无风险」档展示**：无风险村保留在数据中但前端不展示（默认=无风险，村触发预警后按 预警等级低/中/高 分别计入并显示，分母=已触发预警村承保面积）；色带/饼图颜色与农情监测 5 级色带一致（高=较差橙 / 中=正常黄 / 低=较好绿）。
- **灾损预估三项数字只增不减**：记录到访节点最大值（峰值），预警解除回落时保持峰值不回退；循环回起点清零、按区域（省/市/县/乡/村）各自记录。
- **移除派发模式**（自动/人工开关）：统一手动派发——任务经村卡片「派发任务」或表头「一键派发」生成；不再区分自动/人工。

## 为什么

- 真实村边界比村政府驻地脉冲点更能反映预警的空间覆盖与形态，且"无风险"档位易误导（默认=无风险并非未受损）；风险分布改为仅展示已触发预警村，口径更清晰。
- 灾损为累计语义，峰值只增不减符合预期（预警解除不应导致已受灾数字回落）。
- 风险分布颜色与农情监测色带一致，跨面板统一视觉语言，减少认知成本。
- 派发模式（自动/人工）增加演示分支且易误触，移除后仅手动派发更收敛、复用农情任务体系。

## 什么触发重开

- 村级预警改回点位/脉冲标记方案；
- 风险分布重新引入「无风险」档展示或改用其它颜色体系；
- 灾损数字恢复"随预警解除回落"；
- 需要重新引入自动派发模式。
