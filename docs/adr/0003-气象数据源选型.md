# ADR-0003：气象数据源选型（NMC 浙江预警接管预警，和风保留实时）

状态：采纳

## 背景

天气功能首期接入和风天气（实时、分钟级降水、24 小时预报、预警四个模块）。预警模块随后评估了数据来源的稳定性与权威性。

## 决定

- **气象预警模块由 NMC 浙江预警接管**（2026-08-04 后）：固定全省完整预警列表、图标锚定经核验的政府驻地坐标、浮窗仅标题/时间/官方正文、无外链、刷新遵循该需求文档的 60 秒共享冷却规则。
- **和风天气预警请求已下线**；和风天气仅保留实时、分钟降水、24 小时预报三个接口。
- 面状降水预报（未来 7 天逐日网格热力图）由"查看降水"子功能承接，规格以面状降水预报需求为准。
- 可选 APIHz 地址增强线路未配置时，标题按行政对象/地块/地图点选位置文案降级，不阻断主功能。

## 原因

- NMC 为官方来源，预警列表/图标权威性、稳定性和冷却控制优于商业天气 API 的预警接口。
- 减少对单一商业 API 的依赖面，把商业凭据仅用于实时天气类数据。

## 被否方案

- **继续使用和风天气预警接口**：权威性与稳定性不足，被替换。
