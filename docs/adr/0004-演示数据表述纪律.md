# ADR-0004：演示数据表述纪律（不冒充正式成果）

状态：采纳

## 背景

本项目为内部技术验证 demo，但数据链路与界面具有"正式产品"外观（影像识别地块、保单关联、灾害风险），存在演示结果被误认为确权、承保或测绘成果的风险。

## 决定

- UI 统一使用"地块"，**不得把演示结果描述为确权、承保或测绘成果**。
- 天气数据定位为约 1 公里分辨率查询点附近的辅助信息，不代表整块地块或行政区域实测结果，**不作为定损或理赔依据**。
- 人工地块仅保存在当前浏览器（localStorage），不修改原始 AI GeoJSON，也不上传服务器；本地写入失败时保留用户草稿。
- 对演示数据的来源与用途保持准确表述（数据来源、许可归因）。

## 原因

- 合规与信任：避免演示数据被误用于业务决策（定损/理赔）或对外表述为权威成果。
- 与 ADR-0002（受限数据治理）共同构成数据合规边界。

## 被否方案

- **无**（纯表述纪律，无替代方案权衡）。
