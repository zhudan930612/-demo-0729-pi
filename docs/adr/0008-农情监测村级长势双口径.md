# ADR-0008：农情监测村级长势双口径（地图栅格 / 面板保单聚合）

状态：采纳（2026-08-21，经烤打确认）

## 背景

「农情监测」在村级视角下，长势有两种可能的表达方式：地图上用**百米级栅格热力图**（连续空间分布），或用**按保单聚合的 5 档占比**（离散保单口径）。此前需求文档对"村级显示什么"曾有歧义——到底是地块/保单粒度，还是仅热力图。烤打时暴露了"同一村两个不同长势口径"的潜在矛盾。

## 决定

村级长势采用**双口径、有意区分**：

- **村级地图**：用**百米级连续栅格热力图**表达村内**空间分布**（村内哪片正常、哪片极差）；不做地块级/村级色块。
- **村级「农情概况」面板**：用**按保单聚合的 5 档占比**列表（保单维度，一保单可对应多地块），按保单长势排序（极差→极好），表达**保单承保口径**的分档统计。

两者并存且**非矛盾**——是同一村长势的两种视角（空间分布 vs 保单口径），需求文档 R3 已标注"村级双口径说明"。

## 原因

- 空间分布用栅格最直观（村内连续渐变），保单口径用聚合占比最符合业务（承保分档）；
- 避免强迫"村级只能一种表达"而损失任一维度；两者数据来源不同（栅格 vs 保单），前端需分别支持。

## 什么会重开此决定

- 若后续引入真实遥感长势数据、且主张村级单一口径（要么纯空间要么纯保单），需重新评审；
- 若前端实现发现双口径并存成本过高，或用户认为村级两口径反而难懂，可回退为单口径。
